# 填充

```python
import os  
import sys  
# 读取输入的一行字符串  
s = input()  
# 获取字符串长度  
n = len(s)  
ans = 0  # 用于记录找到的子串数量  
i = 1    # 指针，从第2个字符开始（索引为1），为了方便向回看 i-1# 遍历字符串  
while i < n:  
    current_pair = s[i - 1:i + 1]  
      
    if current_pair != '01' and current_pair != '10':  
        ans += 1  
        i += 2  
    else:  
        i += 1     
print(ans) # 输出最终结果
```
