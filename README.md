# Algorithm

个人算法与竞赛学习笔记仓库，主要面向**蓝桥杯**等比赛，用 Markdown 整理题目、思路与代码片段。

## 仓库里有什么

| 目录 | 说明 |
|------|------|
| `算法学习/` | 按专题整理的笔记（搜索与图、动态规划、贪心、前缀和与差分等） |
| `真题文件/` | 真题与练习归档 |
| `模板/` | 常用算法模板与备忘 |
| `第 36 场 蓝桥·算法挑战赛·百校联赛/` | 单场赛事相关笔记 |

笔记以 **Obsidian** 或任意 Markdown 编辑器阅读即可；部分文件含 LaTeX 公式，在支持 Math 的预览中显示更佳。

## 技术约定（代码）

- **Python 3.7** 兼容写法为主。  
- 读入常用：`import sys`，`it = iter(sys.stdin.read().split())`。  
- 竞赛向：短变量名、无多余工程结构；具体习惯见仓库内 `.cursorrules`。

## 使用说明

1. 克隆仓库：`git clone git@github.com:yijieshufu/Algorithm.git`  
2. 本地用 Obsidian 打开仓库根目录，或直接用 VS Code / Cursor 浏览 `算法学习/` 等目录。
