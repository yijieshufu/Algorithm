# 题目描述
给定 $N$ 组冶炼记录 $(A, B)$，满足 $B = \lfloor A / V \rfloor$，求正整数转化率 $V$ 的**最小值**和**最大值**。  
A:总钱 V:价格 B:个数  
$B = \lfloor A / V \rfloor$，意思就是：你的钱**刚好够买 $B$ 个，但不够买 $B+1$ 个**。  
$V_{max} = \lfloor A / B \rfloor$  
 $V_{min} = \lfloor A / (B + 1) \rfloor + 1$  
数据范围：$N \le 10^4$，$1 \le B \le A \le 10^9$。
# 分析
#### **遇到 $B = \lfloor A / V \rfloor$ $\rightarrow$ 想到“价格区间”**
- **分析**：这是一个典型的“下取整”不等式。
- **逻辑**：
    - 如果 $V$ 很大，产出 $B$ 就会变小。所以 $V$ 有个最高封顶。
    - 如果 $V$ 很小，产出 $B$ 就会变大。所以 $V$ 有个最低底线。
- **公式**：对于每一组 $(A, B)$：
    - $V \in [ \lfloor \frac{A}{B+1} \rfloor + 1, \lfloor \frac{A}{B} \rfloor ]$
## 代码

```python
import sys
it = iter(sys.stdin.read().split())
n =int(next(it))
ans_max=float('inf') # 全局
ans_min=0
for _ in range(n):
    a = int(next(it))
    b = int(next(it))
    v_max = a//b
    v_min = a//(b+1) +1
    # 边界 (取交集：下限取大，上限取小)
    ans_max=min(v_max,ans_max) 
    ans_min=max(v_min,ans_min)
print(ans_min,ans_max)
```
