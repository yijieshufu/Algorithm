# 题目描述
有 $n$ 个瓶子，第 $i$ 个瓶子装水 $a_i$。瓶子颜色以 $k$ 为周期循环（即 $i$ 与 $i+k, i+2k, \dots$ 同色）。同色瓶子间，水只能从左侧瓶子倒入右侧瓶子。求经过任意次操作后，所有瓶子水量最小值的最大可能值。  
**数据范围**：$n, a_i \le 10^5$，$1 \le k \le n$。
## 分析
**二分答案 (Binary Search on Answer)**
- **原因**：题目要求“最小值的最大值”，这是典型的二分搜索标志。
- **单调性**：如果最小值 $X$ 可以达到，那么比 $X$ 小的值一定也能达到。
- **验证逻辑**：由于同色瓶子只能“从左往右”倒水，对于每一组同色瓶子，只要保证其前缀和始终能覆盖每个瓶子分配 $X$ 单位水的要求，该 $X$ 即为合法。

- **二分搜索范围**：最小值 $L=0$，最大值 $R=10^{10}$（或初始数组的最大值，保险起见取大值）。
- **Check 函数实现**：
    - 将瓶子按 $i \pmod k$ 分成 $k$ 组。
    - 对每一组进行遍历。维护一个变量 `surplus`（当前可用盈余）。
    - 遍历到瓶子 $a_i$ 时，`surplus += a[i] - X`。
    - 如果 `surplus < 0`，说明左侧没有足够的水填补当前瓶子达到 $X$ 的缺口，且水不能从右往左倒，因此 $X$ 不合法。
- **结果**：二分找到满足条件的最大 $X$。
## 代码

```python
import sys
# 数据读入
it = iter(sys.stdin.read().split())
n = int(next(it))
k = int(next(it))
a = [int(next(it)) for _ in range(n)]
# check h函数
def check(mid):
    for state in range(k):
        surplus = 0
        for i in range(state,n,k):
            surplus += a[i]-mid
            if surplus<0:
                return False
    return True
l,r=0,10**14
ans = 0
while l<=r:
    mid = (l+r)//2
    if check(mid):
        ans = mid 
        l = mid+1
    else:
        r = mid-1
print(ans)
```

# 暴力解题
## 题目描述
### 1. 核心条件
- **颜色循环**：每 $k$ 个瓶子颜色循环一次。这意味着下标对 $k$ 取模相同的瓶子颜色一样（比如 $n=7, k=3$，则第 1, 4, 7 个瓶子同色）。
- **单向流动**：水只能从**前面的**同色瓶子倒入**后面的**同色瓶子。
- **目标**：通过倒水，让所有瓶子里水量的最小值 $\min a_i$ 尽可能地大。
### 2. 目的
你要找到一个全局的“水位高度”，使得每一组同色瓶子通过往后倒水，都能保证组内的每一个瓶子都不低于这个高度。
## 分析
### 1. 为什么是前缀平均值？
想象其中一组同色瓶子，水量分别是 $[8, 2, 4]$：
- **第 1 个瓶子**：自己有 8 单位水。它最多能给自己留 8 单位。
- **第 2 个瓶子**：它只有 2 单位，但它能从第 1 个那里拿水。两人平摊后，每人最多 $10 \div 2 = 5$ 单位。
- **第 3 个瓶子**：它有 4 单位，它能拿第 1, 2 个剩下的水。三人平摊后，$14 \div 3 \approx 4.66$。  
**结论**：因为水只能往后流，所以对于任何一个瓶子，它能达到的最高水位，受限于**它及它之前所有同色瓶子的平均水量**。如果前面水不够，它就接不到；如果前面水多，它可以接过来。
### 2. 木桶效应
- 对于每一组颜色，只要看该组内所有可能的 **“前缀平均值”**，其中最小的那个，就是这一组能保证的最高底线。
- 最后，取所有 $k$ 组颜色中，底线最低的那一组，就是全场的答案。
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
k = int(next(it))
a = [int(next(it)) for _ in range(n)]
ans = 10**18 
for f in range(k):
    b = 0 
    m = 0 
    for g in range(f, n, k):
        m += 1
        b += a[g]
        if b // m < ans:
            ans = b // m
print(ans)
```
