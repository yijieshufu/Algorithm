# 题目描述
**1. 【材料】 (Materials)**
- **输入基准**：两个正整数 $n$（序列长度）和 $k$（子序列最小长度限制）。
- **核心数据**：一个包含 $n$ 个正整数的序列 $a = \{a_1, a_2, \dots, a_n\}$。
- **数值范围**：$1 \le a_i \le n$，$1 \le k \le n \le 10^5$。  
**2. 【限制】 (Constraints)**
- **结构限制**：必须选择**连续**的子序列（Subarray），禁止跳跃选取。
- **长度限制**：所选子序列的长度 $m$ 必须满足 $m \ge k$。
- **中位数定义**（排序后）：
    - 若 $m$ 为奇数：中位数为第 $\lfloor m/2 \rfloor + 1$ 个元素。
    - 若 $m$ 为偶数：中位数为第 $m/2$ 个元素。
- **性能限制**：$n$ 规模达 $10^5$，算法复杂度需控制在 $O(n \log n)$ 级别，严禁 $O(n^2)$ 暴力枚举。  
**3. 【目的】 (Objective)**
- **核心任务**：在所有满足“连续”且“长度 $\ge k$”条件的子序列中，寻找并输出**中位数的最大值**。
## 分析
#### **第一步：遇到“求最大中位数” $\rightarrow$ 想到“二分答案”**
- **痛点**：直接枚举所有区间并排序找中位数太慢。
- **联想**：中位数的取值具有**单调性**。如果中位数能达到 $10$，那它一定能达到 $9$。
- **决策**：既然“直接求”很难，那就“猜”一个值 $x$，转而解决判定性问题：“是否存在一个区间，中位数 $\ge x$？”
#### **第二步：遇到“中位数判定（排序限制）” $\rightarrow$ 想到“+1 / -1 变换”**
- **痛点**：二分里如果还要排序，复杂度依然爆炸。
- **联想**：中位数的本质是**“大于等于它的数”是否足够多**。
- **决策**：使用**及格标记法**。
    - 令 $a_i \ge x$ 为 **+1**， $a_i < x$ 为 **-1**。
    - 根据你的推导（奇偶归一化），只要某个区间的**权重和 $S \ge 1$**，中位数就一定 $\ge x$。
    - **这一步完成了“排序问题”到“求和问题”的跨维度打击。**
#### **第三步：遇到“长度 $\ge k$ 的区间和” $\rightarrow$ 想到“前缀和 + 动态最小值”**
- **痛点**：即便变成了求和，枚举所有长度 $\ge k$ 的区间仍需 $O(n^2)$。
- **联想**：区间和可以表示为 $S[j] - S[i]$。我们需要 $j - i \ge k$ 且 $S[j] - S[i] \ge 1$。
- **决策**：
    - 固定右端点 $j$，在左侧合法范围 $[0, j-k]$ 内寻找最小的 $S[i]$。
    - 通过一个变量 `min_v` 随着 $j$ 的移动同步更新，实现 $O(n)$ 完成判定。
	
	当你固定了右端点 $j$ 时，你要在左边找一个 $i$。这个 $i$ 必须满足：
	1. **距离够远**：$i \le j - k$。
	2. **数值够小**：$S[i]$ 越小， $S[j] - S[i]$ 这一减出来的结果就越大，也就越容易 $\ge 1$。  
	**`min_v` 就是在帮你维护这个“左侧范围内最小的 $S[i]$”。**
## 代码
```python
import sys

# 1. 变量
it = iter(sys.stdin.read().split())
n, k = int(next(it)), int(next(it))
a = [int(next(it)) for _ in range(n)]

# 2. 判定 (操作)
def check(mid):
    s = [0] * (n + 1)
    # 权重转换 + 前缀和
    for i in range(n):
        s[i+1] = s[i] + (1 if a[i] >= mid else -1)
    
    # 动态维护左侧最小前缀和
    min_v = 0
    for j in range(k, n + 1):
        min_v = min(min_v, s[j-k])
        if s[j] - min_v >= 1: return True
    return False

# 3. 二分 (边界)
l, r, ans = 1, max(a), 1
while l <= r:
    mid = (l + r) // 2
    if check(mid):
        ans, l = mid, mid + 1
    else:
        r = mid - 1

# 4. 答案
print(ans)
```
