# 题目描述
小明有 $n$ 种卡牌，每种已有 $a_i$ 张。他有 $m$ 张空白卡，可涂成第 $i$ 种牌（每种最多涂 $b_i$ 张）。问最多能凑出多少套完整的卡牌（每套含全部 $n$ 种牌各一张）。
# 分析
假设我们要凑 `mid` 套牌，对于每一种牌 $i$：
- **如果已有数量 $a_i \ge mid$**：太棒了，这种牌够了，不需要消耗空白卡。
- **如果已有数量 $a_i < mid$**：
    - **缺口计算**：我们需要补 `mid - a_i` 张牌。
    - **硬性约束 1**：补的张数不能超过这种牌允许涂抹的上限 $b_i$。如果超过了，直接判定 `mid` 不可行。
    - **硬性约束 2**：所有种类的牌补齐所需的空白卡总和不能超过手里的 $m$ 张。
## 代码

```python
import sys

it= iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
a = [int(next(it)) for _ in range(n)]
b = [int(next(it)) for _ in range(n)]

def check(mid):
  rem = 0
  for i in range(n): 
    canneed = mid - a[i]
    if canneed > 0:
      if canneed > b[i]:
        return False
      rem += canneed
      if rem > m:
        return False
  return True
l = 0 ; r = m
ans = m
while l<=r:
  mid = (l+r)//2
  if check(mid):
    ans = mid
    l = mid + 1
  else:
    r = mid - 1
print(ans)
```
