# 题目描述
$T$ 组数据  
	一个 $N \times M$ 的矩阵，每个格子 $(i, j)$ 代表一个房间,每个房间的固定容纳人数 $A_{i,j}$。  
	$1$ 个老师 + $K$ 个学生  
	房间距离 $d = \max(|i_1 - i_2|, |j_1 - j_2|)$  
	寻找全局**最小**的正方形半径 $d$，使得至少存在一个老师的住处，能让周围 $d$ 范围内的总容量（K+1）达标。
# 分析
$d = \max(|i_1 - i_2|, |j_1 - j_2|)$ 是 切比雪夫距离  
遇到“**切比雪夫距离**” $\rightarrow$ 想到“**正方形区域**”  
给定中心 $(i, j)$ 和半径 $d$，左上角坐标为 $(i-d, j-d)$，右下角坐标为 $(i+d, j+d)$。

需要判断最远的学生到达老师的距离最小，相当于要**查询矩阵区域的容量**  
	遇到“频繁查询矩形区域总和” $\rightarrow$ 想到“**二维前缀和**”  
	预处理一个二维前缀和数组 $S$。  
	- **公式**：  
    $$S[i][j] = A[i][j] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]$$  
	- **查询**：任意矩形 $(x1, y1) \to (x2, y2)$ 的和为：  
    $$Sum = S[x2][y2] - S[x1-1][y2] - S[x2][y1-1] + S[x1-1][y1-1]$$  
遇到“求最小的半径”且具有单调性 $\rightarrow$ 想到“二分答案”
- 半径 $d$ 越大，容量递增，满足二分的**单调性**。
- 在 $[0, \max(N, M)]$ 范围内二分猜一个 $d$。
## 代码

```python
import sys
# 优化 I/O
it = iter(sys.stdin.read().split())
T_cases = int(next(it))
for _ in range(T_cases):
    N = int(next(it))
    M = int(next(it))
    K = int(next(it))

    grid = []
    total_sum = 0
    for i in range(N): # N*M
        row = [int(next(it)) for _ in range(M)]
        grid.append(row) # 一行行存储
        total_sum += sum(row)

    # 基础可行性判定
    if total_sum < K + 1: #total_sum:总的容量
        print("-1")
        continue

    # 预处理二维前缀和
    S = [[0] * (M + 1) for _ in range(N + 1)]
    for i in range(1, N + 1):
        for j in range(1, M + 1):
            S[i][j] = grid[i - 1][j - 1] + S[i - 1][j] + S[i][j - 1] - S[i - 1][j - 1] #注意grid的下标

    def check(d):
        # 检查半径 d 是否能容纳 K+1 人
        for i in range(1, N + 1):
            for j in range(1, M + 1):
                if grid[i - 1][j - 1] > 0:  # 老师入住的房间必须有容量
                    r1, c1 = max(1, i - d), max(1, j - d)
                    r2, c2 = min(N, i + d), min(M, j + d) # 矩形的区域
                    if S[r2][c2] - S[r1 - 1][c2] - S[r2][c1 - 1] + S[r1 - 1][c1 - 1] >= K + 1:
                        return True
        return False
    # 二分查找最小距离 d
    low, high = 0, max(N, M)
    ans = high
    while low <= high:
        mid = (low + high) // 2
        if check(mid):
            ans = mid
            high = mid - 1
        else:
            low = mid + 1
    print(ans)
```
