# 肖恩的乘法表
在一个 $n \times m$ 的矩阵中，位置 $(i, j)$ 的元素值为 $i \times j$。将矩阵中所有元素从小到大排序，求排序后的第 $k$ 个元素。
## 分析
由于矩阵的每一行和每一列都是单调递增的，这使得我们可以对答案的**数值范围**进行**二分查找**：
1. **二分范围**：最小值 $1$，最大值 $n \times m$。
2. **判定逻辑**：对于给定的数值 $mid$，统计矩阵中有多少个数 $\le mid$。
    - 在第 $i$ 行中，元素为 $i \times 1, i \times 2, \dots, i \times m$。
    - 小于等于 $mid$ 的个数即为 $\min(m, \lfloor mid / i \rfloor)$。
    - 累加所有行的计数，若总数 $\ge k$，说明第 $k$ 小的数可能更小，否则更大。
## 代码
```python
import os
import sys
it = iter(sys.stdin.read().split())
n,m,k = int(next(it)),int(next(it)),int(next(it))
def check(mid):
  cnt = 0
  for i in range(1,n+1):
    cnt +=min(m,mid//i) # 最关键的代码
  if cnt >=k:
    return True
  return False
l = 1;r = n * m
ans = r 
while l <= r:
  mid = (l+r) // 2
  if check(mid) :
    r = mid - 1
    ans = mid
  else :
    l = mid + 1
print(ans)
```
