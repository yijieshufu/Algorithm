# 题目描述
**1. 核心描述**：  
有一根长度为 `len` 的管道（分为 $1$ 到 `len` 段）。在特定位置 $L_i$ 有阀门，它们在不同时刻 $S_i$ 开启。开启后，水流以每秒 1 单位长度的速度向**左右两端**扩散。  
**2. 核心条件（扩散公式）**：
- 在时刻 $T$（$T \ge S_i$），第 $i$ 个阀门覆盖的范围是：  
    **$[L_i - (T - S_i), \ L_i + (T - S_i)]$**
- 水流必须覆盖管道的所有段（从 1 到 `len`）。  
**3. 最终目的**：  
寻找满足全覆盖条件的**最小时间 $T$**。
# 分析
- **$len \le 10^9$**：绝对不能开数组记录每一段的状态（会显存/内存溢出 MLE）。
- **$S_i \le 10^9$**：绝对不能一秒一秒地模拟（会超时 TLE）。
- **$n \le 10^5$**：算法复杂度必须控制在 $O(n \log n)$ 或 $O(n \log^2 n)$ 级别。  
**结论**：  
因为“时间越长，覆盖范围越广”，满足**单调性**。因此，这道题的最优解是：  
**【二分答案】 + 【区间合并校验】**
#### 第一步：二分答案 (Binary Search)
我们不直接求 $T$，而是去**猜** $T$。
- **范围**：下限 $L = 0$，上限 $R = 2 \times 10^9$。
- **逻辑**：如果猜测的时间 $mid$ 能让管道全满，我们就尝试更短的时间（往左找）；如果不能，就必须延长时刻（往右找）。
#### 第二步：校验函数 (check 函数)
##### 1. 区间生成：将时间化为空间
遍历 $n$ 个阀门，只有当 $T \ge S_i$（当前时间晚于开启时间）时，阀门才会出水。
- **扩散半径**：$d = T - S_i$。
- **物理区间**：$[L_i - d, L_i + d]$。
- **裁剪**：为了计算方便，利用 `max(1, ...)` 和 `min(len, ...)` 将区间锁定在管道有效范围内。
##### 2. 排序：确立“接龙”顺序
将所有生成的有效区间按**左端点**从小到大排列。这是为了确保我们能从管道的最左侧开始，一步步向右检查是否存在断层。
##### 3. 贪心合并：无缝衔接判定
这是最关键的一步，我们维护一个变量 `curr`，代表当前**已经连续覆盖到的最右端**。
- **起点检查**：如果排序后第一个区间的左端点 $> 1$，说明开头就没湿，直接返回 `False`。
- **接龙逻辑**：遍历后续区间 $[L, R]$：
    - **判定条件**：$L \le curr + 1$。
    - **含义**：如果新起点的左边（或正好是）已经湿润的范围，说明这两段水流**汇合**了。因为是离散的段，`+1` 表示第 5 段湿了，第 6 段接着湿，中间没有干枯的空隙。
    - **更新**：`curr = max(curr, R)`。利用 `max` 是为了防止被包含的短区间干扰进度。
- **断层处理**：一旦发现 $L > curr + 1$，说明中间出现了**“无人区”**，后续接得再长也没用，直接跳出。
##### 4. 最终判定
最后检查 `curr` 是否达到了管道的总长度 `len`。
## 代码
```python
import os
import sys

# 读入数据
it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it)) 
a = [(int(next(it)),int(next(it))) for _ in range(n)]
# check 函数
def check(t):
  # 计算区间
  q =[]
  for i in range(n):
    l,s=a[i]
    if t>=s:
      d = t-s
      q.append((max(1,l-d),min(m,l+d)))
  if not q:return False
  q.sort() # 排序
  if q[0][0]>1:return False  
  # 裁剪区间
  curr = q[0][1] # 当前的右边界
  for i in range(len(q)):
    if q[i][0]<curr+1:
      curr = max(curr,q[i][1])
    else:
      break
  return curr>=m
# 二分法
l, r, ans = 0, 2000000000, 0
while l<=r:
  mid = (l+r)//2
  if check(mid):
    ans = mid
    r = mid-1
  else:
    l = mid+1
print(ans)
```
