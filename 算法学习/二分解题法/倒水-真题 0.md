# 题目

- **条件**：$n$ 个瓶子，$k$ 种颜色循环。
- **规则**：只有同色瓶子能倒水，且只能 **从左往右**。
- **目标**：求所有操作后，$\min a_i$ 的最大值（即提高所有瓶子的最低水位）。
# 分析

这道题的核心矛盾在于 **“水流的单向性”** 与 **“颜色分组的独立性”**。
1. **分组独立**：不同余数（即不同颜色）的瓶子之间互不干涉，题目可以拆解为 $k$ 个独立的子问题。
2. **前缀瓶颈（木桶效应）**：  
	由于水只能从左往右倒，第 $i$ 个瓶子能达到的最高水位，不仅取决于它自己，还受限于它及其左侧所有同色瓶子的**平均水量**。  
	如果前 $m$ 个瓶子的总水量不足以支撑水位 $X$，那么这 $m$ 个瓶子中必然有瓶子无法达到 $X$。

#### 为什么是“前缀平均值”？
假设某一组同色瓶子的水量为 $[a_1, a_2, \dots, a_m]$。
- 为了让这 $m$ 个瓶子的水位都达到 $X$，它们的总水量必须满足：$\sum a_i \ge m \cdot X$。
- 即：$X \le \frac{\sum_{i=1}^m a_i}{m}$。
- 因为水不能从右往左流，如果前面的瓶子水太少，后面的水再多也补不回来。  
	因此，这一组瓶子能达到的**最大底线**，就是该组所有前缀平均值的**最小值**。
#### 算法流程：
- 遍历 $k$ 种颜色。
- 对每种颜色，从左到右维护当前组的 `总水量` 和 `瓶子数`。
- 计算每个位置的 `当前总水量 // 当前瓶子数`（取模即向下取整）。
- 全局答案 `ans` 是所有组、所有位置计算出的平均值中的 **最小值**。

# 代码

```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
k = int(next(it))
a = [int(next(it)) for _ in range(n)]

ans = 10**18

# 分成 k 个 单位
for s in range(k):
  total_water = 0
  count = 0
  # 同单位的
  for i in range(s,n,k):
    count += 1
    total_water += a[i]
    avg = total_water // count
    if avg < ans:
      ans = avg

print(ans)

```

# 思考

### 1. 突破“最大化最小值”的思维定式
- **定式**：看到“最大化最小值”或“最小化最大值”，90% 的选手会下意识直接写**二分答案**。
- **觉悟**：二分虽然稳，但它其实是“暴力枚举答案”的优化版。这道题告诉我们，如果**限制条件具有极强的方向性**（比如只能从左往右倒水），那么“瓶颈”往往就隐藏在**前缀状态**中。
- **结论**：能 $O(n)$ 解决的，绝不 $O(n \log n)$。
---
### 2. 独立子问题的拆解能力

- **直觉**：看到 $i$ 和 $i+k$ 颜色相同，第一反应不应该是“数组里隔着跳”，而应该是“这是 $k$ 个完全不相关的数组”。
    
- **处理技巧**：在脑海中把原数组纵向切分成 $k$ 条。只要其中一条支流的“最低水位”上不去，整个系统的最小值就上不去。这种 **“木桶效应”** 的处理，是解决复杂约束题目的利器。
    
---
### 3. “流”与“平均值”的数学转化

- **物理模型**：水只能向后流。
    
- **数学等价**：
    
    - 对于一组同色瓶子中的前 $m$ 个，无论你怎么倒，它们的**平均水位** $\frac{\sum_{i=1}^m a_i}{m}$ 是这 $m$ 个瓶子能达到的理论上限。
        
    - 因为水不能回头，所以第 $m$ 个瓶子无法靠第 $m+1$ 个瓶子来拯救。
        
    - 因此，每一处的**前缀平均值**都是一个潜在的“生死线”。
        
- **公式沉淀**：
    
    $$\text{Target} = \min_{s \in [0, k-1]} \left( \min_{m} \left\lfloor \frac{\sum_{j=1}^m \text{group}_{s,j}}{m} \right\rfloor \right)$$
