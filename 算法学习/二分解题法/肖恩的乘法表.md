# 题目描述
用一句话总结题目：在一个 $n \times m$ 的矩阵中，每个位置 $(i, j)$ 的值为 $i \times j$，求所有元素从**小到大**排序后的第 $k$ 个数。  
**输入：** 三个整数 $n, m, k$。  
**输出：** 第 $k$ 小的数值。  
**数据范围：** $n, m \le 5 \times 10^5$，$1 \le k \le n \times m$。  
**评估：** 难度：中等考频：高频必备（二分答案经典题）
# 分析
当你发现直接求“第 $k$ 个数”很难，但判断“某个数 $x$ 是不是第 $k$ 个数”很容易时，就要立刻想到二分。
#### 1. 为什么不能暴力？
$n, m \le 5 \times 10^5$，矩阵总元素有 $2.5 \times 10^{11}$ 个。如果存进数组再排序，内存会爆（需几百GB），时间也会超（排序 $O(NM \log NM)$ 根本跑不完）。
#### 2. 二分答案的逆向思维
我们不去找那个位置，我们去**猜**那个数值。
- 假设第 $k$ 小的数是 $x$。
- 如果矩阵中**小于等于 $x$ 的数**超过或等于 $k$ 个，说明我们要找的答案可能就是 $x$，或者比 $x$ 更小。
- 这个性质是**单调**的：$x$ 越大，小于等于 $x$ 的数肯定越多。
#### 3. 关键的 `check(x)`：如何快速数数？
这是最精妙的地方。在乘法表中，每一行都是某个数的倍数：
- 第一行：$1, 2, 3, \dots, m$
- 第二行：$2, 4, 6, \dots, 2m$
- 第 $i$ 行：$i \times 1, i \times 2, \dots, i \times m$  
我们要找第 $i$ 行有多少个数 $\le x$。  
即找到最大的 $j$，使得 $i \times j \le x \implies j \le x/i$。  
因为每一行只有 $m$ 个数，所以第 $i$ 行符合条件的个数就是 $\min(m, \lfloor x/i \rfloor)$。
## 代码
```python
import sys

# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
k = int(next(it))
if n > m: n, m = m, n # 优化：遍历较小的边

# 2.边界
l, r = 1, n * m
ans = r

# 3.操作 (二分搜索)
while l <= r:
    mid = (l + r) // 2
    
    # 核心：统计 <= mid 的元素个数
    cnt = 0
    for i in range(1, n + 1):
        cnt += min(m, mid // i)
    
    if cnt >= k:
        ans = mid
        r = mid - 1
    else:
        l = mid + 1

# 4.答案
print(ans)
```
