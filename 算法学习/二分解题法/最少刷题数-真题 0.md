# 题目
- **输入**：$N$ 名学生的刷题数数组 $A$。
- **规则**：对每个学生，求至少再刷多少题，使得：**刷题比他多的人数 $\le$ 刷题比他少的人数**。
- **约束**：$N \le 10^5$，刷题数 $\le 10^5$。要求 $O(N \log N)$ 复杂度。
# 分析
将刷题数排序得到 $S$，中位数 $mid = S[n // 2]$ 是天然的平衡点。
- 统计全班原始数据中：严格小于 $mid$ 的人数 $cl$，严格大于 $mid$ 的人数 $cr$。

如果一个学生 $x$ 原本不达标（$比他多 > 比他少$），他需要刷到 $T$。在他刷到 $T$ 后：
- **左侧变化**：他自己从“比 $T$ 少”的池子里消失了。
- **条件转化**：$cr \le cl - 1$，即 $cr < cl$。
- **结论**：
    - 如果 $cr < cl$，目标线 $T = mid$ 即可。
    - 如果 $cr \ge cl$，说明强者太多或持平，目标线必须上移，$T = mid + 1$。

- 排序：$O(n \log n)$。
- 二分查找：利用 `bisect_left` 和 `bisect_right` 快速统计人数，单次 $O(\log n)$。
# 代码

```python
import sys
from bisect import bisect_left,bisect_right

it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]
s= sorted(a)
mid = s[n//2]
l = bisect_left(s,mid)
r = n - bisect_right(s,mid)
t = mid if r < l else mid+1
ans = []
for x in a:
  ll = bisect_left(s,x)
  rr = n - bisect_right(s,x)
  if rr <= ll:
    ans.append(0)
  else:
    ans.append(max(0,t-x))
print(*ans)
```
