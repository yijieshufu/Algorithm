# 题目描述
- **目标**：在长度为 $n$ 的序列中，找一个长度 $\ge k$ 的连续子序列，使其排序后的**中位数最大**。
- **中位数定义**：
    - 长度 $m$ 为奇数：第 $(m+1)/2$ 个数。
    - 长度 $m$ 为偶数：第 $m/2$ 个数。
- **范围**：$n, k \le 10^5$，时间限制要求 $O(n \log n)$。
# 分析
#### 第一步：二分答案的单调性
中位数的值具有单调性：如果存在一个子序列的中位数 $\ge x$，那么一定也存在中位数 $\ge x-1$。因此我们可以通过二分搜索来“猜”中位数的值。
#### 第二步：及格标记法（状态转换）
如何判断是否存在一个长度 $\ge k$ 的子序列，其中位数 $\ge x$？
1. 我们将原序列 $a$ 转换成 $b$：
    - 若 $a_i \ge x$，则 $b_i = 1$；
    - 若 $a_i < x$，则 $b_i = -1$。
2. **关键推导**：
    - 若子序列长度 $m$ 为奇数（$m=2p+1$），中位数为第 $p+1$ 大。此时 $b$ 序列的和 $S \ge (p+1) - p = 1$。
    - 若子序列长度 $m$ 为偶数（$m=2p$），中位数为第 $p$ 大。此时 $b$ 序列的和 $S \ge (p+1) - (p-1) = 2$。
    - 由于区间和 $S$ 的奇偶性与长度 $m$ 一致，只要满足 **$S \ge 1$**（即 $S > 0$），上述两种情况的中位数判定均成立。
#### 第三步：双指针与前缀和优化判定
判定问题转化为：是否存在 $i, j$ 使得 $j - i \ge k$ 且 $S_j - S_i \ge 1$。
1. 计算 $b$ 序列的前缀和 $s$。
2. 固定右端点 $j$，在左侧合法范围 $[0, j-k]$ 内寻找最小的前缀和 $s_i$。
3. 只要 $s_j - \min(s_i) \ge 1$，则该 $x$ 合法。
# 代码
```python
import sys 
it = iter(sys.stdin.read().split())
n = int(next(it))
k = int(next(it))
a = [int(next(it)) for _ in range(n)]

def check(mid):
  s = [0]*(n+1)
  for i in range(n):
    s[i+1] = s[i] + (1 if a[i]>=mid else -1)
  
  min_v = 0
  for j in range(k,n+1):
    min_v = min(min_v,s[j-k])
    if s[j] - min_v >=1: return True
  return False

l,r,ans = 1,max(a),1
while l<=r:
  mid = (l + r ) // 2
  if check(mid):
    ans , l = mid, mid+1
  else:
    r = mid-1
print(ans)
```

# 二分思考

### 1. 第一类：求“满足条件的最大值” (找最后一个 T)
这是最常见的类型（如：最大中位数、最大底线、切绳子）。  
**逻辑：** 越小越容易满足（True），越大越难满足（False）。
- **`check(mid)` 为 True**：说明当前的 `mid` **行**。既然行，那 `mid` 可能是答案，但也可能还有更大的 `mid` 也行。
    - **动作**：记录答案，去右边找更大的。
    - **代码**：`ans = mid; l = mid + 1`
- **`check(mid)` 为 False**：说明当前的 `mid` **不行**。太大了，直接排除。
    - **动作**：去左边找。
    - **代码**：`r = mid - 1`、
### 2. 第二类：求“满足条件的最小值” (找第一个 T)
常见于“最短时间”、“最小花销”（如：管道注水）。 **逻辑：** 越大越容易满足（True），越小越难满足（False）。
- **`check(mid)` 为 True**：说明当前的 `mid` **行**。既然行，那 `mid` 可能是答案，但也可能还有更小的 `mid` 也行。
    - **动作**：记录答案，去左边找更小的。
    - **代码**：`ans = mid; r = mid - 1`
- **`check(mid)` 为 False**：说明当前的 `mid` **不行**。太小了，没法覆盖。
    - **动作**：去右边找。
    - **代码**：`l = mid + 1`
