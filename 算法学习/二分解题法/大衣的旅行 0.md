# 题目描述
在一个 $N \times M$ 的房间矩阵中，每个房间 $(i, j)$ 有固定容量 $A_{i,j}$。  
你需要安排 **1 名老师**和 **$K$ 名学生**入住。
- **目标**：寻找一个最小的半径 $d$，使得至少存在一个房间作为老师的住处，并且以该房间为中心、半径为 $d$ 的范围内，房间总容量之和大于等于 $K+1$。
- **距离定义**：采用切比雪夫距离，即 $d = \max(|i_1 - i_2|, |j_1 - j_2|)$。
- **特殊限制**：老师必须入住一个容量 $A_{i,j} > 0$ 的房间。
- **无解情况**：若全图总容量都不足 $K+1$，输出 $-1$。
# 分析
题目给出的距离公式 $d = \max(|i_1 - i_2|, |j_1 - j_2|)$ 实际上定义了一个**正方形区域**。  
如果老师住在 $(i, j)$，距离他不超过 $d$ 的所有房间构成的矩形范围是：
- **行范围**：$[i-d, i+d]$
- **列范围**：$[j-d, j+d]$  
半径 $d$ 具有明显的**单调性**：
- 如果半径 $d$ 能够容纳所有师生，那么比 $d$ 大的半径一定也能容纳。
- 这符合二分答案的特征。我们可以在 $[0, \max(N, M)]$ 范围内二分猜一个 $d$，然后去验证它是否可行。

在验证某个半径 $d$ 是否可行时，我们需要频繁查询不同正方形区域内的容量总和。如果每次都用循环去累加，复杂度会爆炸。  
**二维前缀和**可以在 $O(1)$ 时间内给出任意矩形区域的和：
- **预处理公式**：  
    $$S[i][j] = A[i][j] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]$$
- **查询左上角 $(r1, c1)$ 到右下角 $(r2, c2)$ 的矩形和**：  
    $$Sum = S[r2][c2] - S[r1-1][c2] - S[r2][c1-1] + S[r1-1][c1-1]$$
# 代码

```python
import sys 
it = iter(sys.stdin.read().split()) 
t = int(next(it))

for _ in range(t):
  n,m,k =int(next(it)),int(next(it)),int(next(it))
  a = [[0]*(m) for _ in range(n)]
  total_sum = 0
  teacher = []
  for i in range(n):
    for j in range(m):
      val = int(next(it))
      total_sum+=val
      a[i][j] = val
 
      if a[i][j] > 0 :
        teacher.append((i,j))
  
  if total_sum < k+1:
    print("-1")
    continue 

  s = [[0]*(m+1) for _ in range(n+1)]
  for i in range(1,n+1):
    for j in range(1,m+1):
      s[i][j] = a[i-1][j-1] + s[i][j-1]+s[i-1][j] - s[i-1][j-1]

  def check(d):
    for  rr , cc in teacher:
      rr +=1 ;cc+=1
      r1 = max(1,rr-d)
      c1 = max(1,cc-d)
      r2 = min(n,rr+d)
      c2 = min(m,cc+d)
      tt_sum = s[r2][c2] - s[r1-1][c2] - s[r2][c1-1] + s[r1-1][c1-1]
      if tt_sum >= k+1:
        return True
    return False
  
  low = 0 ;high = max(n,m)
  ans = -1
  while low <= high:
    mid = (low+high)//2
    if check(mid):
      ans = mid 
      high = mid -1
    else:
      low = mid +1
  print(ans)

```
