# 题目描述
****场景**：有一根长度为 $M$ 的管道（坐标为 $1$ 到 $M$）。管道上有 $N$ 个阀门。  
**参数**：每个阀门 $i$ 位于 $L_i$，$S_i$ 时刻开启。  
**规则**：
- 阀门开启后，水流每秒向左、向右各流动 $1$ 个单位。
- 在时刻 $T$ ($T \ge S_i$)，第 $i$ 个阀门覆盖的区间为：$[L_i - (T - S_i), \ L_i + (T - S_i)]$。
- 所有的坐标超出 $[1, M]$ 的部分可以忽略。  
**目标**：寻找**最小的时刻 $T$**，使得管道的 $[1, M]$ 区域被完全覆盖。
# 分析
- **二分搜索**：
    - 时间范围从 $0$ 到 $2 \times 10^9$。
    - 如果时刻 $T$ 能覆盖全管，则 $T+1$ 必然也能；反之亦然。
- **区间合并 (Check 函数)**：
    - 对于给定的 $T$，收集所有已打开阀门（$S_i \le T$）形成的区间。
    - 将区间按左端点排序。
    - **连续性判定**：从左往右遍历，维护当前能覆盖到的最右端点 `curr`。若下一个区间的左端点 $\le curr + 1$，则说明水流是连续的，更新 `curr = max(curr, 新右端点)`。
- **复杂度**：二分次数为 $\log(2 \times 10^9) \approx 31$ 次，每次 `check` 涉及排序 $O(N \log N)$。总复杂度 $O(31 \cdot N \log N)$，在 $N=10^5$ 规模下稳过。

```python
import os
import sys

# 读入数据
it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it)) 
a = [(int(next(it)),int(next(it))) for _ in range(n)]
# check 函数
def check(t):
  # 计算区间
  q =[]
  for i in range(n):
    l,s=a[i]
    if t>=s:
      d = t-s
      q.append((max(1,l-d),min(m,l+d)))
  if not q:return False
  q.sort() # 排序
  if q[0][0]>1:return False  
  # 裁剪区间
  curr = q[0][1] # 当前的右边界
  for i in range(len(q)):
    if q[i][0]< curr+1:
      curr = max(curr,q[i][1])
    else:
      break
  return curr>=m
# 二分法
l, r, ans = 0, 2000000000, 0
while l<=r:
  mid = (l+r)//2
  if check(mid):
    ans = mid
    r = mid-1
  else:
    l = mid+1
print(ans)
```
