# 题目描述
**【材料】 (Materials)**
- **输入数据**：一个整数 $N$（代表全班学生总数）。
- **核心样本**：一个包含 $N$ 个元素的数组 $A$，记录了每名学生目前的刷题数量。
- **规模参考**：$N$ 和 $刷题量$ 均达到 $10^5$ 级别，提示我们算法必须高效。  
**【条件】 (Constraints)**
- **核心公式**：必须满足：`刷题比我多的人数` $\le$ `刷题比我少的人数`。
- **过滤规则**：刷题量和你**完全相等**的人是“透明人”，不计入统计。
- **性能红线**：禁止 $O(N^2)$ 的双重循环暴力对比，必须在 $O(N \log N)$ 级别内完成。

**【目的】 (Objective)**
- 对于数组中的**每一个**原始学生 $A_i$，计算他为了达标至少需要再刷多少道题。如果他现在已经达标，则输出 0。
## 分析
### 1. 遇到“比我多 vs 比我少” $\rightarrow$ 想到“排序后的中位数”
**逻辑**：要衡量一个人在群体中的排名，最快的方法就是**排序**。
- 一旦我们将数组 $A$ 排序得到 $S$，中位数 $mid\_val = S[N // 2]$ 就成了天然的“分水岭”。
- 我们不再需要和每个人对比，只需要看自己和中位数的关系。
### 2. 遇到“如何确定安全分数” $\rightarrow$ 想到“动态平衡点 $T$”
**逻辑**：这道题最微妙的地方在于，如果你为了达标多刷了题，你可能会把原本和你一样多的人“挤”到比你少的那一侧。
- **分析**：我们需要找一个全局的“及格线” $T$。
- **决策**：
    - 统计严格小于中位数的人数 $L$ 和严格大于的人数 $R$。
    - 如果 $L > R$（弱者多），你只要达到中位数即可，$T = mid\_val$。
    - 如果 $L \le R$（强者多或持平），你必须比中位数多 1 题，$T = mid\_val + 1$。
### 3. 遇到“大量数据快速定位” $\rightarrow$ 想到“二分查找 (bisect)”
**逻辑**：即使排了序，如果对每个学生都去数一遍左右人数，还是太慢。
- **工具**：Python 的 `bisect_left` 和 `bisect_right` 能在 $O(\log N)$ 时间内告诉你某个分数在有序数组中的排名，从而直接算出 $L$ 和 $R$。
## 代码
**`bisect_left` 的逻辑**：它在有序数组 `s` 中寻找 `mid` 应该插入的最左侧位置。  
**`bisect_right` 的逻辑**：它寻找 `mid` 应该插入的最右侧位置（即所有等于 `mid` 的元素之后）。
- **统计小于 $x$ 的个数**：用 `bisect_left(s, x)`。它返回的索引值，恰好就是左边所有比 $x$ 小的元素个数。
- **统计大于 $x$ 的个数**：用 `n - bisect_right(s, x)`。先找到 $x$ 应该呆的最右侧位置，剩下的就是比它大的。
- **统计等于 $x$ 的个数**：用 `bisect_right(s, x) - bisect_left(s, x)`。这能瞬间算出某个值在数组里出现了几次。
```python
import sys
from bisect import bisect_left, bisect_right

# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]

# 2.边界 (预处理排序与基准)
s = sorted(a)
mid = s[n // 2]
cl = bisect_left(s, mid)
cr = n - bisect_right(s, mid)

# 确定全局安全目标 target
t = mid if cl > cr else mid + 1

# 3.操作 (逐人扫描)
ans = []
for x in a:
    l = bisect_left(s, x)
    r = n - bisect_right(s, x)
    # 如果现在就达标
    if r <= l:
        ans.append(0)
    else:
        # 否则必须刷到目标线
        ans.append(max(0, t - x))

# 4.答案
print(*ans)
```
