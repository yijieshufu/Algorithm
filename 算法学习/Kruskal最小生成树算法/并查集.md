# 蓝桥幼儿园
**【材料】 (Materials)**
- **主体**：$N$ 名学生（编号 $1 \sim N$）。
- **核心逻辑**：友谊具有**传递性**。如果 A 和 B 是朋友，B 和 C 是朋友，那么 A 和 C 也是朋友。
- **操作**：
    - `op = 1`：建立连接（Union）。
    - `op = 2`：查询连通性（Find/Connected）。
- **规模**：$N, M \le 2 \times 10^5$。这意味着必须使用 $O(M \alpha(N))$ 级别的算法，暴力搜索会超时。  
**【条件】 (Constraints)**
- 必须能够快速判断两个节点是否在同一个“朋友圈”（连通分量）中。
- 操作是**动态进行的，即一边加边一边查询**。  
**【目的】 (Objective)**
- 对于每一个 `op = 2` 的询问，输出 `YES`（是朋友）或 `NO`（不是朋友）。
## 分析
#### **1. 遇到“朋友的朋友是朋友” $\rightarrow$ 想到“集合归属”**
- 这本质上是维护若干个不相交的集合。每个集合代表一个朋友圈。
- **并（Union）**：将两个朋友圈合并成一个。
- **查（Find）**：判断两个学生是否属于同一个朋友圈（即他们的“根节点”是否相同）。
#### **2. 遇到 $2 \times 10^5$ 的规模 $\rightarrow$ 想到“路径压缩”**
- **路径压缩 (Path Compression)**：在查找根节点的过程中，顺便把路径上的所有节点直接连到根节点上。
- 这可以将树的高度压缩到极低，使得操作几乎达到常数时间。
## 代码

```python
import sys
sys.setrecursionlimit(300000)
it = iter(sys.stdin.read().split())
n,m= int(next(it)),int(next(it))
f = list(range(n+1))
while m :
  m-=1
  op,a,b =int(next(it)),int(next(it)),int(next(it))
  while f[a]!=a:
    f[a]=f[f[a]]
    a = f[a]
  while f[b]!=b:
    f[b]=f[f[b]]
    b = f[b]
  if op ==1:
    f[a]=b
  else:
    print("YES" if a==b else"NO")

```
