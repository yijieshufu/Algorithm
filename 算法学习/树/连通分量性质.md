# 建造国家-真题
**【材料】 (Materials)**
- **基础结构**：$n$ 个城市，$n-1$ 条道路，且保证全连通。
    - **核心结论**：这在图论中定义为一棵**树（Tree）**。
- **资源分布**：共有 $k$ 个警察局，分布在 $k$ 个不同的城市中。
- **安全定义**：每个城市只要能通过剩下的道路到达**任意一个**警察局，就是安全的。
- **规模**：$n, k \le 10^5$。  
**【条件】 (Constraints)**
- **目标**：关闭尽可能多的道路（即删除尽可能多的边）。
- **限制**：删除边后，形成的每一个连通分量（子树）中都**必须至少包含一个警察局**。如果某个分量里没有警察局，那这个分量里的城市就不安全了。  
**【目的】 (Objective)**
- 求出能够关闭的**最大道路数量**。
## 分析
就是想 一个警察局 就是一个连通分量了  
	原本n个点 n-1全不连接  
	现在要k个连通分量  
	直接计算就可以

要得到k个连通分量 : 如何计算呢？  
	**推导过程：**  
	1. 初始状态：一棵树有 $n$ 个点，$n-1$ 条边（此时分量数 $C=1$）。  
	2. 每删掉 **1** 条边，连通分量就增加 **1** 个。  
	3. 目标：让分量数从 $1$ 增加到 $k$，需要增加 $k-1$ 个分量。  
	4. 动作：所以要删掉 $k-1$ 条边。  
	5. 剩余边数 = 初始边数 - 删掉的边数 = $(n-1) - (k-1) = \mathbf{n-k}$。

- **初始边数**：$n - 1$。
- **目标分量数**：$k$（最大化分量数，以最小化保留的边）。
- **保留边数**：根据公式，要有 $k$ 个分量，需要保留 $n - k$ 条边。
- **关闭边数**：总边数 - 保留边数 = $(n - 1) - (n - k) = k - 1$。
