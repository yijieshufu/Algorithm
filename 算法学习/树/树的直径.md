# 串门-树的直径
**【材料】 (Materials)**
- **基础结构**：一棵拥有 $n$ 个节点和 $n-1$ 条边的树。
- **权重**：每条边都有一个边权 $w_i$（代表长度）。
- **行动规则**：
    1. 可以从**任意点**出发。
    2. 必须访问每个节点**至少一次**。
- **规模**：$n \le 10^5$，边权可达 $10^9$（总长度可能超过 $2^{31}-1$，需使用 64 位整数）。  
**【条件】 (Constraints)**
- **必须遍历全员**：这意味着每一条边都必须被跨越。
- **路径连续**：不能跳跃，必须沿边行走。  
**【目的】 (Objective)**
- 寻找访问所有节点所需跨越的**最短总路径长度**。
## 🧠 逻辑分析：为什么和“直径”有关？
如果你需要访问树上的每一个点并最终**回到起点**，那么每一条边都必须“一进一出”，即每条边走两次。此时总长度为：$2 \times \sum w_i$。  
但本题允许你**在任何地方结束**。为了让路径最短，我们希望某些边只走一次，而不必走第二次“回头路”。
1. **观察**：凡是不在“起点到终点的简单路径”上的边，都必须走两次（进去访问子树，然后原路返回）。
2. **结论**：总路径长度 = $2 \times (\text{所有边权之和}) - (\text{起点到终点的距离})$。
3. **最优化**：为了让总长度最小，我们需要减去的“起点到终点的距离”尽可能**大**。而在树上，两个点之间最长的距离被称为**树的直径 (Tree Diameter)**。  
**公式总结：**  
$$\text{最短路径} = 2 \times \sum \text{边权} - \text{树的直径}$$

两次BFS 求直径：  
	第一次找到 从1节点出发 代价最大的a点 记录a  
	第2次 从a点出发 记录 最大的代码 则为直径
## 代码
```python
import sys 
from collections import deque

it = iter(sys.stdin.read().split())
n = int(next(it))
if n ==1:
  print(1)
  sys.exit()
g = [[] for _ in range(n+1)]
m = 0 # 计算边权之和
for _ in range(n-1):
  u,v,w = int(next(it)),int(next(it)),int(next(it))
  g[u].append((v,w))
  g[v].append((u,w))
  m+=w
ans = 0 
#BFS 从 1 号点出发找到代价最大的 a
q = deque([(1,0)])
f = [-1]*(n+1)
f[1]=0 # 初始代价为0 
a,b=1,0 # 记录最远点a
while q:
  u,d=q.popleft()
  if d>b:a,b=u,d #换点 找最远点a
  for v,w in g[u]:
    if f[v]==-1:
      f[v]=d+w #代价
      q.append((v,f[v]))

q = deque([(a,0)])
f = [-1]*(n+1) # 到达某点的距离
f[a] = 0 # 初始代价还是为0 
b = 0 # 计算直径了
while q:
  u,d=q.popleft()
  if d>b: b = d #找最大直径
  for v,w in g[u]:
    if f[v]==-1:
      f[v]=d+w
      q.append((v,f[v]))
ans = 2*m-b
print(ans)
```
