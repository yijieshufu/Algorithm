# 联盟X
- **空间**：$n$ 个村庄（节点），$m$ 条道路（无向边）。
- **定义**：
    - **村子联盟**：即图论中的“连通块”。只要两个村子直接或间接相连，就属于同一个联盟。
    - **生产力**：等于该连通块内村子的数量（即连通块的大小）。
- **规模**：$n, m \le 2 \times 10^4$。这意味着 $O(n + m)$ 的算法（如 BFS、DFS 或并查集）是完美的。
- **输出:** **最小**的生产力是多少？
## 分析
就是计算连通分量的大小  
	求最小值

用这种路径压缩 加 合并后  
	还是可以找到各个节点的连通分量  
	判断条件：`f[i] = i`
## 代码

```python
import sys

it =iter(sys.stdin.read().split())
n,m=int(next(it)),int(next(it))
f = list(range(n+1)) # 初始的时候自己是自己的父亲
sz = [1]*(n+1) # 每个集合的大小

# 路径压缩: 全部都挂到了父亲节点下
def find(x):
  if f[x]!= x: # 如果自己不是自己的父亲
    f[x] = find(f[x])
  return f[x]

for _ in range(m):
  u,v = int(next(it)),int(next(it))
  root_u,root_v = find(u),find(v)
  if root_u != root_v:
    f[root_u] = root_v
    sz[root_v]+=sz[root_u] # 累计集合数量
ans = n+1 # 设置一个最大值
for i in range(1,n+1): # 树是从1 开始的
  if f[i]==i:
    ans = min(ans,sz[i])
print(ans)
```
