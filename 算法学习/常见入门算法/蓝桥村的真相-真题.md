# 题目
### 1. 场景设定
- **人物**：$n$ 名村民围坐成一个**圆圈**（编号 $1$ 到 $n$，且 $n$ 的下一个是 $1$）。
- **身份**：每人只有两种可能的身份：
    - **诚实者**：永远说真话。
    - **说谎者**：永远说假话。
### 2. 核心断言
每一位村民 $i$ 都指着他顺时针方向后面的两位村民（$i+1$ 和 $i+2$）说：
> **“他们两个当中，一个是诚实者，另一个是说谎者。”**
### 3. 逻辑判定规则（关键！）
你需要根据说话者的身份，拆解出背后的真相：
- **如果说话人是“诚实者”**：  
    他之后的那两个人**确实是一个真、一个假**。
    - 组合可能：(真, 假) 或 (假, 真)。
- **如果说话人是“说谎者”**：  
    他说的“一真一假”是**假的**。
    - 组合可能：**全是真话** (真, 真) 或 **全是假话** (假, 假)。
## 分析
### 1. 翻译断言
题目说：村民 $i$ 称“后面两人（$i+1, i+2$）**一真一假**”。  
在二进制逻辑中，“一真一假”等价于**异或结果为 1**。
### 2. 身份对齐（核心公式）
- 如果 $i$ 是**诚实者** ($1$)：现实符合断言 $\rightarrow x_{i+1} \oplus x_{i+2} = 1$。
- 如果 $i$ 是**说谎者** ($0$)：现实违反断言 $\rightarrow x_{i+1} \oplus x_{i+2} = 0$。  
由此发现，无论说话人是谁，其身份值都等于后面两人的异或值：  
$$x_i = x_{i+1} \oplus x_{i+2}$$  
利用异或特性变形，得到**递推公式**：  
$$x_{i+2} = x_i \oplus x_{i+1}$$
## 🔬 暴力分析：四种种子实验
既然第 $i+2$ 个人的身份由前两个人的状态**唯一确定**，那么全村人的排列就取决于**前两个人的“种子”开局**。
### 1. 为什么枚举 4 种方案？
每个人只有 $0$ 或 $1$ 两种可能，两个人的组合只有 $2 \times 2 = 4$ 种。这四种开局覆盖了所有可能的物理现实：
- **方案一**：$(0, 0)$
- **方案二**：$(1, 0)$
- **方案三**：$(0, 1)$
- **方案四**：$(1, 1)$
### 2. 闭环验证（接水管）
因为村民围成圈，我们必须检查推导出的结果在“接头处”是否自洽：
- **操作**：从 $a[0], a[1]$ 开始往后填，填满 $n$ 个人。
- **检查**：计算出的第 $n$ 位（$a[0]$ 的虚像）是否等于 $a[0]$，且第 $n+1$ 位是否等于 $a[1]$。
- **统计**：只有通过检查的方案，才数一数里面有多少个说谎者（$0$）。

## 代码
```python
import sys
it = iter(sys.stdin.read().split())
m = int(next(it)) # 组数

for _ in range(m):
    n = int(next(it))
    ans = 0
    # 枚举 4 种初始状态 (f, g)
    for f in range(2):
        for g in range(2):
            a = [0] * (n + 2)
            a[0], a[1] = f, g
            for b in range(n):
                a[b+2] = a[b] ^ a[b+1]
            # 闭环检查
            if a[n] == a[0] and a[n+1] == a[1]:
                for b in range(n):
                    if a[b] == 0: ans += 1
    print(ans)
```
