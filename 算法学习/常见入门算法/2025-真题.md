
# 题目描述
**目标**：统计 $1 \sim 20250412$ 范围内，满足特定条件的整数个数。  
**核心判定条件**：  
一个数字经过“重排”后能包含 `2025`，本质上是要求该数字的**各数位中**必须**至少**包含以下“零件”：
- **1 个 `0`**
- **2 个 `2`**
- **1 个 `5`**
## 代码

```python
import os
import sys
# 请在此输入您的代码
res =0
for i in range(1,20250413):
  a=str(i)
  a_2=a.count('2')
  if a_2 < 2:continue
  a_0=a.count('0')
  if a_0 < 1 :continue
  a_5=a.count('5')
  if a_5 < 1 :continue
  if a_2 >=2 and a_0 >=1 and a_5 >=1:
    res+=1
print(res)
```
