# 题目
在一个 $n \times m$ 的网格中，寻找有多少对**不同的**格子 $(a, b)$ 和 $(c, d)$，满足：
1. **数值相等**：$A_{a,b} = A_{c,d}$。
2. **对角线关系**：$|a-c| = |b-d| > 0$（即两格在同一条 45 度对角线上，且不是同一个格）。
3. **有序对**：$(1,2)-(2,1)$ 与 $(2,1)-(1,2)$ 视为两对。
## 分析
**暴力思路**：
- 遍历网格中的每一个点作为第一个点 $(a, b)$。
- 再遍历网格中的每一个点作为第二个点 $(c, d)$。
- 检查是否满足：值相等、且在对角线上、且不是同一点。
## 暴力代码 45/100
```python
import os
import sys
it = iter(sys.stdin.read().split())

n = int(next(it))
m = int(next(it))
A = [[int(next(it)) for _ in range(m)] for _ in range(n)]
ans = 0
for a in range(n):
  for b in range(m):
    for c in range(n):
      for d in range(m):
        if a==c and b==d :continue
        if A[a][b]==A[c][d] and abs(a-c)==abs(b-d):
          ans+=1
print(ans)
```
