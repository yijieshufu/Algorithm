# 题目
- **总长度**：$n = 10000$。
- **禁手**：不能出现 `0`。这意味着每个位置只能从 $\{1, 2, 3, 4, 5, 6, 7, 8, 9\}$ 这 **9** 个数字中选择。
- **必选**：必须包含 `3` 和 `7`。
## 分析
我们要找的是“在不含 $0$ 的前提下，同时包含 $3$ 和 $7$”的字符串。  
$$满足条件的 = 总数 - (不含 3 的) - (不含 7 的) + (既不含 3 也不含 7 的)$$
- **总数** (仅排除 $0$)：每个位置有 9 种选法 $\Rightarrow 9^{10000}$
- **不含 $3$** (排除 $0$ 和 $3$)：每个位置有 8 种选法 $\Rightarrow 8^{10000}$
- **不含 $7$** (排除 $0$ 和 $7$)：每个位置有 8 种选法 $\Rightarrow 8^{10000}$
- **既不含 $3$ 也不含 $7$** (排除 $0, 3, 7$)：每个位置有 7 种选法 $\Rightarrow 7^{10000}$  
**最终公式**：  
$$Ans = (9^{10000} - 2 \cdot 8^{10000} + 7^{10000}) \pmod{10^9+7}$$
## 代码
```python
import sys 
mod = 10**9+7
total = pow(9,10000,mod)
a =  pow(8,10000,mod)
b =  pow(7,10000,mod)
print((total-2*a+b)%mod)
```
