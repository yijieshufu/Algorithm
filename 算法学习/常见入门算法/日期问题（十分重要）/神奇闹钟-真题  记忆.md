# 题目
### 1. 故事背景
小蓝发现了一个非常准时的“神奇闹钟”。它像一把刻度极其精准的尺子，铺在了从 **1970年1月1日 00:00:00**（时间原点）开始的时间轴上。
### 2. 闹钟规则
- **响铃起点**：1970-01-01 00:00:00（它响了第一声）。
- **响铃频率**：每经过 **$x$ 分钟**，闹钟就会准时触发一次。
- **数学本质**：所有的响铃时间点，都必须是离原点 **$x$ 分钟的整数倍**。
### 3. 你的任务
小蓝会给你一个具体的时间点 **$T$**（比如 `2026-03-16 15:20:43`），你需要帮他找到：
> 在时间轴上，**紧贴在 $T$ 左侧（过去）** 或者 **刚好就在 $T$ 这一点**的那个闹钟时刻。
## 代码
```python
import sys
from datetime import datetime, timedelta

# 读入规范
it = iter(sys.stdin.read().split())

# 1.变量
n = int(next(it)) # 组数
b = datetime(1970, 1, 1) # 基准原点
ans = ""

# 3.操作
for _ in range(n):
    # 合并读入日期和时间字符串
    a = datetime.strptime(next(it) + " " + next(it), "%Y-%m-%d %H:%M:%S")
    m = int(next(it)) # 间隔 x 分钟
    
    # f: 计算当前时间距离原点的总秒数
    f = int((a - b).total_seconds())
    # g: 闹钟间隔的总秒数
    g = m * 60
    
    # 核心对齐逻辑：整除抹零，回到最近的整倍数刻度
    f = (f // g) * g
    
    # ans: 将秒数加回原点，并格式化输出
    ans = (b + timedelta(seconds=f)).strftime("%Y-%m-%d %H:%M:%S")
    
    # 4.答案
    print(ans)
```
