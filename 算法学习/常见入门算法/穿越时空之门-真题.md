# 题目
我们要找的是满足以下条件的 $n \in [1, 2024]$：  
$$S_2(n) = S_4(n)$$
- **$S_2(n)$**：$n$ 的二进制各位数之和（实际上就是 $n$ 的二进制中 $1$ 的个数）。
- **$S_4(n)$**：$n$ 的四进制各位数之和。

这是一个非常有趣的数学现象。因为 $4 = 2^2$，所以**四进制的每一位正好对应二进制的两位**：
- 四进制 `0` $\to$ 二进制 `00`（和：$0 = 0$ ✅）
- 四进制 `1` $\to$ 二进制 `01`（和：$1 = 1$ ✅）
- 四进制 `2` $\to$ 二进制 `10`（和：$1 \neq 2$ ❌）
- 四进制 `3` $\to$ 二进制 `11`（和：$2 \neq 3$ ❌）  
**结论**：要让 $S_2(n) = S_4(n)$，这个数的**四进制表示中只能包含数字 `0` 和 `1`**。
## 代码

```python
import sys
# 1.变量
ans = 0
# 3.操作
for i in range(1, 2025):
    # 计算二进制数位和
    a = bin(i).count('1')
    # 计算四进制数位和
    b = 0
    t = i
    while t:
        b += t % 4
        t //= 4
    # 判定
    if a == b:
        ans += 1
# 4.答案
print(ans)
```
