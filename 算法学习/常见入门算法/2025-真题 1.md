
# 题目描述
**目标**：统计 $1 \sim 20250412$ 范围内，满足特定条件的整数个数。  
**核心判定条件**：  
一个数字经过“重排”后能包含 `2025`，本质上是要求该数字的**各数位中**必须**至少**包含以下“零件”：
- **1 个 `0`**
- **2 个 `2`**
- **1 个 `5`**
## 代码

```python
import sys 
ans  = 0
for i in range(1,20250412+1):
  s = str(i)
  zeros = s.count('0') 
  twos = s.count('2') 
  fives = s.count('5') 
  if zeros >=1 and twos>=2 and fives>=1:
    ans+=1
print(ans)
```
