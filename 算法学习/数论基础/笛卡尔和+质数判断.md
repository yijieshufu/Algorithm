# 魔法科考试-真题
- **口诀组合**：有 $n$ 个上半部分口诀 $a_i$ 和 $m$ 个下半部分口诀 $b_j$。
- **合成规则**：完整口诀 $S = a_i + b_j$。
- **有效条件**：
    1. $S \le n + m$（和的上限）。
    2. $S$ 必须是**质数**。
- **目标**：统计一共有多少种**不同**的有效口诀值 $S$。
# 分析过程

## 代码

```python
import os
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
a_set = {int(next(it)) for _ in range(n)}
b_set = {int(next(it)) for _ in range(m)}

# 质数判断
limit = 40000
is_prime = [True] * (limit + 1)
is_prime[0]=is_prime[1] = False # 1 不是质数
for i in range(2,int(limit**0.5) + 1):
  if is_prime[i]:
    for j in range (i*i,limit+1,i):
      is_prime[j]=False

# 计算 a + b 笛卡尔积之和
bits_b = 0
for x in b_set:
  bits_b |=(1 << x)
sum = 0 
for x in a_set:
  sum |=(bits_b << x )

res = 0
for p in range(2,m+n+1):
  if is_prime[p]: # 判断p是否是质数
    if (sum>>p&1): # p 是否是 a+b 的和
      res+=1
print(res)
```
