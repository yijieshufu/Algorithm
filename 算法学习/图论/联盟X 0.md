# 联盟X ：连通分量的大小  
- **空间**：$n$ 个村庄（节点），$m$ 条道路（无向边）。
- **定义**：
    - **村子联盟**：即图论中的“连通块”。只要两个村子直接或间接相连，就属于同一个联盟。
    - **生产力**：等于该连通块内村子的数量（即连通块的大小）。
- **规模**：$n, m \le 2 \times 10^4$。这意味着 $O(n + m)$ 的算法（如 BFS、DFS 或并查集）是完美的。
- **输出:** **最小**的生产力是多少？
## 分析
就是计算连通分量的大小  
	求最小值

用这种路径压缩 加 合并后  
	还是可以找到各个节点的连通分量  
	判断条件：`f[i] = i`
## 代码

```python
import sys

it = iter(sys.stdin.read().split())
n,m = int(next(it)),int(next(it))
f = list(range(n+1)) # 初始化 父数组
sz = [1]*(n+1) # 连通集合的大小

# 节点直接挂在 父节点下
def find(x):
  if f[x] != x:
    f[x] = find(f[x])
  return f[x]

# 边的关系
for _ in range(m):
  u,v = int(next(it)) ,int(next(it))
  root_u,root_v  = find(u),find(v)
  if root_u !=root_v: # 挂在新的root_V 下
    f[root_u] = root_v
    sz[root_v] += sz[root_u]

ans = n+1 # 求最小值 设置最大值
for i in range(1,n+1):
  if f[i] == i : # 找到连通集合了
    ans = min(ans,sz[i])
print(ans)
```
