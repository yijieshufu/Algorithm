# 串门-树的直径
你有一棵**树**（n 个节点，n-1 条边，没有环，任意两点之间只有一条路）
- 每条边有一个长度（权重）
- 要求：**从任意点出发，走遍树上所有节点至少一次，路径连续不能跳**
- 求：**走完所有节点的最短总路程**
### 关键限制
1. 必须访问**每一个节点**
2. 必须沿着边走，不能瞬移
3. 起点随便选，终点也随便选
4. 数据规模很大：n ≤ 10⁵，必须用高效算法
# 核心分析

- **回到原点的遍历**：若要求访问所有节点并返回起点，每一条边都必须“进去”再“出来”，即每条边至少走两次。此时总路程为 $2 \times \sum W$。

- **不回头的优化**：如果起点和终点可以不同，我们可以选择一条路径 $A \to B$，这条路径上的边只需要走 **1次**。为了使总路程最短，我们要让这部分只走一次的路程尽可能长。
    
- **结论**：树上最长的简单路径即为**树的直径**（Diameter）。
    - **最短路程** = $2 \times (\text{所有边权之和}) - \text{树的直径}$。
- **解题步骤**：
    - 累加所有边权得到 $s$。
    - 通过两遍 BFS 找到树的直径 $L$。
    - 计算 $2s - L$。
## 代码
```python
import os
import sys

it = iter(sys.stdin.read().split())
n = int(next(it))

if n ==1:
  print(0)
  sys.exit()

g = [[] for _ in range(n+1)]
s = 0
for _ in range(n-1):
  u,v,w = int(next(it)),int(next(it)),int(next(it))
  g[u].append((v,w));g[v].append((u,w))
  s+=w  # 顺便累加总的权重

def bfs(start):
  dist = [-1] * (n+1)
  dist[start] = 0
  q = [start]
  p = start
  for u in q:
    if dist[u] > dist[p]: # 只需要记录距离最大的左边就可以
      p = u
    for v,w in g[u]:
      if dist[v] ==-1:
        dist[v] = dist[u]+w
        q.append(v)
  return p,dist[p]
p1,_ = bfs(1)
p2,diameter = bfs(p1)
print(2*s - diameter)

```
