# 题目
$n$ 个城市，$n-1$ 条边（一棵树）。  
要在城市中部署三组哨兵 $A, B, C$。 要求：$dist(A, B) = dist(A, C)$。  
目标：最大化 $dist(B, C)$。
# 分析

- **等价条件转化**：$B$ 到 $C$ 的距离最大。在树上，两点间的最长路径就是**树的直径**。
- **核心观察**：
    - 若 $B, C$ 是树的直径的两个端点，只要存在一个点 $A$ 到它们的距离相等，那么直径长度就是答案。
        
    - 在树中，任意两点 $B, C$ 之间存在唯一的简单路径。若存在点 $A$ 满足 $dist(A, B) = dist(A, C)$，意味着 $A$ 到路径 $B-C$ 的**中点**（或中边）的距离是对称的。
        
    - 更简单地：只要 $dist(B, C)$ 是**偶数**，我们一定能找到中点作为 $A$；如果 $dist(B, C)$ 是**奇数**，我们需要 $A$ 跨过中边保持对称。
        
    - **实际上**，在树中，对于**任意**两个点 $B, C$，总能找到一个点 $A$（最极端的情况是 $A$ 就在 $B, C$ 路径的中点处，或者 $A=B=C$ 距离为0）。但注意题目要求 $A, B, C$ 是城市，所以只要 $dist(B, C)$ 是**偶数**，答案就是直径长度。
        
- **结论**：题目本质上是求树上最长的**偶数距离**。如果直径是偶数，答案就是直径；如果直径是奇数，答案则是次长偶数路径，或者直径减1。
# 代码

```python
import os
import sys

sys.setrecursionlimit(200000)
it = iter(sys.stdin.read().split())
n = int(next(it))

# 构建邻接表
g = [[] for _ in range(n+1)]
for _ in range(n-1):
  u,v = int(next(it)),int(next(it))
  g[u].append(v);g[v].append(u)

def bfs(s):
  d = [-1] * (n+1)
  d[s] = 0
  q = [s]
  best_u = s
  for u in q :
    if d[u] > d[best_u]:
      best_u = u
    for v in g[u]:
      if d[v] == -1:
        d[v] = d[u]+1
        q.append(v)
  
  return d[best_u] , best_u

_,p1 = bfs(1)
L,p2 = bfs(p1)

if L % 2 ==0:
  print(L)
else:
  print(L-1)
```
