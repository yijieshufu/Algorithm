# 建造国家-真题
有 `n` 个城市、`n-1` 条路且全连通，所以图是一棵树。  
其中有 `k` 个城市有警察局。  
你可以关闭一些道路，要求关闭后：  
每个城市都还能到达至少一个警察局（等价于：每个连通块至少有一个警察局）。  
求最多能关闭多少条路。
# 分析
设关闭了 `x` 条边。
- 树初始有 1 个连通块。
- 每删 1 条边，连通块数 `+1`。
- 所以删完后连通块数是 `x + 1`。
- 每个连通块至少要有 1 个警察局，而总警察局数是 `k`，所以连通块数最多 `k`。

因此： `x + 1 <= k`  
`x <= k - 1`

这是上界。

再看可行性：这个上界一定能达到（总能构造删掉 `k-1` 条边且每块有警察局），所以最大值就是：

`ans = k - 1`

import sys
