#### **基础版本 (Base Version)**
只是单纯地顺着父节点往上爬，直到找到根节点。
```python
def find(x):
    # 如果我不是掌门人，就问我爹
    if f[x] == x:
        return x
    return find(f[x])
```

#### **路径压缩版本 (Path Compression)**
在找掌门人的过程中，顺便把路上遇到的所有人全部直接挂在掌门人名下。
```python
def find(x):
    # 如果我不是掌门人，一边问我爹，一边把问到的结果直接变成我爹
    if f[x] != x:
        f[x] = find(f[x]) # 核心：路径压缩
    return f[x]
```

|**维度**|**基础版本 (Base)**|**路径压缩 (Path Compression)**|
|---|---|---|
|**搜索形态**|**线性爬坡**。可能形成很长的链。|**扁平化**。树的高度被极度压缩。|
|**最坏复杂度**|**$O(n)$**。如果合并成了长链，速度极慢。|**几乎 $O(1)$**。均摊复杂度为 $\alpha(n)$。|
|**结构影响**|保持原始的合并顺序，树可能很深。|**破坏原始结构**，使所有点直接指向根。|
|**竞赛评价**|**绝对红线**。在大规模数据下必 TLE。|**标准操作**。竞赛中的唯一选择。|
