## 2543.判断一个点是否可以到达
在一个无穷大的网格图中，你初始位于点 $(1, 1)$。每一秒，你可以从当前点 $(x, y)$ 移动到以下四个点之一：
1. $(x, y - x)$
2. $(x - y, y)$
3. $(2x, y)$
4. $(x, 2y)$  
给定目标点 $(targetX, targetY)$，请判断是否能从 $(1, 1)$ 出发到达该点。
## 分析
**性质一：辗转相减法的不变性**  
前两种移动 $(x, y-x)$ 和 $(x-y, y)$ 是 **欧几里得算法（辗转相减法）** 的标准操作。  
根据性质：$\gcd(x, y) = \gcd(x, y-x) = \gcd(x-y, y)$。  
这意味着，这两步操作**永远不会改变**两个坐标的**最大公约数**。  
**性质二：倍增操作的局限性**  
后两种移动 $(2x, y)$ 和 $(x, 2y)$ 会将其中一个坐标翻倍。  
这会导致新的 $\gcd$ 可能保持不变，或者**引入 2 的质因子**。  
例如：$\gcd(3, 3)=3 \to \gcd(6, 3)=3 \to \gcd(6, 6)=6$。  
**结论推导：**
- 我们从 $(1, 1)$ 出发，初始 $\gcd(1, 1) = 1$。
- 所有的操作只能让 $\gcd$ 保持不变，或者乘上 2。
- 因此，如果我们能到达 $(targetX, targetY)$，那么它们的最大公约数 $g = \gcd(targetX, targetY)$ 必须是 **2 的幂次**（即 $g = 2^k, k \ge 0$）。
## 代码
```python
class Solution:
    def isReachable(self, targetX: int, targetY: int) -> bool:
        g = math.gcd(targetX,targetY) # 求最大公约数
        return  (g & (g-1)) == 0 # 判断是否是 2 的幂次
```
