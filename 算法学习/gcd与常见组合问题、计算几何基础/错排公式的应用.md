# 糊涂人寄信
有 $n$ 封信和 $n$ 个信封，每一封信都有一个正确对应的信封。

现在要求**每一封信都装错**（即信封 $A$ 里面绝对不能装信 $A$），求出这种“全装错”的情况总共有多少种。

# 分析过程
[[错排计算公式]]

```python
import os
import sys
# 请在此输入您的代码
it = iter(sys.stdin.read().split())
for val in it:
  n = int(val)
  d = [0] * 21
  d[1]=0;d[2]=1
  for i in range(3,n+1):
    d[i]=(i-1)*(d[i-1]+d[i-2])
  print(d[n])
```
