# 题目
- 给定 $N$ 个不一定有序的整数，它们属于某个等差数列。
- 求包含这 $N$ 个整数的最短等差数列的**项数**。
- 数据范围：$N \le 10^5$，$A_i \le 10^9$。
# 分析
1. **排序**：首先对输入的 $N$ 个数进行升序排序，确定数列的边界 $min = a[0]$，$max = a[n-1]$。
2. **找公差**：
    - 计算所有相邻项的差值：$diff_1 = a[1]-a[0], diff_2 = a[2]-a[1], \dots$。
    - 这组数的最优公差 $d$ 就是这些差值的**最大公约数**。
    - **特殊情况**：如果 $d=0$（即所有数字都相同），最短项数就是 $N$。
3. **计算结果**：项数 $ans = \frac{a[n-1] - a[0]}{d} + 1$。
# 代码
```python
import os
import sys
import math


it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(x) for x in it]
a.sort()
d = 0

for i in range(1,n):
  d = math.gcd(d,a[i] - a[i-1])

if d ==0:
  print(n)
else:
  ans = (a[n-1]-a[0]) // d +1
  print(ans)

```
