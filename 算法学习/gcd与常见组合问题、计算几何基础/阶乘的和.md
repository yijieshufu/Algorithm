# 题目
**1. 核心条件**：
- **输入**：$n$ 个整数 $A_i$。
- **定义**：$\sum_{i=1}^n (A_i!)$ 是指这 $n$ 个数的阶乘之和。
- **目标**：找到最大的整数 $m$，使得 $m!$ 能够整除这个和。

**2. 数据规模**：
- $n \le 10^5$，但 $A_i$ 可以高达 $10^9$。这意味着我们不能**构建数组**，必须使用**字典（映射）** 来处理。
## 分析
### 1. 核心逻辑：阶乘的“进位制”
在普通的十进制中，10个 $1$ 进位成1个 $10$。而在阶乘的世界里，进位的规则是动态变化的：
- **$2$ 个 $1!$** 可以进位成 **$1$ 个 $2!$** （因为 $2 \times 1! = 2!$）
- **$3$ 个 $2!$** 可以进位成 **$1$ 个 $3!$** （因为 $3 \times 2! = 3!$）
- **$x+1$ 个 $x!$** 可以进位成 **$1$ 个 $(x+1)!$**  
**结论**：只要低阶阶乘的数量足够多，它们就能不断“合体”变成高阶阶乘。
### ## 2. 深度拆解 $\sum A_i!$
我们不需要计算 $\sum A_i!$ 的具体数值，而是要看这个“总和”最高能被转化为什么级别的阶乘。
1. **记录账本 (f)**：统计每个 $A_i$ 出现的次数。比如输入 `2 2 2 3 3 3`，账本就是 `{2: 3, 3: 3}`。
2. **从小到大扫描**：从最小的阶乘（比如 $g=2$）开始处理。
3. **尝试进位**：
    - 看账本里 $2!$ 有几个？有 3 个。
    - 检查 $3$ 能否被 $(2+1)$ 整除？可以。
    - **等值替换**：$3 \times 2!$ 变成了 $1 \times 3!$。
    - **更新账本**：把新生成的 $1$ 个 $3!$ 加到原来的 $3$ 个 $3!$ 上，现在账本变成 `{3: 4}`。
4. **寻找瓶颈**：当 $g=3$ 时，有 4 个 $3!$。检查 $4$ 能否被 $(3+1)$ 整除？可以，变成 1 个 $4!$。
### ## 3. 为什么这个 $m$ 是最大的？
当你在某个等级 $g$ 停下来（即 `f[g] % (g+1) != 0`）时：
- 这意味着你手里的 $g!$ 数量凑不够 $(g+1)$ 个。
- 剩下的这些 $g!$ 无论如何也变不成 $(g+1)!$。
- 因为 $(g+1)!$ 是 $g!$ 的 $(g+1)$ 倍，如果余数不为零，那么总和 $\sum A_i!$ 绝对无法被 $(g+1)!$ 整除。
- **所以，当前的 $g$ 就是你能达到的极限 $m$。**
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]
f = {}
for g in a: # 记录里面 每个g的频次
	f[g]=f.get(g,0)+1

g = min(f.keys()) # 最小g开始

while g in f:
	if f[g]%(g+1) ==0:# 达到合并条件
		f[g+1] = f.get(g+1,0)+f[g]//(g+1) # 加入下一个数量
		g+=1 # 开始下一个
	else:
		break
print(g)
```
