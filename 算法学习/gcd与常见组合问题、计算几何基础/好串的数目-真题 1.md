# 题目
- **阶梯串**：相邻数字满足 $s[i+1] = s[i]$ 或 $s[i+1] = s[i] + 1$。
- **好串**：长度为 1 的串；或者能切成两个连续阶梯串的串。
- **目标**：给定字符串，求好串总数。
- **范围**：$n=10^5$，要求 $O(n)$。
# 分析
- **预处理 `f[i]`（阶梯串的终点）**：  
    我们需要知道从任意位置 $i$ 开始，**最长**的阶梯串能走到哪里。
    - 如果 $s[i]$ 和 $s[i+1]$ 满足阶梯条件，那么从 $i$ 开始的终点就是从 $i+1$ 开始的终点。
    - 如果不满足，终点就是它自己。
    - 这一步通过**倒序遍历**实现，时间 $O(n)$。
- **组合计数逻辑**：  
    对于每一个起始点 $l$：
    - **第一段**：它能延伸出的第一个最长阶梯串终点是 $i = f[l]$。
    - **第二段**：紧接着第一段之后的那个点 $i+1$，它能延伸出的最长阶梯串终点是 $j = f[i+1]$。
    - **结论**：由于“好串”定义为最多两段阶梯串，那么从 $l$ 开始，到 $l, l+1, \dots, j$ 为止的所有子串都是好串。
    - **数量**：以 $l$ 为起点的子串个数就是 $j - l + 1$。
# 代码

```python
import os
import sys
it = iter(sys.stdin.read().split())
s = next(it)
n = len(s)
a = [int(x) for x in s]

f = [0] * n
f[n-1] = n-1 
for i in range(n-2,-1,-1):
  f[i] = f[i+1] if a[i+1] == a[i] or a[i+1] ==a[i] + 1 else i 
ans = 0

for l in range(n):
  i = f[l]
  j = f[i+1] if i < n-1 else i 
  ans += j-l+1 
print(ans)
```
