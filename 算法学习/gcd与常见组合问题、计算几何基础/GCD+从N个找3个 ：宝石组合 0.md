# 宝石组合
在森林里有 $N$ 枚宝石，第 $i$ 枚宝石的“闪亮度”为 $H_i$。小蓝需要从中选出三枚宝石，其组合的“精美程度” $S$ 由以下公式计算：  
$$S = H_a H_b H_c \cdot \frac{\text{LCM}(H_a, H_b, H_c)}{\text{LCM}(H_a, H_b) \cdot \text{LCM}(H_a, H_c) \cdot \text{LCM}(H_b, H_c)}$$  
目标是找到使 $S$ **最大化**的三枚宝石。若 $S$ 相同，则选择三者升序排列后**字典序最小**的方案。
# 分析
[[GCD知识的本质]]

[[宝石组合复杂公式的化简]]  
这个复杂的公式其实可以简化为一个非常简洁的形式。  
利用性质 $\text{LCM}(x, y) = \frac{xy}{\text{GCD}(x, y)}$ 以及三元素的 LCM 公式，经过代数化简可得：  
也就是说，**精美程度 $S$ 就是三枚宝石闪亮度的最大公约数。**

**解题步骤：**
- 我们假设这 3 个数的 GCD 是 $g$。
- 那么这 3 个数一定都是 $g$ 的倍数（比如 $g, 2g, 3g, 10g \dots$）。
- 如果我们在原始的宝石堆里，能找到**至少 3 个**数都是 $g$ 的倍数，那么这个 $g$ 就是“合法的”。
- 我们从大到小去试 $g$，第一个试成功的 $g$，就是我们要找的最大 $S$！
# 代码

```python
import sys
it = iter(sys.stdin.read().split())

# ========== 1. 输入与初始化 ==========
n = int(next(it))
a = [int(next(it)) for _ in range(n)]
m = max(a)                    # 最大可能的GCD
f = [0] * (m + 1)             # 频率数组，f[x]表示x出现了几次
ans = []

# ========== 2. 统计频率 ==========
for b in a:
    f[b] += 1

# ========== 3. 核心：从大到小枚举GCD ==========
for g in range(m, 0, -1):     # 从大到小枚举！
    a = []                    # 收集g的倍数
    # 从小到大遍历g的倍数（保证字典序最小）
    for b in range(g, m + 1, g):
        if f[b] > 0:          # 这个倍数存在
            # 取min(f[b], 还需个数)：一个数可能出现多次
            for _ in range(min(f[b], 3 - len(a))):
                a.append(b)
        if len(a) >= 3:       # 找到3个了，停止
            break
    
    if len(a) >= 3:           # 成功找到3个g的倍数
        ans = sorted(a)       # 升序排列
        break                 # 第一个找到的就是最大的S！

# ========== 4. 输出 ==========
print(*(ans))
```
