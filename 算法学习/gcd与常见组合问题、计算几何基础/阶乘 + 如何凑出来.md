# 阶乘的和
给定 $n$ 个正整数 $A_1, A_2, \dots, A_n$。  
你需要找到一个最大的整数 $m$，使得 $m!$ 能够整除这 $n$ 个数阶乘的和，即：  
$$m! \mid \sum_{i=1}^{n} (A_i!)$$
## 分析
阶乘的一个核心性质：  
$$(x+1)! = (x+1) \times x!$$

假设我们有 $k$ 个 $x!$ 相加。
- 如果 $k$ 恰好是 $x+1$ 的倍数，那么我们可以把它们合并：  
    $$(x+1) \cdot x! = (x+1)!$$
- 推广一下：如果有 $cnt$ 个 $x!$，且 $cnt \pmod{x+1} == 0$，那么我们可以形成 $\frac{cnt}{x+1}$ 个 $(x+1)!$。

**解题步骤**
- **统计频率**：用一个哈希表 {}
- **从小到大扫描**：从最小的 $A_i$ 开始。
- **尝试合并**：对于当前的数字 $x$，如果它的数量 `count[x]` 能被 $x+1$ 整除，说明它可以全部转化为更高一级的阶乘。
- **停止条件**：一旦 `count[x]` 不能被 $x+1$ 整除，说明 $m!$ 最高只能到 $x$（或者更准确地说，是 $x$ 之后的余数无法凑成更高的阶乘了）。
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]
f = {}
# 计算频次
for x in a :
  f[x] = f.get(x,0)+1
# 最小的开始
g = min(f.keys()) 
while g in f:
  if f[g] %(g+1) == 0:
    f[g+1] = f.get(g+1,0) + f[g] // (g+1) 
    g+=1
  else:break
print(g)
```
