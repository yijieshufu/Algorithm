# 题目描述
- **定义**：对于排列 $A=(a_1, \dots, a_n)$，其“价值”等于所有满足 $j < i$ 且 $a_j < a_i$ 的二元组 $(j, i)$ 的数量（即顺序对的数量）。
- **任务**：给定 $n$，求 $1$ 至 $n$ 的所有全排列的价值之和。
- **注意**：结果对 $998244353$ 取模。
# 思路分析
1. **单排列价值**：排列的价值即为该排列中**顺序对**的总数。
2. **对称性原理**：
    - 在一个排列中，任意一对位置 $(j, i)$ ($j < i$)，要么是顺序对 ($a_j < a_i$)，要么是逆序对 ($a_j > a_i$)。
    - 总位置对数为 $C_n^2 = \frac{n(n-1)}{2}$。
    - 在所有 $n!$ 个排列中，由于对称性，任何一个位置对作为“顺序对”出现的次数正好是 全排列总数的一半，即 $\frac{n!}{2}$（当 $n \ge 2$ 时）。
3. **最终公式**：  
    $$\text{Total Sum} = \text{位置对数} \times \text{每个位置对贡献的次数}$$  
    $$\text{Total Sum} = \frac{n(n-1)}{2} \times \frac{n!}{2} = \frac{n(n-1) \cdot n!}{4} \pmod{998244353}$$
$$

\text{总价值} = \frac{n(n-1)}{2} \times \frac{n!}{2}

$$
## 代码

```python
import os
import sys
it =iter(sys.stdin.read().split())
n = int(next(it))
MOD = 998244353
if n < 2:
    print(0)   
f = [0] * (n + 1)
f[1]=1
for i in range(2,n+1):
  if i == 2:  # 先除去2
    f[i]=f[i-1]
  else:
    f[i]=f[i-1]*i % MOD
ans = (n * (n-1) // 2 * f[n] )%MOD
print(ans)
```
