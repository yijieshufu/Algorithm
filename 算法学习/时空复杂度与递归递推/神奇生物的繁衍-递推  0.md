# 题目描述

- **规则**：出生满 5 年成年，成年后每年年初生 1 只，长生不老。
- **初始**：第 0 年有 1 只幼年生物。
- **任务**：求 $n$ 年后的生物总数 $\pmod{10^9 + 7}$。
# 分析
我们要推导第 $i$ 年的总数 $dp[i]$：
1. **存量（继承）**：去年的生物今年还在，即 $dp[i-1]$。
2. **增量（出生）**：今年新出生多少只？
    - 只有**成年**的才能生。
    - 谁在今年（第 $i$ 年）成年了？是第 $i-5$ 年 及 以前出生的所有生物。
    - 第 $i-5$ 年的所有生物，到了第 $i$ 年刚好都满 5 岁（或以上），全部变为成年。
    - 所以：**今年新出生的数量 = 第 $i-5$ 年的总数**。  
**状态转移方程：**  
$$dp[i] = dp[i-1] + dp[i-5]$$
## 代码

```python
import os
import sys

# 请在此输入您的代码
it =iter(sys.stdin.read().split())
n=int(next(it))
mod = 10**9+7
dp = [0]*(n+2)
for i in range(1,n+2):
  if i <= 5:
    dp[i]=1
  else:
    dp[i]=(dp[i-1]+dp[i-5])%mod
print(dp[n+1])
```
