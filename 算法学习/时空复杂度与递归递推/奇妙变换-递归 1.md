## 题目简述：递归函数求值

**定义**：$f(x) = \begin{cases} 2 \times x \times f(x-6) & (x > 10) \\ x \times (x - 1) & (x \leq 10) \end{cases}$

**任务**：输入 $n$ ($1 \le n \le 10^5$)，输出 $f(n) \pmod{998244353}$。

**样例**：输入 `15` $\to$ 输出 `2160`。

递归
```python
import os
import sys
sys.setrecursionlimit(1000000)
# 请在此输入您的代码

it = iter(sys.stdin.read().split())
n = int(next(it))
mod = 998244353

def f(x):
  if x>10:
    return 2*x*f(x-6) % mod 
  else:
    return x*(x-1) % mod
print(f(n) % mod)
```
