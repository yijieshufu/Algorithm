# 题目
在 $N \times N$ 的点阵上，选取 4 个点组成一个正方形（允许倾斜），求总共有多少种不同的取法。结果对 $10^9 + 7$ 取模。  
![[Pasted image 20260406204151.png]]  
输入：一个整数 $N$ ($2 \le N \le 10^6$)。

# 分析
这道题的本质是 **“通过外接正方形统计所有正方形”**。
1. **外接正方形（Bounding Box）**：  
    每一个正方形（无论是否倾斜）都必然嵌套在一个边长为 $k$ 的“水平正方形”内，且其四个顶点恰好在边长为 $k$ 的水平正方形的四条边上。
2. **内接正方形个数**：  
    对于一个固定的边长为 $k$ 的水平区域，内部可以构造出恰好 $k$ 个不同的正方形（1 个水平的，$k-1$ 个倾斜的）。
3. **全局统计**：
    - 在 $N \times N$ 的点阵中，边长为 $k$ 的水平正方形区域共有 $(N-k) \times (N-k)$ 个。
    - 总数 $ans = \sum_{k=1}^{N-1} k \cdot (N-k)^2$。

# 代码

```python
import sys
import sys

# 1. 读入
it = iter(sys.stdin.read().split())
n = int(next(it))
mod = 10**9 + 7
ans = 0
for k in range(1, n):
    ans = (ans + k * (n - k) * (n - k)) % mod
print(ans)
```
