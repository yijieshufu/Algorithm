# 题目
- **目标**：将 $N$ 个圆盘从 A 杆借助 B 杆移动到 C 杆。
- **规则**：一次只能动一个；大不能压小。
- **任务**：
    1. 输出第 $M$ 步的具体操作（格式：`#编号: 源->目`）。
    2. 输出完成 $N$ 层汉诺塔的总最少步数。

# 分析
汉诺塔的递归只有三行逻辑，你要在脑子里把它抽象成**三步动作**：
1. **打包挪开**：把上面的 $n-1$ 个盘子看作一个整体，从 `A` 搬到 `B`（借助 `C`）。
2. **正主归位**：把最底下的第 $n$ 个盘子（最大的那个），从 `A` 直接搬到 `C`。这是**唯一**确定的物理动作，也是我们计数 `cnt` 的时刻。
3. **打包归位**：把刚才留在 `B` 的那 $n-1$ 个盘子整体，从 `B` 搬到 `C`（借助 `A`）。  
**数学必杀技**：  
完成 $n$ 层汉诺塔的总步数 $ans$ 严格等于 $2^n - 1$。在 Python 中利用位运算 `(1 << n) - 1` 可以 $O(1)$ 瞬杀，不需要在递归里累加。
# 代码
```python
import os
import sys

# 请在此输入您的代码
it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
cnt = 0

def f(n,a,b,c):
  global cnt 
  if n ==0: return 
  # 第一步 ，把n-1 从 a 移到 b
  f(n-1,a,c,b)
  # 第二步：移到 第 n 个
  cnt +=1
  if cnt == m:
    print(f"#{n}: {a}->{c}")
  # 第三步：把 b上的 n-1 个 移到 c
  f(n-1,b,a,c)

f(n,"A","B","C")
print((1<<n)-1)

```
