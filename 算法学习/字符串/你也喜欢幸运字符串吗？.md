# 你也喜欢幸运字符串吗？
**【描述】 (Description)**  
给定一个长度为 $n$ 的字符串 $S$。定义“幸运字符串”为 $S$ 的任意一个前缀。要求计算所有前缀在原字符串 $S$ 中出现的总次数之和。  
**【条件】 (Constraints)**
- 字符串长度 $1 \le n \le 2 \times 10^5$。
- 字符串仅由小写字母组成。
- 必须在 $O(n)$ 时间内解决。  
**【目的】 (Objective)**

求出 $\sum_{i=1}^{n} \text{count}(S[0...i-1])$，其中 $\text{count}(P)$ 表示子串 $P$ 在 $S$ 中出现的次数。
