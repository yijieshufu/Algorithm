# 异或和之和-位运算-真题
**题目描述**  
- **目标**：给定一个数组 $A$，求所有子段 $[L, R]$ 的异或和之和。
- **公式**：$\sum_{1 \le L \le R \le n} (A_L \oplus A_{L+1} \oplus \dots \oplus A_R)$。
- **范围**：$n$ 通常为 $10^5$ 级别，要求算法复杂度为 $O(n \log(\max A))$。
# 分析
异或的精髓在于 **“不进位加法”**。第 $k$ 位最后是不是 1，只取决于这一位上有多少个 1。

1. **区间异或在第 $k$ 位为 1 的条件**：$S_j$ 的第 $k$ 位与 $S_i$ 的第 $k$ 位**不同**（一个是 0，一个是 1）。
2. **组合计数**：
    - 统计所有前缀异或值 $S_0, S_1, \dots, S_n$ 在第 $k$ 位上，0 的个数 $cnt0$ 和 1 的个数 $cnt1$。
    - 根据乘法原理，能配成 $cnt0 \times cnt1$ 对不同的 $(i, j)$，使得它们异或后第 $k$ 位为 1。
3. **计算贡献**：第 $k$ 位的每一对 1，价值都是 $2^k$。
    - 该位贡献 $= (cnt0 \times cnt1) \times 2^k$。
## 代码
```python
import os
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int((next(it))) for _ in range(n)]

s = [0]*(n+1)
for i in range(n):
  s[i+1] = s[i]^a[i]
ans = 0
for k in range(31):
  c0 = 0
  c1 = 0
  for x in s:
    if (x >> k) & 1:
      c0+=1
    else:c1+=1
  ans += (c0*c1)*(1<<k)
print(ans)
```
