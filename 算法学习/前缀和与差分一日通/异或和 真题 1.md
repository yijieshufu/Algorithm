# 异或和-真题
**【描述】 (Description)**  
给定 $n$ 个整数 $a_1, a_2, \dots, a_n$，计算所有数对的“异或值乘以其下标差”的总和。  
具体公式为：  
$$\sum_{i=1}^{n} \sum_{j=i+1}^{n} (a_i \oplus a_j) \times (j - i)$$
```python
# 暴力 只能过 8/12
import os
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [0]+[int(next(it)) for _ in range(n)]
res =0
for i in range(1,n+1):
  for j in range(i+1,n+1):
    res+=(a[i]^a[j])*(j-i)
print(res)
```
## 分析
**合并同类项**。将 $(j-i)$ 的累加拆为 $j$ 的个数减去 $i$ 的总和。  
**变量映射**。`c` 存**历史个数**，`s` 存**历史下标和**，`j` 为当前下标。  
**核心公式**。`j * c - s` 实现 $O(1)$ 计算，避免 $O(n)$ 循环嵌套。  
**优化效果**。由 $O(n^2)$ 降至 $O(n)$，彻底解决**超时问题**。
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [0] + [int(next(it)) for _ in range(n)]
ans = 0
for k in range(31):
  c0,s0=0,0
  c1,s1=0,0
  toal=0
  for j in range(1,n+1): # 计算k位
    if (a[j] >> k) & 1 :
      toal += (j*c0 - s0)
      c1+=1
      s1+=j
    else:
      toal += (j*c1 - s1)
      c0+=1
      s0+=j
  ans+=toal*(1<<k)
print(ans)
```
