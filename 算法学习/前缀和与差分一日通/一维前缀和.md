# 大学里的树木要维护
**【描述】 (Description)**  
教外有 $N$ 棵排成一线的树，每棵树都有一个预估的维护费用 $A_i$。为了统一管理，园艺人员会频繁询问某个特定区间 $[L, R]$ 内所有树木的维护费用总和。  
**【条件】 (Constraints)**
- **树木数量 $N$ 与查询次数 $M$**：虽然图中未直接给出具体范围，但通常此类题目 $N, M$ 会达到 $10^5$ 级别。
- **时间限制**：1s。
    - _Sigma 级警示_：如果对每个查询都用 `for` 循环累加，复杂度是 $O(M \times N)$，在 $10^5$ 规模下必超。必须使用 **$O(1)$** 的查询算法。
- **区间坐标**：$L$ 和 $R$ 是树的编号。  
**【目的】 (Objective)**  
对于每一次给定的区间查询，快速准确地输出该区间内所有维护费用的总和。

## 分析
#### **1. 遇到“静态数组”且“频繁区间求和” $\rightarrow$ 想到“前缀和”**
- **原理**：我们先花 $O(N)$ 的时间预处理出一个“累加数组” $S$。其中 $S[i]$ 表示前 $i$ 棵树的总费用。
- **计算公式**：第 $L$ 棵到第 $R$ 棵树的总和 = $S[R] - S[L-1]$。
## 代码
```python
import os
import sys
it = iter(sys.stdin.read().split())
N = int(next(it))
M = int(next(it))
a = [0]+[int(next(it)) for _ in range(N)]
sum = [0]*(N+1) 
for i in range(1,N+1):
  sum[i]=sum[i-1]+a[i] # 计算区间的前缀和
for _ in range(M):
  L=int(next(it))
  R=int(next(it))
  print(sum[R]-sum[L-1])
```
