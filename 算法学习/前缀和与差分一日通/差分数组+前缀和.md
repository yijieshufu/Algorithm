# 商品库存管理-真题
在一个包含 $n$ 种商品的系统中，初始库存均为 0。  
给定 $m$ 个区间加法操作 $[L, R]$，每个操作使区间内商品库存加 1。  
任务是：对于每一个操作 $i$，计算如果**唯独不执行**这一个操作，最终库存量为 0 的商品有多少种。
# 分析
通过**差分数组**快速求出全局库存，再利用**前缀和**快速统计每个操作区间内“库存恰好为 1”的商品数量。
## 代码

```python
import os
import sys
it=iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
ops = []
diff = [0]*(n+2)

for _ in range(m):
  l,r=int(next(it)),int(next(it))
  ops.append((l,r))
  diff[l]+=1
  diff[r+1]-=1

zeros = 0
curr = 0
s1 = [0]*(n+1) # 前缀和
for i in range(1,n+1):
  curr += diff[i]
  if curr ==0:
    zeros+=1
  s1[i] = s1[i-1]+(1 if curr == 1 else 0) 
ans = [] 
for l,r in ops:
  count = zeros + (s1[r]-s1[l-1])
  ans.append(str(count))
print("\n".join(ans))
```
