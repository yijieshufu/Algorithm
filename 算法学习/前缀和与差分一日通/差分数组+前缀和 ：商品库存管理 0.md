# 商品库存管理-真题
- **初始状态**：$n$ 个商品，库存全为 0。
- **操作**：$m$ 个区间 $[L, R]$，区间内每个商品库存 $+1$。
- **任务**：对于每一个操作 $i$，求出：如果**唯独不执行**第 $i$ 个操作，最后库存为 0 的商品种数。
- **范围**：$n, m \le 10^5$。
# 分析
我们要找的是 skipping 操作 $i$ 后，$V'_j = 0$ 的数量。
- **全局视角**：先算出执行**所有** $m$ 个操作后，每个商品的最终库存 $V_j$。
- **情况 A（天生为 0）**：若 $V_j = 0$，无论去掉哪个操作，它依然是 0。我们记这类商品的数量为 `zeros`。
- **情况 B（临界为 1）**：若 $V_j = 1$，且商品 $j$ 在操作 $i$ 的区间 $[L_i, R_i]$ 内，去掉操作 $i$ 后，$V_j$ 会变成 0。
- **逻辑闭环**：对于操作 $i=[L, R]$，结果 = `zeros` + `[L, R] 范围内最终库存为 1 的商品数量`。
## 代码
```python
import os
import sys
it=iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
ops = []
diff = [0]*(n+2)

for _ in range(m):
  l,r=int(next(it)),int(next(it))
  ops.append((l,r))
  diff[l]+=1
  diff[r+1]-=1

zeros = 0
curr = 0
s1 = [0]*(n+1) # 前缀和
for i in range(1,n+1):
  curr += diff[i]
  if curr ==0:
    zeros+=1
  s1[i] = s1[i-1]+(1 if curr == 1 else 0) 
ans = [] 
for l,r in ops:
  count = zeros + (s1[r]-s1[l-1])
  ans.append(str(count))
print("\n".join(ans))
```
