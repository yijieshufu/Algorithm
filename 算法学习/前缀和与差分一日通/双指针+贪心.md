# 挖矿-真题
小蓝在数轴上的 $0$ 点出发，要在总移动距离不超过 $m$ 的前提下，尽可能多地收集矿石。数轴上有 $n$ 个矿石，位置在 $a_i$。经过矿石点即收集，每个矿石只能收集一次。  
- **核心动作**：在数轴上从 $0$ 出发，移动总距离不超过 $m$，求最多能经过（覆盖）多少个矿洞点。
## 分析
**路径分类**：要覆盖区间 $[L, R]$（其中 $L \le 0 \le R$），只有两种最省力的走法：
- 先往左走到底再折返往右走：距离 = $2|L| + R$。
- 先往右走到底再折返往左走：距离 = $2R + |L|$。
- 最短距离即为：$\min(2|L| + R, 2R + |L|)$。

先对矿洞坐标进行**排序**，然后利用**双指针（滑动窗口）** 在正负坐标区域内寻找最优的左右边界

## 代码

```python
import os
import sys

it = iter(sys.stdin.read().split())
n,m = int(next(it)),int(next(it))
a = [int(next(it)) for _ in range(n)]
neg = sorted([-x for x in a if x < 0]) 
pos = sorted([x for x in a if x > 0])
j = len(pos)
ans = 0
for i in range(len(neg)+1): # i代表当前左边的矿的个数 
  L = neg[i-1] if i > 0 else 0 # L 左边的坐标
  if L>m : break
  while j > 0 :
    R = pos[j-1] # 右边的坐标
    dist = min(2*L+R,2*R+L)
    if dist <= m : break
    j-=1
  ans = max(ans,i+j)
print(ans)
```
