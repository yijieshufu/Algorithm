# 大学里的树木要维护
- **输入**：$N$ 棵树的初始维护费用，以及 $M$ 个区间 $[L, R]$。
- **目标**：快速计算每个区间内树木维护费用的总和。
- **范围**：通常 $N, M \le 10^5$。
# 分析
# 代码
```python
import os
import sys
it = iter(sys.stdin.read().split())
N = int(next(it))
M = int(next(it))

a = [int(next(it)) for _ in range(N)]

pre = [0] * (N+1)

for i in range(N):
  pre[i+1] = pre[i] + a[i]

for _ in range(M):
  l = int(next(it))
  r = int(next(it))
  print(pre[r]-pre[l-1])
```
