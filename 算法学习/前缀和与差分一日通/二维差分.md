# 棋盘-真题
**题目描述**
$n \times n$ 的全白棋盘，进行 $m$ 次区域**反转颜色**操作（黑白互换）。
要求输出所有操作完成后，棋盘上每个格子的最终颜色状态。
**条件**
棋盘大小 $n$ 和操作数 $m$ 均达到 **2000**。
直接对矩形区域内每个点进行修改会导致 $O(m \cdot n^2)$ 复杂度，**必定超时**。
**目的**
利用高效的数据结构，在 **$O(n^2 + m)$** 时间内完成 **区间修改与单点查询**。
**分析**
**二维差分**。将矩形区域的整体反转转化为四个关键顶点的数值增减。
**二维前缀和**。通过一次全盘累加，还原每个点被覆盖（翻转）的总次数。
**奇偶判定**。翻转奇数次变为黑色（1），偶数次保持白色（0），对 2 **取模**即可。

## 代码

```python
import os
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
diff = [[0]*(n+2) for _ in range(n+2)]
for _ in range(m):
  x1 = int(next(it))
  y1 = int(next(it))
  x2 = int(next(it))
  y2 = int(next(it))
  diff[x1][y1]+=1
  diff[x1][y2+1]-=1
  diff[x2+1][y1]-=1
  diff[x2+1][y2+1]+=1  # 先记录好
for i in range(1,n+1):
  row_res = []
  for j in range(1,n+1):
    # 通过二维前最后求值
    diff[i][j]+=diff[i-1][j]+diff[i][j-1]-diff[i-1][j-1] 
    if diff[i][j]%2==1:
      row_res.append('1')
    else:
      row_res.append('0')
  sys.stdout.write("".join(row_res) + "\n")
```

## 总结
**二维前缀和**递推公式：$S_{i,j} = S_{i-1,j} + S_{i,j-1} - S_{i-1,j-1} + A_{i,j}$。用于快速预处理。

**二维前缀和**查询公式：$Sum = S_{x2,y2} - S_{x1-1,y2} - S_{x2,y1-1} + S_{x1-1,y1-1}$。实现 $O(1)$ 查询。

**二维差分**修改操作：对矩形 $(x1, y1)$ 到 $(x2, y2)$ 加 $v$，修改四个顶点。
$$D_{x1,y1} \gets D_{x1,y1} + v$$
$$D_{x1,y2+1} \gets D_{x1,y2+1} - v$$
$$D_{x2+1,y1} \gets D_{x2+1,y1} - v$$
$$D_{x2+1,y2+1} \gets D_{x2+1,y2+1} + v$$

**差分还原**逻辑：对**差分数组**求一次**二维前缀和**，即可还原出修改后的原数组。

**容斥原理**核心：计算时“多加的要减去，多减的要补回来”，保证区域不重不漏。
