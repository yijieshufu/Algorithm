# 题目
- **缩写逻辑：** 只保留首尾字符，中间用长度代替。例如 `internationalization` → `i18n`。
- **核心动作**：在字符串 $S$ 中，统计长度 $\ge K$ 且以 $c_1$ 开头、$c_2$ 结尾的子串数量。
- **数据边界**：$|S| \le 5 \times 10^5$。必须实现 $O(N)$ 复杂度，防止 TLE。
# 分析
## 代码

暴力：4/10
```python
import os
import sys

it = iter(sys.stdin.read().split())
K = int(next(it))
S = next(it)
c1 = next(it)
c2 = next(it)
n = len(S)
ans = 0
for i in range(n):
  if S[i] ==c1:
    for j in range(i+1,n):
      if S[j] == c2 and (j-i+1)>=K:
        ans +=1
print(ans)

```
