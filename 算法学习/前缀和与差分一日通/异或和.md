# 异或和-真题
- **核心动作**：给定序列 $a$，求所有数对 $(a_i, a_j)$ 的**异或值**与其**下标差**乘积的总和。
- **目标公式**：$\sum_{i=1}^{n} \sum_{j=i+1}^{n} (a_i \oplus a_j) \times (j - i)$
- **数据边界**：$n$ 通常为 $10^5$ 级，$a_i$ 约 $10^9$。直接 $O(n^2)$ 暴力必 TLE，需优化至 $O(n \log A)$
```python
# 暴力 只能过 8/12
import os
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [0]+[int(next(it)) for _ in range(n)]
res =0
for i in range(1,n+1):
  for j in range(i+1,n+1):
    res+=(a[i]^a[j])*(j-i)
print(res)
```

import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [0] + [int(next(it)) for _ in range(n)]
ans = 0
for k in range(31):
    c0, s0 = 0, 0  
    c1, s1 = 0, 0
    bit_total = 0
    for j in range(1, n + 1):
        if (a[j] >> k) & 1:
           
            bit_total += (j * c0 - s0)
            c1 += 1
            s1 += j
        else:
           
            bit_total += (j * c1 - s1)
            c0 += 1
            s0 += j
    ans += bit_total * (1 << k) 
print(ans)
