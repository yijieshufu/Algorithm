# 异或和之和-位运算-真题
**题目描述**  
给定长度为 $n$ 的数组 $A$。计算所有可能的子段 $[L, R]$ 的**异或和**，并将这些子段异或和的结果全部**相加**。  
即求：$\sum_{1 \le L \le R \le n} (A_L \oplus A_{L+1} \oplus \dots \oplus A_R)$。
## 分析
$$\underbrace{\text{Ans}}_{\text{最终答案}} = \sum_{k=0}^{20} (\underbrace{cnt0 \times cnt1}_{\text{第 } k \text{ 位是 1 的子段总数}} \times \underbrace{2^k}_{\text{该位的数值权值}})$$

所有字段的异或和：  
	第k位的 0 和1 各自数量 相乘  
	再乘以 权重

在 第k位的时候  
	先统计 0 和 1 的 个数  
	如果要让异或结果为 1，我们必须**从 $c_0$ 堆里挑一个，再从 $c_1$ 堆里挑一个**。  
	根据乘法原理，总共可以配成 **$c_0 \times c_1$** 对。  
然后 **成功的配对数 ($c_0 \times c_1$) $\times$ 每一配对的价值 ($2^k$)**。
## 代码
```python
import os
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int((next(it))) for _ in range(n)]

s = [0]*(n+1)
for i in range(n):
  s[i+1] = s[i]^a[i]
ans = 0
for k in range(31):
  c0 = 0
  c1 = 0
  for x in s:
    if (x >> k) & 1:
      c0+=1
    else:c1+=1
  ans += (c0*c1)*(1<<k)
print(ans)
```
