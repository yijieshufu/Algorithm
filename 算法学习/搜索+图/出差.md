# 出差-真题 （变体：边权的转化）
- 有 `n` 个城市，`m` 条双向道路，每条路通行时间为 `w`。
- 每个城市 `i` 有隔离时间 `c[i]`。
- 从 `1` 出发到 `n`。
- 规则：
    - 到达某城市后，若还要继续走，需先隔离该城市对应时间；
    - 城市 `1` 不用隔离就能出发；
    - 到达城市 `n` 后结束，不用隔离。
- 求最小总耗时，不可达输出 `-1`。
## 分析
### 1) 点权转边权
原路 `u <-> v`，路程时间 `w`。  
若走 `u -> v`，这一步总代价可写成：
- `w + c[v]`（当 `v != n`）
- `w`（当 `v == n`）  
这样就把“中转城市的隔离时间”并到“进入该城市的边”上了。  
双向路要拆成两条有向边，分别算代价。
### 2) 跑 Dijkstra
- 现在图上每条有向边权都非负，直接堆优化 Dijkstra。
- 复杂度 `O(m log n)`，`n=1000, m=10000` 完全够用。
## 代码

```python
import os
import sys
import heapq

it = iter(sys.stdin.read().split())

n = int(next(it))
m = int(next(it))

c = [0] + [int(next(it)) for _ in range(n)]

g = [[] for _ in range(n+1)]

for _ in range(m):
  a = int(next(it)); b = int(next(it)); w = int(next(it))
  g[a].append((b,w+(0 if b == n else c[b])))
  g[b].append((a,w+(0 if a == n else c[a])))

inf = 10**30 
d = [inf] * (n+1)
d[1] = 0
q = [(0,1)]
while q:
  x,a = heapq.heappop(q)
  if x != d[a]: # 更新了 就不用在更新了
    continue
  for b,w in g[a]:
    f = x+w
    if f <d[b]:
      d[b] = f
      heapq.heappush(q,(f,b))
ans = d[n]
print(-1 if ans == inf else ans)
```
