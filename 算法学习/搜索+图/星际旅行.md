# 星际旅行

## 题目描述

有 $N$ 个星球（编号 $1 \sim N$），星球之间有无向**传送门**共 $M$ 条。经过任意一条传送门都算作 **$1$ 步**（边权均为 $1$）。

现有 $Q$ 次询问。

第 $i$ 次询问给定起点星球 $x_i$ 和步数上限 $y_i$，问：从 $x_i$ 出发，在**不超过** $y_i$ 步的前提下，**最多能到达多少个星球**（**包含起点**本身）。

要求输出这 $Q$ 次结果的**平均值**，保留 **$2$** 位小数。

形式化地，若第 $i$ 次可达数为 $c_i$，则输出

$$
\frac{c_1 + c_2 + \cdots + c_Q}{Q}
$$

保留两位小数。

## 分析

- **询问含义**：边权为 1，求从 $x$ 出发**最短步数 $\le y$** 能到多少点（含起点）。
- **BFS**：单源最短路用 BFS 得到每个点的 `dist`。
- **预处理**：起点只有 $N$ 种，对每个 $i$ 做一次 BFS，避免每次询问都 BFS（$Q$ 大时超时）。
- `**f[i][d]` 两段**：先按 `dist` 统计「距离恰好为 $d$」的个数；再对 $d$ 做**前缀和**，变成「距离 $\le d$」的个数，查询 $(x,y)$ 时直接取 `f[x][min(y,n)]`（$O(1)$）。`min` 防止 $y$ 过大越界，且最多只有 $n$ 个点。
- **复杂度**：预处理约 $O(N(N+M))$，空间 $O(N^2)$；单次询问 $O(1)$。

---

## 代码

```python
import sys

it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
q = int(next(it))

g = [[] for _ in range(n + 1)]
for _ in range(m):
    u = int(next(it))
    v = int(next(it))
    g[u].append(v)
    g[v].append(u)

# f[i][d]：先存「距离 i 恰好为 d」的点数，再改成「距离 ≤ d」的前缀
f = [[0] * (n + 1) for _ in range(n + 1)]

for i in range(1, n + 1):
    dist = [-1] * (n + 1)
    dist[i] = 0
    que = [i]
    for u in que:
        for v in g[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                que.append(v)

    for d in dist:
        if d != -1:
            f[i][d] += 1

    for d in range(1, n + 1):
        f[i][d] += f[i][d - 1]

s = 0
for _ in range(q):
    x = int(next(it))
    y = int(next(it))
    s += f[x][min(y, n)]

print(f"{s / q:.2f}")
```
