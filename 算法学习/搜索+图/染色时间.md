# 染色时间

## 题目描述

小蓝有一个 $n \times m$ 的白色棋盘，每个格子都可以被染色。

- 若格子 $(i,j)$ 被**触发**，则从触发时刻起，需要 $t_{i,j}$ 秒该格才**染色完成**。
- 某格**染色完成的瞬间**，会立刻向上下左右四个相邻格子各发送一次触发。
- 每个格子**只接受第一次触发**，之后的触发会被忽略。
- 时刻 $T=0$ 时，格子 $(1,1)$ 被触发。

给定 $n,m$ 以及每个格子的 $t_{i,j}$（正整数），求：**整个棋盘所有格子都染色完成**的时刻（秒）。

## 分析（极简）

**1. 一格什么时候染完？**  
$(1,1)$ 在 $0$ 秒被触发，所以它在 $t_{1,1}$ 秒完成。别的格要等**某个邻居先染完**才会被触发，触发后再等**本格的** $t$，才完成。  
一句话：**邻格完成时刻 = 父格完成时刻 + 邻格自己的 $t$**（代码里 `a` 存 $t$）。

**2. 「只认第一次触发」**  
多条路线可能先后传到同一格，但只有最先到达的那次算数。所以我们要算的是：每个格**最早**第几秒完成——取所有来路里完成时间的**最小值**。

**3. 怎么算？**  
上面就是在网格上做**最短路**：边从 $A$ 连到四邻 $B$，代价用 $B$ 的 $t$（正数），从 $(1,1)$ 出发跑 **Dijkstra**，`f[i][j]` 记最早完成时刻；堆按时间弹出，和 `f` 不一致的堆顶丢掉即可。

**4. 答案**  
全棋盘染完 = 最后一格完成，即所有 `f[i][j]` 的**最大值**。  
复杂度：$O(nm\log(nm))$ 时间，$O(nm)$ 空间。

---

## 代码（Python 3.7，极简竞赛）

```python
import heapq
import sys

it = iter(sys.stdin.read().split())
n = int(next(it))
m = int(next(it))
a = [[0] * m for _ in range(n)]
for i in range(n):
    for j in range(m):
        a[i][j] = int(next(it))

INF = 10 ** 30
f = [[INF] * m for _ in range(n)]
f[0][0] = a[0][0]
h = [(f[0][0], 0, 0)]  # 小根堆：(完成时刻, 行, 列)

while h:
    d, r, c = heapq.heappop(h)
    if d != f[r][c]:
        continue  # 过期堆顶
    for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        b, g = r + dr, c + dc
        if 0 <= b < n and 0 <= g < m:
            nd = d + a[b][g]
            if nd < f[b][g]:
                f[b][g] = nd
                heapq.heappush(h, (nd, b, g))

ans = 0
for i in range(n):
    for j in range(m):
        if f[i][j] > ans:
            ans = f[i][j]
print(ans)
```
