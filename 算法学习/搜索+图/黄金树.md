# 黄金树

## 题目描述

给定一棵 $n$ 个节点的二叉树，节点编号 $1 \sim n$，**根为 $1$**。

- 每个节点 $i$ 有权值 $w_i$。
- 每个节点有左儿子 $l_i$、右儿子 $r_i$；若不存在则对应为 $-1$。

**黄金指数 $GI$** 在从根向下的路径上按规则传递：

| 节点    | 规则                   |
| ----- | -------------------- |
| 根 $1$ | $GI = 0$             |
| 左儿子   | $GI$ = 父节点 $GI + 1$  |
| 右儿子   | $GI$ =  父节点 $GI - 1$ |

遍历全树，求**所有满足 $GI = 0$ 的节点**的权值**之和**。

## 分析

- 从根出发 DFS（或 BFS）即可沿**父子关系**走完整棵树。
- 递归时维护当前节点的 $GI$：根传入 $0$；递归左子 $GI+1$，右子 $GI-1$。
- 若当前 $u=-1$（空儿子）直接返回。
- 若当前 $GI=0$，把 $w_u$ 计入答案；否则不计。
- 树规模 $O(n)$，每个节点访问一次，时间、空间均为 $O(n)$（递归栈深度 $\le n$）。

---

## 代码

```python
import sys

it = iter(sys.stdin.read().split())
n = int(next(it))
w = [0] + [int(next(it)) for _ in range(n)]
a = [(0, 0)]
for _ in range(n):
    l = int(next(it))
    r = int(next(it))
    a.append((l, r))  # a[i] 为节点 i 的 (左, 右)，下标 1..n
def dfs(u, g):
    if u == -1:
        return 0
    s = w[u] if g == 0 else 0
    l, r = a[u]
    return s + dfs(l, g + 1) + dfs(r, g - 1)


print(dfs(1, 0))
```
