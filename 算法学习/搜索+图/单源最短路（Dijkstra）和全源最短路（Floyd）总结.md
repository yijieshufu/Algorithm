# 1. Dijkstra：单源最短路（狙击手模式）
**【核心思想】**：从一个点出发，每次挑“最近”的那个点去更新周围的人。  
**【适用场景】**：$N$ 很大（如 $10^5$），但 $M$（边数）相对较少。求的是 **“1 号点到其他所有人”** 的距离。
#### **写法精要 (Sigma 规范)：**
1. **材料**：**邻接表** `g = [[] for _ in range(n+1)]`。因为 $N$ 很大，邻接矩阵会爆内存。
2. **核心工具**：`heapq`。Python 的堆是小顶堆，存的是 `(距离, 节点)`，保证每次弹出的都是目前距离起点最近的点。
3. **判定逻辑**：`if d > dist[u]: continue`。这是 Dijkstra 的灵魂剪枝，防止旧的、更长的距离重复计算。
# 2. Floyd：全源最短路（地毯式模式）
**【核心思想】**：暴力枚举每一个可能的“中转站” $k$，看 $i$ 到 $j$ 能不能通过 $k$ 变短。  
**【适用场景】**：$N$ 很小（如 $\le 400$），查询次数 $Q$ 很多。求的是 **“任意两点间”** 的最短路。
#### **写法精要 (Sigma 规范)：**
1. **材料**：**邻接矩阵** `f = [[inf]*(n+1) for _ in range(n+1)]`。
2. **三层循环顺序**：**$k$ 必须在外层**。记住口诀：“中转站在外，起点终点在内”。
3. **Python 专项优化**：
    - **行引用**：`fi = f[i]`。在 Python 中，访问 `f[i][j]` 是两次寻址，访问 `fi[j]` 是一次，速度提升明显。
    - **剪枝**：`if fi[k] == inf: continue`。如果起点连不上中转站，直接跳过最内层循环。

# 3. 两种算法的对比清单

|**特性**|**Dijkstra (堆优化)**|**Floyd-Warshall**|
|---|---|---|
|**解决问题**|1 到 $N$ (单源)|任意点到任意点 (全源)|
|**复杂度**|$O(M \log N)$|$O(N^3)$|
|**存储方式**|邻接表 (省内存)|邻接矩阵 (费内存)|
|**负权边**|**不支持**|**支持** (不能有负权环)|
|**Python 极限**|$N=10^5$ 级|$N=400 \sim 500$ 级|
# **Dijkstra 骨架**
```python
# 1.变量
# 使用 g 存储邻接表, pq 存储堆
# 2.边界
dist[1] = 0
pq = [(0, 1)]
# 3.操作 (松弛边缘)
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]: continue
    for v, w in g[u]:
        if dist[u] + w < dist[v]:
            dist[v] = dist[u] + w
            heapq.heappush(pq, (dist[v], v))

```
# **Floyd 骨架**
```python
# 1.变量
# 使用 f 存储二维矩阵
# 2.边界
for i in range(1, n+1): f[i][i] = 0
# 3.操作 (三层 DP)
for k in range(1, n+1):
    fk = f[k]
    for i in range(1, n+1):
        fi = f[i]
        if fi[k] == inf: continue
        fik = fi[k]
        for j in range(1, n+1):
            if fik + fk[j] < fi[j]:
                fi[j] = fik + fk[j]

```
