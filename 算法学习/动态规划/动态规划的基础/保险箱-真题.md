# 题目
**1. 核心描述**：  
有一个 $n$ 位的密码锁（每一位 0-9）。你可以将某一位 $+1$ 或 $-1$。  
**2. 核心条件（进位规则）**：
- **向上进位**：某位从 9 变到 0 时，其**左边位**会自动 $+1$。
- **向下退位**：某位从 0 变到 9 时，其**左边位**会自动 $-1$。
- **边界**：最高位（最左边第一位）的进位或退位直接被**忽略**。  
**3. 最终目的**：  
求将数字 $x$ 变为 $y$ 所需的**最少操作次数**。

**4.数据规模判断算法**
- **$n \le 10^5$**：意味着我们的算法复杂度必须是 **$O(n)$**。
- **局部依赖性**：因为进位/退位只影响**左边**的数字，这具有明显的**后效性**。当我们从右往左处理时，当前位的选择会影响左边位的初始值。
- **算法选择**：**线性 DP**。我们从右向左扫描，记录当前位产生的进位状态。
## 分析
#### 1. 核心决策：三种拨法
对于每一位数字 $x_i$，要把它变成 $y_i$，你手里其实有三张牌：
- **直接拨**：从 3 拨到 8，走 5 步。对左边没影响（进位 = 0）。
- **向上拨过头**：从 9 拨到 1。你其实是拨到了 **11**。走了 2 步，但顺便帮左边那位**增加了 1**。
- **向下拨过头**：从 1 拨到 9。你其实是拨到了 **-1**。走了 2 步，但顺便帮左边那位**减小了 1**。
#### 2. 连锁反应
由于每一位受到的影响只来自于它的右邻居，我们应该**从右往左**处理：
1. 看最右边那一位，计算它产生“进位、不进位、退位”给左邻居时，各自最少要花多少步。
2. 处理下一位时，先接收右边送来的“礼物”，再重复上述三个决策。
3. 一直推到最左边。
## 代码
```python
import sys

# 1. 变量 (读取为字符串处理大数)
it = iter(sys.stdin.read().split())
n = int(next(it))
x = [int(d) for d in next(it)]
y = [int(d) for d in next(it)]

# f 存储当前产生进位状态为 [-1, 0, 1] 时的最小代价
f = [float('inf'), 0, float('inf')]

# 2. 边界 (从右向左，模拟进位流动)
for i in range(n - 1, -1, -1):
    g = [float('inf')] * 3
    # 遍历当前位向左传出的进位 v_out 和接收到的进位 v_in
    for v_out in [-1, 0, 1]:
        for v_in in [-1, 0, 1]:
            if f[v_in + 1] == float('inf'): continue
            
            # 3. 操作: 计算代数位移
            # 步数 = |(目标值 + 进位圈数) - (初始值 + 接收进位)|
            cost = abs((y[i] + 10 * v_out) - (x[i] + v_in))
            g[v_out + 1] = min(g[v_out + 1], f[v_in + 1] + cost)
    f = g

# 4. 答案 (最高位的进位被忽略，取三种状态中的最小值)
print(min(f))
```
