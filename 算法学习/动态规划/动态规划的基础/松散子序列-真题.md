# 题目
**1. 核心条件**：
- **输入**：一个纯小写字母字符串 $s$。
- **规则**：选择一个子序列，要求子序列中任意两个字符在原字符串中的**下标之差必须 $\ge 2$**。
- **直观理解**：在原字符串里，**不能选择两个相邻的字符**。
- **价值计算**：字符 `a~z` 分别对应权重 `1~26`。  
**2. 目的**：
- 找出满足“**不相邻**”条件的所有子序列中，字符价值总和最大的那一个。
## 分析
题目要求 $p_i - p_{i-1} \ge 2$。
- 如果你选了第 $5$ 个字符，那么前一个选的字符只能是第 $1, 2, 3$ 个。
- **直白结论**：在原字符串中，你选中的任何两个字符都**不能相邻**。  
当我们处理到字符串的第 $i$ 个字符时，为了让总价值最大，我们只有两个选择：
- **选项 A：不选第 $i$ 个字符**  
    此时的最大价值，就等于处理完前一个字符（第 $i-1$ 个）时攒下的最大价值。  
    $$价值 = dp[i-1]$$
- **选项 B：必选第 $i$ 个字符**  
    如果你选了它，你就获得了它的分值 $v$。但根据“不相邻”规则，你**不能**带上第 $i-1$ 个字符的成果，只能在**第 $i-2$ 个**字符的基础上累加。  
    $$价值 = dp[i-2] + v$$  
为了最大化价值，我们每一位都**取两者的最大值**：  
$$dp[i] = \max(dp[i-1], dp[i-2] + \text{value}(s[i]))$$
## 代码
```python
import sys
# 1. 变量
it = iter(sys.stdin.read().split())
s = next(it)
n = len(s)
# f 数组存储 dp 状态，多开一个位置处理边界
f = [0] * (n + 1)
# 2. 边界
f[1] = ord(s[0]) - 96 # 第 1 个字符的最优解就是它自己
# 3. 操作
for i in range(2, n + 1):
    # a 存储当前字符的价值
    a = ord(s[i-1]) - 96
    # 状态转移：max(不要当前位, 要当前位 + 隔一位的最优值)
    f[i] = max(f[i-1], f[i-2] + a)
# 4. 答案
ans = f[n]
print(ans)
```
