# 951.翻转等价二叉树
- **输入**：两棵二叉树的根节点 `root1` 和 `root2`。
- **定义“翻转”**：选择任意节点，交换它的左子树和右子树。
- **任务**：判断 `root1` 经过若干次翻转后，能否变成 `root2`。
- **关键提示**：树中每个节点的值都是**唯一**的。
# 分析 
#### 情况 A：不用翻转（直接对应）
- `node1` 的左子树和 `node2` 的左子树等价
- **且** `node1` 的右子树和 `node2` 的右子树等价。
#### 情况 B：需要翻转（交叉对应）
- `node1` 的左子树和 `node2` 的**右**子树等价
- **且** `node1` 的右子树和 `node2` 的**左**子树等价。  
# 代码
```python
class Solution:
    def flipEquiv(self, root1: Optional[TreeNode], root2: Optional[TreeNode]) -> bool:
        if not root1 and not root2:
            return True
        if not root1 or not root2 or root1.val != root2.val:
            return False
        # 情况1 不翻转
        no_flip = self.flipEquiv(root1.left,root2.left) and self.flipEquiv(root1.right,root2.right)
        # 情况2 翻转
        flip = self.flipEquiv(root1.left,root2.right) and self.flipEquiv(root1.right,root2.left)
        return no_flip or flip
```
