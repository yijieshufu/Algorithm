# 100 相同的树
- **输入**：两棵二叉树的根节点 `p` 和 `q`。
- **任务**：检查这两棵树是否“相同”。
- **“相同”的定义**：
    1. **结构相同**：对应的分支长得一模一样。
    2. **数值相同**：对应位置节点的值必须相等。
# 分析

- **都为空**：`p` 和 `q` 都是 `None`。返回 `True`。
- **一个为空，一个不为空** 或者 **值不同**：返回 `False`。

- 左边对比左边：`isSameTree(p.left, q.left)`
- 右边对比右边：`isSameTree(p.right, q.right)`
# 代码
```python
class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        if not p and not q :
            return True
        if not p or not q or q.val != p.val:
            return False
        return self.isSameTree(p.left,q.left) and self.isSameTree(p.right,q.right)
```
