# LC 208. 实现 Trie (前缀树)
- **任务**：设计并实现一个 Trie（发音类似 "try"，前缀树/字典树）数据结构。
- **核心功能**：
    - `__init__()`：初始化前缀树对象。
    - `insert(word)`：将字符串 `word` 插入树中。
    - `search(word)`：检查字符串 `word` 是否完整存在于树中（精确匹配）。
    - `startsWith(prefix)`：检查树中是否包含以 `prefix` 为前缀的字符串（模糊匹配）。
# 分析
初始化：  
	每个节点 都创建一个字典  
	设计一个标记位  
插入：  
	遇到没有的位置 直接 创建 Trie()  
	`node = node.children[char]` 找到下一个 子节点
# 代码
```python
class Trie:

    def __init__(self):
        self.children = {} # 每个子节点 都创建一个字典
        self.is_end = False # 标记位

    def insert(self, word: str) -> None:
        node = self
        for char in word:
            if char not in node.children:
                node.children[char] = Trie()
            node = node.children[char] # 移到到下一节点
        node.is_end = True

    def search(self, word: str) -> bool:
        node  = self
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end

    def startsWith(self, prefix: str) -> bool:
        node  = self
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True
```
