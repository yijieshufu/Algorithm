## [[递归 + 同步遍历 ：951.翻转等价二叉树]]
对 二叉树 是否 **翻转** 进行判断  
	递归  
		不翻转  
			左 对 左  
			右 对 右  
		翻转  
			左 对 右  
			右 对 左  
边界条件的判断
```python
if not root1 and not root2: # 都到空节点了 返回正确
    return True
if not root1 or not root2 or root1.val != root2.val: # 发一个为空 或者 值不一样的 返回 False
    return False
```

## [[递归 + 同步遍历 ：LC101对称二叉树]]
单棵树 判断 是否 轴对称  
递归：  
	左 对 右  
	右 对 左  
同步 DFS
```python
函数 是否对称(root):
    如果 root 为空: 返回 True
    // 同步遍历校验器
    函数 dfs(左节点, 右节点):
        // 1. 判双空 (都走到底了，成功)
        如果 左节点 为空 且 右节点 为空: 
            返回 True
        // 2. 判单空 或 判值不等 (匹配失败)
        如果 左节点 为空 或 右节点 为空 或 左节点.值 != 右节点.值: 
            返回 False
        // 3. 交叉递归 (外侧比外侧，内侧比内侧)
        返回 dfs(左节点.左孩, 右节点.右孩) 且 
             dfs(左节点.右孩, 右节点.左孩)
    // 触发递归
    返回 dfs(root.左孩, root.右孩)
```

## [[递归 + 同步遍历：LC 1367. 二叉树中的链表]]
一个列表 + 一个树  
找到树中的列表  
	不限制 树的起点

判断找到：  
	列表的元素走到头了  
判断没有找到  
	树节点为空 或者 值不一样

双重 DFS
```python
函数 外层全图扫描(模板, 当前树节点):
    // 0. 树都搜到底了，还是没找到合适的起点
    如果 当前树节点 为空: 
        返回 False
    // ==========================================
    // 内层比对器：只负责“顺着一条路往下对”
    // ==========================================
    函数 内层比对(模板节点, 树节点):
        // 1. 模板全部核对完毕，匹配成功！
        如果 模板节点 为空: 
            返回 True
        // 2. 树没路了，或者长得不一样，当前这条路失败
        如果 树节点 为空 或 树节点.值 != 模板节点.值: 
            返回 False
        // 3. 当前点对上了，拿着模板的下一个节点，去树的左右碰运气
        返回 内层比对(模板节点.下一个, 树节点.左孩) 或 
             内层比对(模板节点.下一个, 树节点.右孩)
    // ==========================================
    // 外层驱动：在全图的每一个节点都试一次
    // ==========================================
    返回 内层比对(模板, 当前树节点) 或          // 就在当前位置直接比对
         外层全图扫描(模板, 当前树节点.左孩) 或   // 去左子树找别的起点
         外层全图扫描(模板, 当前树节点.右孩)      // 去右子树找别的起点
```
