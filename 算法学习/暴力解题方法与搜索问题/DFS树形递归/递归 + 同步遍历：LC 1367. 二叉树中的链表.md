# LC 1367. 二叉树中的链表
- **输入**：一个链表的头节点 `head`，一棵二叉树的根节点 `root`。
- **任务**：判断二叉树中是否存在一条**一直向下的路径**，其节点值与链表中的节点值**完全匹配**。
- **关键规则**：路径的起点可以是二叉树中的**任意节点**。向下指的是从父节点走向左儿子或右儿子。
# 分析
边界条件  
	判断找到：  
		列表的元素走到头了  
	判断没有找到  
		树节点为空 或者 值不一样

如何走（递归）：  
	列表节点固定  
	树可以是  
		当前节点  
		左右的子节点
# 代码
```python
class Solution:
    def isSubPath(self, head: Optional[ListNode], root: Optional[TreeNode]) -> bool:
        if not root : 
            return False
        def dfs(list_node,tree_node):
            if not list_node: # 链表走到空 表示走完了
                return True
            if not tree_node or tree_node.val != list_node.val: # 树节点为空 或者 值不一样
                return False
            # 列表节点 与 树的左右子节点 对比
            return dfs(list_node.next,tree_node.left) or dfs(list_node.next,tree_node.right)
        # 列表节点  与 当前跟节点开始对比 或者 左右的子节点对比
        return dfs(head,root) or self.isSubPath(head,root.left) or self.isSubPath(head,root.right)
```
