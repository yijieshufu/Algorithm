# LC 879. 盈利计划
集团有 $n$ 名员工。第 $i$ 种工作需要 `group[i]` 名成员，产生 `profit[i]` 的利润。  
求选出**利润至少为 `minProfit`**，且**员工总数不超过 $n$** 的工作子集（盈利计划）的总方案数。  
结果对 $10^9 + 7$ 取模。
# 分析
**本质**：**带“下界截断”的二维 0-1 背包**。  
这题和 **LC 474（一和零）** 的骨架完全一致，有两个维度的资源限制：人数（不能超）和 利润（不能少）。

**唯一且致命的区别**：人数是“上限”（超过就死），而利润是“下限”（赚够了就行，超额完成依然算成功）。

所以，当所需利润减到负数时，我们不能让它爆表，而是要把它**截断到 0**，表示“利润目标已达成，后面赚多赚少无所谓了”。

**核心状态**：  
	`dfs(idx, members_left, profit_needed)` 面对第 `idx` 个工作，  
	手里还有 `members_left` 个人可以差遣，距离保底利润目标还差 `profit_needed`。  
**边界条件的判断**：
```python
if idx == len(group): # 工作全看完了，清点业绩
    return 1 if profit_needed == 0 else 0 
if (idx, members_left, profit_needed) in memo: 
    return memo[(idx, members_left, profit_needed)]
```
**决策分支（状态转移）**：
- **路线 A（不接这单工作）**： `res1 = dfs(idx + 1, members_left, profit_needed)`
- **路线 B（接这单工作）**：前提是当前人数够用 (`members_left >= group[idx]`)。  
	**下界截断核心**：  
		`new_profit = max(0, profit_needed - profit[idx])`  
		`res2 = dfs(idx + 1, members_left - group[idx], new_profit)`
- **汇总**：把两条路的**方案数**加起来，并取模。 `res = (res1 + res2) % (10**9 + 7)`

# 代码
```python
class Solution:
    def profitableSchemes(self, n: int, minProfit: int, group: List[int], profit: List[int]) -> int:
        memo = {}
        length = len(group)
        MOD = 10**9+7
        def dfs(idx,member_left,profit_needed):
            if idx == length:
                return 1 if profit_needed == 0 else 0
            state = (idx,member_left , profit_needed)
            if state in memo:
                return memo[state]
			# A 方案
            res = dfs(idx+1,member_left,profit_needed)
			# B方案
            if member_left>=group[idx]:
                new_profit = max(0,profit_needed - profit[idx])
                res += dfs(idx+1,member_left - group[idx],new_profit)
            res %= MOD
            memo[state] = res
            return res
        return dfs(0,n,minProfit)
```
