# LC 416. 分割等和子集

给定一个只包含正整数的非空数组 `nums`。判断是否可以将这个数组分割成**两个子集**，使得两个子集的**元素和相等**。

# 分析

**本质**：**装满容量为 `sum / 2` 的背包**。  
既然要把数组平分成两半，那么每一半的和一定是 `总和 / 2`。  
问题瞬间转化成了：“你能否从这些数字（物品）中挑出几个，让它们的和**刚好等于** `sum / 2`（背包容量）？”  
**前置拦截（天生残疾剪枝）**：
- 如果数组总和是**奇数**，绝对不可能平分出整数，连算都不用算，直接返回 `False`。  
**核心状态**： `dfs(idx, remain)` 面对第 `idx` 个数字时，距离凑齐目标和还差 `remain`。能否凑齐？  
**边界条件的判断**：
```python
if remain == 0: return True # 完美！刚好凑齐了
if idx == len(nums) or remain < 0: return False # 没数字了，或者加爆了（超重）
if (idx, remain) in memo: return memo[(idx, remain)] # 算过直接拿
```
**决策分支（状态转移）**：
- **路线 A（不选当前数字）**：额度不变。 `res = dfs(idx + 1, remain)`
- **路线 B（选当前数字）**：前提是当前额度够扣。 `res = dfs(idx + 1, remain - nums[idx])`
- **汇总**：只要有一种选法能成就算胜利！用 `or` 连接。 `res = 路线 A or 路线 B`
# 代码

```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total_sum = sum(nums)
        if total_sum % 2 !=0:
            return False

        target = total_sum //2
        memo = {}
        length = len(nums)
        def dfs(idx,remain):
			# 条件判断
            if remain ==0: return True
            if idx == length or remain < 0: return False

			# 记忆
            state = (idx,remain)
            if state in memo:
                return memo[state]
                
            res = dfs(idx+1,remain)
            # A 没有成功 可以选B路线
            if not res and remain >=nums[idx]:
                res = dfs(idx+1,remain - nums[idx])
			# 存储记忆
            memo[state] = res
            return res
        return dfs(0,target)

```
