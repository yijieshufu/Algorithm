# LC 474. 一和零 
给定一个二进制字符串数组 `strs` 和两个整数 `m` 和 `n`。

求 `strs` 的最大**子集长度**，要求该子集中最多有 `m` 个 `0` 和 `n` 个 `1`。

# 分析
**本质**：**双约束条件的 0-1 背包问题**。

每个字符串是一个“物品”，它有两个重量（0 的个数和 1 的个数），价值为 1（因为求的是数量）。

你有两个背包（0 的容量和 1 的容量），面对每个物品，你要决定“**选**”还是“**不选**”。

**核心状态**：  
	`dfs(idx, m_left, n_left)` 面对第 `idx` 个字符串时  
	手里还剩 `m_left` 个 0 的额度，以及 `n_left` 个 1 的额度  
	最多还能选几个字符串。  
**边界条件的判断**：
```python
if idx == len(strs): return 0 # 字符串都看完了，没有收益了
if (idx, m_left, n_left) in memo: return memo[(idx, m_left, n_left)] # 算过直接拿
```
**决策分支（状态转移）**：
- **路线 A（不选当前字符串）**：  
	额度不扣，收益为 0。  
	`res = dfs(idx + 1, m_left, n_left)`
- **路线 B（选当前字符串）**：  
	前提是当前的 `m_left` 和 `n_left` 够扣。收益为 1。  
	`res = max(res, 1 + dfs(idx + 1, m_left - 消耗的0, n_left - 消耗的1))`
# 代码
```python
class Solution:
    def findMaxForm(self, strs: List[str], m: int, n: int) -> int:
        memo = {}
        length = len(strs)
        def dfs(idx,m_limit,n_limit):
            if idx ==length:
                return 0 
            state = (idx,m_limit,n_limit)
            if state in memo:
                return memo[state]
				
            # 当前元素 0 和 1 的个数
            zeros = strs[idx].count('0')
            ones = len(strs[idx]) - zeros
            # 不选
            res = dfs(idx+1,m_limit,n_limit)
            # 选
            if m_limit>=zeros and n_limit>=ones:
                res = max(res,1+dfs(idx+1,m_limit-zeros,n_limit-ones))
            
            memo[state] = res # 保存结果
            return res
        return dfs(0,m,n)
```
