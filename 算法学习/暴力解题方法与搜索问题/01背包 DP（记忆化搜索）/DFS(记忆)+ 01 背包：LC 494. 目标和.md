# LC 494. 目标和

给你一个非负整数数组 `nums` 和一个整数 `target`。你可以向数组中的每个整数前添加 `+` 或 `-`，求能凑成 `target` 的不同表达式的数目。

# 分析
**本质**：**必选的 0-1 背包**。  
普通的背包是“选”与“不选”，而这道题是你**没有退路，必须选**。  
面对每一个数字，你的抉择变成了“加”还是“减”。  
因为求的是“一共有多少种走法”，所以最后要把两条路的方案数**加起来**。  
**核心状态**： `dfs(idx, current_sum)` 面对第 `idx` 个数字时，目前的累计和是 `current_sum`。  
从这里出发，还有多少种路径能走到最终的 `target`？

**边界条件的判断**：
```python
# 走完所有数字了，清点战果
if idx == len(nums): 
    return 1 if current_sum == target else 0 # 凑够了算1种方案，没凑够算0种
if (idx, current_sum) in memo: 
    return memo[(idx, current_sum)] # 算过直接拿
```

**决策分支（状态转移）**：
- **路线 A（给当前数字加正号）**： `res1 = dfs(idx + 1, current_sum + nums[idx])`
- **路线 B（给当前数字加负号）**： `res2 = dfs(idx + 1, current_sum - nums[idx])`
- **汇总**：把两条路的成功方案数相加。 `res = res1 + res2`
# 代码
```python
class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        memo = {}
        length = len(nums)
        def dfs(idx,current_sum):
			# 出口
            if idx == length:
                return 1 if current_sum == target else 0 
			# 记忆
            state = (idx,current_sum)
            if state in memo:
                return memo[state]
            # 计算 加减法的各种的 方案数
            add_ways = dfs(idx+1,current_sum + nums[idx])
            sub_ways = dfs(idx+1,current_sum - nums[idx])
            res = add_ways + sub_ways
			# 记忆
            memo[state] = res
            return res
        return dfs(0,0)
```
