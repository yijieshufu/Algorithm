# LC 402. 移掉 K 位数字

给定一个以字符串表示的非负整数 `num` 和一个整数 `k`，移除其中的 `k` 位数字，使得剩下的数字**最小**。不能有前导零。

# 分析

**本质**：**“削山头（消除逆序对）”**。

为了让数字最小，我们要保证高位的数字尽可能小。

如果发现出现“左边大、右边小”的断崖式下降（例如 `143` 里的 `4` 和 `3`），赶紧把左边那个大的（4）踢掉！

**核心逻辑拆解**：
1. **建立审查机制（单调栈）**：准备一个空栈，数字从左到右排队进栈。
2. **踢人规则（贪心）**：新来一个数字 `d` 时，盯着栈顶看。如果栈顶的数字**大于** `d`，说明栈顶占着高位且数值更大，是个“毒瘤”。  
	只要还有开除名额（`k > 0`），就无情地把栈顶 `pop` 掉！
3. **收尾工作**：
    - **没删够**：如果数字本来就是递增的（如 `12345`），前面没人可踢，那就把名额全用在最后，切掉尾巴（最大的那些数）。
    - **去前导零**：像 `10200` 删掉 `1` 后变成 `0200`，输出时必须把开头的 `0` 抹掉。

# 代码
```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        stack = []
        # 维护 单调栈
        for digit in num:
            while stack and k > 0 and stack[-1] > digit:
                stack.pop()
                k-=1
            stack.append(digit)
        if k>0: # 没有用完
            stack = stack[:-k]
        # 去除前导 0 
        res = "".join(stack).lstrip('0')
        return res if res else "0"
```
