# LC 670. 最大交换 
给定一个非负整数，你至多可以**交换一次**数字中的**任意两位**。返回你能得到的最大值。

# 分析
**本质**：**“绝对的权重压制”**。  
在十进制数字中，左边的位权重远远大于右边。  
哪怕用个位数的 `9` 去换千万位的 `8` 也是血赚。 

核心策略：**把尽可能大的数字，换到尽可能靠左（高位）的位置**。

如果有多个相同的较大数字（比如 `199`），选**最靠右**的那个（换成 `991` 大于 `919`），这样能让被换下来的小数字尽量垫底。

**核心逻辑拆解**：
1. **建立坐标系（找最后位置）**：遍历一次数字，记录每个数字 `0-9` **最后一次**出现的索引。
2. **从左向右贪心（占领高地）**：遍历数字的每一位。对于当前位，我们环顾四周，看看有没有比它**更大**的数字。
3. **查表匹配（必须在右边）**：从 `9` 开始往下查到 `当前数字 + 1`，如果找到了这个大数字，且它的最后出现位置在当前位置的**右边**，直接交换！
4. **一击脱离**：因为至多只能交换一次，换完之后立刻结束并返回。
# 代码

```python
class Solution:
    def maximumSwap(self, num: int) -> int:
        nums = list(str(num))
        # 覆盖原理 取最后的出现的位置
        last_idx = {int(val):i for i ,val in enumerate(nums)}
        # 从左向右
        for i,val in enumerate(nums):
            # 9 到 val + 1
            for d in range(9,int(val),-1):
                if last_idx.get(d,-1)>i: # 只选 比当前位置后面的树
                    nums[i] ,nums[last_idx[d]] = nums[last_idx[d]],nums[i] # 交换位置
                    return int("".join(nums))
        return num
```
