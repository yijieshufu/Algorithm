# 网格 DFS
## [[网格 DFS 回溯：N皇后]]
同行、同列、同斜线 仅一君
- a **列冲突**：直接用列索引 $i$。 a 
- f **正对角线 (/)**： $r + c$ 是常数。代码中为 `f[u + i]`。
- g **反对角线 ()**： $r - c$ 是常数。代码中为 `g[u - i + n]`。
```python
# 1. 占领（过河拆桥）
a[i] = f[u+i] = g[u-i+n] = 1 
# 2. 深入（探索下一行）
dfs(u + 1)
# 3. 撤销（恢复现场/回溯）
a[i] = f[u+i] = g[u-i+n] = 0
```
