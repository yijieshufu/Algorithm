# [扩散](https://www.lanqiao.cn/courses/52517/learning/?id=5126259&compatibility=false)
- **核心动作**：在二维网格中，给定 4 个初始黑点，每分钟向四周扩散 1 格，求 2020 分钟后黑点的总数。
- **本质**：求 4 个以初始点为中心、曼哈顿距离 $L_1 \le 2020$ 的**正方形（旋转 45° 的菱形）并集的格点数**。
- **关键数据**：初始点 $P_1(0,0), P_2(2020,11), P_3(11,14), P_4(2000,2000)$；时间 $T=2020$。
# 分析
### **数学本质：曼哈顿距离**
扩散规则规定每分钟走一格且只能沿坐标轴移动，这本质上是**曼哈顿距离**（$L_1$ 距离）的体现。
- 如果一个格子 $(x, y)$ 到任意一个初始点 $(p_x, p_y)$ 的曼哈顿距离满足以下公式，则该格子在 $t$ 分钟后必然变黑：  
    $$|x - p_x| + |y - p_y| \le t$$
## 代码
```python
import sys
pts = [(0, 0), (2020, 11), (11, 14), (2000, 2000)]
t = 2020
ans = 0
x_range = range(-2020, 2020 + 2020 + 1)
y_range = range(-2020, 2000 + 2020 + 1)
for x in x_range:
    for y in y_range:
        for px, py in pts:
            if abs(x - px) + abs(y - py) <= t:
                ans += 1
                break 
print(ans) 
```
