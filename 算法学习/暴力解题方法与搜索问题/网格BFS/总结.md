# 多源
## [[BFS+多源：LC 542. 01 矩阵]]
从全图所有的 0 同时出发向外波纹扩散，计算每个 1 被“浪潮”拍到的最早时间（最短距离）。  
**多源 BFS 逆向染色。**
- **多源初始化**：不从 1 找 0，而是把所有 0 看作**同步出发**的起点。
- **层级扩散**：利用队列 `a` 保证扩散是按距离 $1, 2, 3...$ 顺序进行的。
- **原地标记（`ans` 矩阵）**：
    - `ans` 初始设为 `-1`，既代表“无穷远”，也充当了 `visited` 数组的功能。
    - **核心逻辑**：只要邻居是 `-1`，它就是第一次被波纹触碰到，此时的距离 `ans[r][c] + 1` 绝对是最短的，更新后立即入队封死，绝不回头。  
**最关键的代码行：**
```python
ans[f][g_v] = ans[r][c] + 1 # 触碰瞬间即最短，更新距离并标记已访问
```

## [[BFS+多源：LC 994. 腐烂的橘子]]
从全图所有**腐烂源**同时开启“传染模式”，看波纹同步**扩散多少层**能覆盖掉所有新鲜橘子。

**多源起点（Multi-source）同步扩散的 BFS。**
- **多源同步**：不同于普通 BFS 只有一个起点，这道题初始就把所有 `2` 塞进队列。这相当于在地图上同时点燃了多个火苗，它们会步调一致地向外延烧。
- **层级即时间**：队列 `a` 里的 `ans` 记录了当前扩散到的“波纹层数”。因为 BFS 保证了每一层都是最短路径，所以最后传染到的那个橘子所花的层数，就是全图腐烂的最短时间。
- **原地标记与计数**：
    - 通过 `g[ni][nj] = 2` **原地爆破**，省去了 `visited` 数组。
    - 通过 `f` 记录新鲜橘子总数。如果最后 `f > 0`，说明有橘子处于“孤岛”，波纹传不过去，直接判定为 `-1`。

```python
g[ni][nj] = 2 # 过河拆桥：标记已访问并改变状态，防止重复入队
a.append((ni,nj,ans+1)) # 步步为营：时间随层数逻辑自然增长
```

# 单源 VS 多源

| **维度**   | **单源 BFS (Single-Source)** | **多源 BFS (Multi-Source)** |
| -------- | -------------------------- | ------------------------- |
| **初始化**  | 队列 `a` 只压入 **1个** 起点。      | 队列 `a` 循环压入 **N个** 起点。    |
| **距离本质** | 计算 **起点 A** 到终点 B 的最短路。    | 计算 **最近的起点** 到终点 B 的最短路。  |
| **原地爆破** | 只封死 1 个起点的路。               | 必须在入队时封死 **所有** 起点的路。     |
| **波纹扩散** | 像一颗石子丢进水里，产生一个圆。           | 像多颗石子同时丢进水里，产生多个交织的圆。     |
