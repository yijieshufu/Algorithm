# 五子棋对弈
- **棋盘规模**：$5 \times 5$ 的方格棋盘，共 **25 个格子**。
- **棋子分配**：白棋（先手）与黑棋轮流落子。当棋盘填满时，**白棋占 13 子，黑棋占 12 子**。
- **胜利条件**：在横线、竖线或斜线上形成**连续五个**同色棋子。
- **平局定义**：棋盘下满 25 子，且没有任何一方达成五连珠。
- **任务**：计算所有可能的平局棋局总数。
# 分析
- **状态空间**：这是一个典型的组合问题。我们需要从 25 个位置中选出 13 个放白棋，剩下的 12 个放黑棋。总组合数为：  
    $$C_{25}^{13} = \frac{25!}{13!12!} = 5,200,300$$  
    这个规模在 Python 中使用 `itertools.combinations` 可以在 10 秒左右完成遍历。
- **判定目标（12 条胜线）**：
    - **横线**：5 条（每行一个集合）。
    - **竖线**：5 条（每列一个集合）。
    - **对角线**：2 条（主对角线与副对角线）。
- **逻辑本质**：
    1. 生成所有 $C_{25}^{13}$ 种白棋布局。
    2. 对于每种布局，检查这 12 条“胜线”集合。
    3. 如果某条胜线是白棋集合的**子集**，或者它是黑棋集合的**子集**，则该布局不是平局。
    4. 否则，计数器 `ans += 1`。
## 代码
```python
import os
import sys
import itertools

# 1. 预处理 获胜线
lines =[] # 胜利集合
#行
for i in range(0,25,5):
  lines.append((set(range(i,i+5))))
#列
for j in range(5):
  lines.append((set(range(j,25,5))))  # 存入的集合
#对角线
lines.append({0,6,12,18,24})
lines.append({4,8,12,16,20})
all_pos = set(range(25))
ans = 0 
# 2. 白棋 combinations
for write in itertools.combinations(range(25),13):
  w_set=set(write) # 白色集合
  b_set=all_pos-w_set # 剩下的是黑色集合
  is_draw = True # 预定平局
  for line in lines:
    if line<= w_set or line<= b_set: # 黑或者白 有个是胜利 集合
      is_draw =False
      break
  if is_draw:ans+=1 
print(ans)
```
