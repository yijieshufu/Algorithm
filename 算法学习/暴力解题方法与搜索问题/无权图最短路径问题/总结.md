## [[逆向 BFS+附加边+一维映射：迷宫]]

随机开始  
	计算到终点的 期望  
	加个传送门

**一维平铺与极速切片**  
Python 的二维列表 `g[r][c]` 寻址极慢。  
直接加跨度 `s = n+2` 转为一维数组 `g[u]`。
```python
for i in range(1,n+1):
    start = i*s + 1
    g[start:start+n] = [-1] * n
```

**极简字典构图**  
抛弃二维表存传送门，使用字典 `p` 按需分配。
```python
    p[u] = p.get(u,[]) + [v] # 极简双向链存边
```

**哨兵逻辑（绝对性能红线）**  
外圈默认值为 `-2`，核心区域为 `-1`。  
BFS 扩散时，无需任何坐标范围校验（直接干掉 `if 1<=r<=n` 这种废话），撞墙自然会被 `-1` 过滤。
```python
    for o in (1,-1,-s,s):
        v = u + o
        if g[v] ==-1: # 哨兵发威，无越界判断
            g[v] = d_next
            q.append(v)
```
