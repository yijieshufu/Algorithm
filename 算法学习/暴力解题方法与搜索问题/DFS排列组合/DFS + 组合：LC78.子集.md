# LC78.子集
- **输入**：一个整数数组 `nums`，其中元素 **互不相同**。
- **任务**：返回该数组所有可能的子集（幂集）。
- **规则**：解集不能包含重复的子集。
- **数据规模**：$n \le 10$，非常小，适合 DFS。

# 分析
这是理解子集问题的关键：
- **组合问题**（如组合总和）：通常有一个目标（凑够 $k$ 个数或者凑够一个 $target$），只有走到递归树的特定深度才收集结果。
- **子集问题**：**递归树上的每一个节点都是一个答案！**
    - 空集 `[]` 是答案（根节点）。
    - 只有一个数的 `[1]` 是答案。
    - 有两个数的 `[1, 2]` 也是答案。  
**本质逻辑：**
1. **收集时机**：只要进入 `dfs` 函数，不设任何前提条件，直接把当前的 `path` 存入结果。
2. **搜索起点**：为了防止搜出 `[1, 2]` 之后又搜出 `[2, 1]`，依然使用 `begin` 变量控制“只许向后看”。
3. **不能重复**：每个数字只能选一次，所以递归传 `i + 1`。
# 代码
```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        res = []
        path = []
        n = len(nums)
        def dfs(begin):
            res.append(path[:]) # 每一个节点都是答案
            for i in range(begin,n):
                path.append(nums[i])
                dfs(i+1)
                path.pop()
        dfs(0)
        return res
```
