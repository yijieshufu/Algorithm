# LC46全排列
- **输入**：一个不含重复数字的数组 `nums`（例如 `[1, 2, 3]`）。
- **任务**：返回该数组所有可能的**全排列**。
- **输出**：结果可以按任意顺序返回。
- **数据规模**：数组长度 $1 \le n \le 6$。这个规模非常小，意味着我们可以放心地使用指数级复杂度的搜索算法。
# 分析
要把全排列写对，脑子里必须有一棵**决策树**。  
以 `nums = [1, 2, 3]` 为例，我们有三个坑位要填：
1. **第一层（填第一个坑）**：你有 3 种选择：`1` 或 `2` 或 `3`。
2. **第二层（填第二个坑）**：如果你刚才选了 `1`，那现在只能选 `2` 或 `3`。
3. **第三层（填第三个坑）**：如果你刚才选了 `1, 2`，那现在只能选 `3`。  
**本质逻辑：**
- **状态控制**：我们需要一个 `used` 数组来标记哪些数字已经被填入路径了。
- **回溯还原**：当我们从深层递归“爬”回上层时，必须把刚才占用的数字“释放”掉，这样它才能被其他分支选择。
# 代码
```python
class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        res = []
        n = len(nums)
        path = []            # 动态口袋
        used = [False] * n   # 标记下标 0~n-1 是否被用过
        def dfs():
            # 第一步：判定边界
            if len(path) == n:
                # 关键：存入结果时要拍快照 [:]
                res.append(path[:]) 
                return
            # 第二步：遍历选项 (遍历数组下标)
            for i in range(n):
                if not used[i]:
                    # 第三步：做选择
                    used[i] = True
                    path.append(nums[i]) # 塞入数组里的值
                    dfs()
                    # 第四步：回溯撤销
                    path.pop()
                    used[i] = False
        dfs()
        return res
```
