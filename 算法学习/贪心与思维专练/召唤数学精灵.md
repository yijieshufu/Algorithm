# 召唤数学精灵-真题
寻找满足 $(A(i) - B(i)) \pmod{100} = 0$ 的 $i$ 的个数。
- $A(i) = 1 + 2 + \dots + i = \frac{i(i+1)}{2}$
- $B(i) = 1 \times 2 \times \dots \times i = i!$
## 分析
### 1. 是什么：本质结构 (What)
该问题的本质是将一个极其复杂的序列拆解为两个部分：
- **瞬态阶段（Transient Phase）**：$i$ 较小时，所有项都在剧烈变化，必须暴力检查。
- **稳态阶段（Steady Phase）**：由于模运算的特性，其中一项（阶乘）直接“自毁”变为 $0$，另一项（累加和）进入“时钟式”的周期循环。
---
### 2. 为什么：逻辑支撑 (Why)
#### ① 阶乘的“坍缩” (The Collapse of $B(i)$)
在模 $M$ 的环境下，只要 $i$ 足够大，使得 $i!$ 包含了 $M$ 的所有质因子，那么对于之后所有的 $i$，$B(i) \equiv 0 \pmod M$。
- **具体到本题**：$100 = 2^2 \times 5^2$。
- 当 $i=10$ 时，$10!$ 刚好凑够了两个 $2$ 和两个 $5$，所以从 $i=10$ 开始，$B(i)$ 彻底消失。
#### ② 累加和的“时钟性” (The Periodicity of $A(i)$)
$A(i) = \frac{i(i+1)}{2}$ 是一个关于 $i$ 的二次函数。在模运算下，多项式序列一定存在周期。
- **周期判定**：我们需要找到 $i$ 使得 $\frac{i(i+1)}{2} \equiv 0 \pmod{100}$，即 $i(i+1)$ 是 $200$ 的倍数。
- **结论**：这个“数学时钟”的刻度盘大小（周期）是 **200**。  

**计算200周期内：**
```python
for  i in  range(1,201):  
    if (i*(i+1))%200==0:  
        print(i)
```

计算 1-10之间的答案
```python
b = 1  # 存放阶乘 i!，初始为 1!ans = []  
# 3.操作  
for i in range(1, 11):  
    # A(i) = i*(i+1)//2  
    a = i * (i + 1) // 2  
  
    # 核心判定：(A(i) - B(i)) % 100 == 0  
    if (a - b) % 100 == 0:  
        ans.append(i)  
  
    # 为下一轮准备：(i+1)! = i! * (i+1)  
    b *= (i + 1)  
# 4.答案  
print(ans)
```

## 变体一：幂次精灵（幂次项的周期律）
**【题目描述】**  
寻找满足 $(i + 3^i) \pmod{10} = 0$ 的 $i$ 的个数，其中 $i \in [1, 20240413]$。  
**【数学本质：双周期叠加】**
1. **$i \pmod{10}$ 的周期**：显然是 **10**。
2. **$3^i \pmod{10}$ 的周期**：观察：$3^1=3, 3^2=9, 3^3=7, 3^4=1, 3^5=3 \dots$。周期是 **4**。
3. **总周期**：$LCM(10, 4) = 20$。  
**【极简代码逻辑】**
```python
import sys
n = 20240413
ans = 0
# 1. 寻找 20 周期内的满足点
points = []
for i in range(1, 21):
    if (i + pow(3, i, 10)) % 10 == 0:
        points.append(i)

# 2. 批量计算
q, r = n // 20, n % 20
ans = q * len(points)
for x in points:
    if x <= r:
        ans += 1
print(ans)
```
## 变体二：组合精灵（阶乘与多项式的复合）
**【题目描述】**  
寻找满足 $(i! + i^2) \pmod{7} = 0$ 的 $i$ 的个数，其中 $i \in [1, 10^{12}]$。  
**【数学本质：消失点 + 二次剩余】**
- **消失点 (Vanishing Point)**：  
    当 $i \ge 7$ 时，$i!$ 中必然包含因子 $7$，因此 $i! \equiv 0 \pmod 7$。  
    此时原式坍缩为：$0 + i^2 \equiv 0 \pmod 7 \implies i^2 \equiv 0 \pmod 7$。
- **二次剩余稳态**：  
    由于 $7$ 是质数，满足 $i^2$ 是 $7$ 的倍数的唯一条件是 $i$ 本身是 $7$ 的倍数。  
    这意味着在 $i \ge 7$ 的**稳态阶段**，满足条件的 $i$ 分布为：$7, 14, 21, 28, \dots$。
- **瞬态阶段**：  
    对于 $i \in [1, 6]$，阶乘尚未“消失”，必须暴力枚举。  
**【极简代码逻辑】**
```python
import sys
# 1.变量
# 题目给定范围 n = 10**12
n = 10**12
ans = 0
# 2.瞬态检查 (i从1到6)
# 手算/代码跑出：只有 i=6 时 (720+36)=756 能被7整除
b = 1 # 存放 i!
for i in range(1, 7):
    if (b + i * i) % 7 == 0:
        ans += 1
    b = (b * (i + 1)) % 7

# 3.稳态计算 (i从7到n)
# 在这个区间内，只要 i 是 7 的倍数就满足条件
# [1, n] 范围内 7 的倍数个数为 n // 7
# 因为 [1, 6] 里面没有 7 的倍数，所以 n // 7 全部落在 [7, n] 区间内
ans += n // 7
# 4.答案
print(ans)
```
