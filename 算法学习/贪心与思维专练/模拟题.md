# 劲舞团-真题

如果连续 K 次敲击中，**任意相邻两次敲击的时间间隔都不超过 1 秒（≤1s）**，那么这就算一次“K连击”。  
现在给你一份游戏记录文件 `log.txt`，里面包含 N 条记录，每条记录有三个字段：
- 正确的敲击字符
- 小蓝实际打出的字符
- 打出该字符的毫秒级时间戳  
你的任务是：**找出最长的 K 连击长度，并输出这个 K 值。**
## 代码

```python
import sys

# 块 1：极简 I/O 起手式 (针对赛场标准输入)
it = iter(sys.stdin.read().split())
# 若是读取文件则换为: it = iter(open("log.txt").read().split())
ans = 0
cur = 0
pre_t = -2000 # 初始化为极小值，确保第一笔匹配时 t - pre_t > 1000
while True:
    try:
        tar = next(it)
        usr = next(it)
        t = int(next(it))
        # 块 2：核心推导 - 分情况讨论状态转移
        if tar == usr:
            if t - pre_t <= 1000:
                cur += 1 # [认知块：连击延续]
            else:
                cur = 1  # [认知块：对字但超时，重开连击]
            pre_t = t
            if cur > ans: ans = cur # [认知块：步步更新最大值]
        else:
            cur = 0 # [认知块：错字，连击彻底中断]
    except StopIteration:
        break
print(ans)
```
# 抽奖-真题
**难度评分**：⭐⭐（基础入门） **考频程度**：⭐⭐⭐⭐⭐（**省赛必考**，通常出现在前 3 题）  
**核心设定**：
- **结构**：3个转轮，数字 $1 \sim n$，初始位置均为 $1$。
- **移动**：进行 $m$ 轮，每轮各转轮在**当前位置**基础上向后拨动 $x_{j}$ 次（循环转动）。  
**计分规则 (单次取最高分)**：
- **200分**：
    1. 三数全等 (如 `5, 5, 5`)
    2. 顺序连续 (如 `1, 2, 3`)
- **100分**：
    1. 仅二数相等 (如 `5, 5, 2`)
    2. 乱序连续 (如 `2, 1, 3` 或 `3, 2, 1`)

**目标**：计算 $m$ 轮后的累计总积分。
## 代码

```python
import os
import sys

it = iter(sys.stdin.read().split())

n = int(next(it))
a = [int(next(it)) for _ in range(n)]
b = [int(next(it)) for _ in range(n)]
c = [int(next(it)) for _ in range(n)]
p0,p1,p2=0,0,0
m = int(next(it))
ans = 0
for _ in range(m):
  p0 = (p0+int(next(it)))%n
  p1 = (p1+int(next(it)))%n
  p2 = (p2+int(next(it)))%n
  score = 0
  if a[p0]==b[p1]==c[p2]:
    score = max(score,200)
  if a[p0]==b[p1] or a[p0]==c[p2] or b[p1]==c[p2]:
    score = max(score,100)
  if a[p0]+1==b[p1] and b[p1]+1 ==c[p2]:
    score = max(score,200)
  s = sorted([a[p0],b[p1],c[p2]]) 
  if s[0]+1==s[1] and s[1]+1==s[2]:
    score = max(score,100)
  ans +=score
print(ans)
```
# LQ图形
### 问题描述
小蓝要为蓝桥画一个图形。由于小蓝的画图能力有限，他准备用大写字母 $Q$ 画一个 $L$ 形状的字符画。  
他希望 $L$ 的粗细正好是 $w$ 个字符宽，竖的笔划伸出 $h$ 高（因此图形总共 $h + w$ 高），横的笔划伸出 $v$ 宽（因此图形总共 $v + w$ 宽），要求每个笔划方方正正不能有多余内容。  
例如，当 $w = 2, h = 3, v = 4$ 时，图形如下所示：
```Plaintext
QQ
QQ
QQ
QQQQQQ
QQQQQQ
```
给定 $w, h, v$，请帮助小蓝画出这个图形。
```python
import sys
# 请在此输入您的代码
it = iter(sys.stdin.read().split())
w=int(next(it))
h=int(next(it))
v=int(next(it))
for _ in range(h):
  print('Q' * w)
for _ in range(w):
  print('Q' * (w + v))
```
