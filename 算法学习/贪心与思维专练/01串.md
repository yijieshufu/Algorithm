# 01串-真题
将数字 $0, 1, 2, 3 \dots$ 的二进制形式按顺序拼接在一起，形成一个**无限长**的字符串（如：$0, 1, 10, 11, 100 \dots$ 拼成 `011011100...`）。给定一个位置 $x$，求该字符串前 $x$ 位中有多少个数字 `1`。
# 分析
暴力解法的核心是**逐个模拟数字的生成与拼接**。
1. **逐个产生数字**：从 $i=0$ 开始，依次向上累加。
2. **二进制转换**：利用 Python 内置的 `bin(i)` 函数。注意 `bin()` 返回的是以 `0b` 开头的字符串，所以需要 `bin(i)[2:]` 来截取纯二进制部分。
3. **长度监控**：
    - 维护一个 `now_len` 变量记录当前已经拼接了多少位。
    - 每一轮将新数字的长度 `bit_l` 累加到 `now_len`。
4. **边界处理（最关键）**：
    - 如果 `now_len + bit_l` 超过了目标位置 $x$，说明这个数字**只有一部分**属于前 $x$ 位。
    - 此时只截取该二进制串的前 `x - now_len` 位，统计其中的 `1`，然后结束循环。
# 代码
```python
import sys

it = iter(sys.stdin.read().split())
target = int(next(it))  
ans = 0                
now_len = 0            
i = 0                
while True:
    bin_s = bin(i)[2:] 
    bit_l = len(bin_s)  
    if now_len + bit_l >= target:
        need = target - now_len
        ans += bin_s[:need].count('1')
        break 
    ans += bin_s.count('1')
    now_len += bit_l
    i += 1
print(ans)
```
