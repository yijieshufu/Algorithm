# 01串-真题
将数字 $0, 1, 2, 3 \dots$ 的二进制形式按顺序拼接在一起，形成一个**无限长**的字符串（如：$0, 1, 10, 11, 100 \dots$ 拼成 `011011100...`）。给定一个位置 $x$，求该字符串前 $x$ 位中有多少个数字 `1`。
- **题型**：**数位统计 + 二分查找** 
- **难度**：⭐⭐⭐⭐ (中等偏难)
- **蓝桥杯地位**：**高频必备题**。对于 $x \le 10^{18}$ 的规模，任何线性模拟都会超时，必须使用对数级别的算法。
## 01 串数位统计：分块统计本质
### 一、 结构的本质：等长数字块
我们将所有二进制数按 **长度 $L$** 分组，每一组都是一个独立的“数据块”。
- **$L=1$ 组**：$[0, 1]$（注：$0$ 为特殊项占 $1$ 位，真正起点从 $2^0=1$ 开始）
- **$L=2$ 组**：$[2^1, 2^2-1] \implies [10_2, 11_2] \implies [2, 3]$
- **$L=3$ 组**：$[2^2, 2^3-1] \implies [100_2, 111_2] \implies [4, 7]$
> **核心结论：**  
> 第 $L$ 组共有 **$2^{L-1}$** 个数，且每个数刚好有 **$L$** 位。  
> **每一组的总长度** = 个数 $\times$ 位数 = **$L \cdot 2^{L-1}$**
---
### 二、 计数本质：首位孤立 + 余位对称
在计算一个完整组内 $1$ 的总数时，可以拆解为两部分进行“降维打击”：
#### 1. 首位（Most Significant Bit）：绝对存在
在第 $L$ 组中，所有数字的二进制首位（最高位）永远是 $1$。
- **贡献**：$2^{L-1} \times 1 = \mathbf{2^{L-1}}$ **个 1**。
#### 2. 后续位（Remaining Bits）：完美对称
剩下的 $L-1$ 个位置，其数字分布遵循完全对称性。
- **逻辑**：在从全 $0$ 到全 $1$ 的组合中，$0$ 和 $1$ 的出现概率严格为 $1:1$。
- **总槽位**：$(L-1) \cdot 2^{L-1}$（剩余位数 $\times$ 数字个数）。
- **贡献**：因为一半是 $1$，所以是 $\frac{(L-1) \cdot 2^{L-1}}{2} = \mathbf{(L-1) \cdot 2^{L-2}}$ **个 1**。
### 三、 组内总计公式
将上述两部分合并，第 $L$ 组内 $1$ 的总数为：  
$$\text{Ones}(L) = 2^{L-1} + (L-1) \cdot 2^{L-2}$$
## 代码
```python
import sys

it = iter(sys.stdin.read().split())
X = int(next(it))
# 计算 0 到 n 数字 拼接后 的 总长度
def get_len(n):
    if n < 0: return 0
    res = 1 # 数字 0 占 1 位
    if n == 0: return res
    l, r, bit = 1, 1, 1  # l,r位数的起点  bit这层数有多少位
    while r <= n:
        res += (r - l + 1) * bit  # 个数 * 每个数的位数 = 长度
        bit += 1 #进行下一层的数
        l = r + 1 # 下一层的起点是上一层的终点+1
        r = (l << 1) - 1 # 下一层的终点 是 起点左移1位再-1
    if l <= n:
        res += (n - l + 1) * bit  # 剩下的长度
    return res
# 计算 0 到 n 中所有二进制位 1 的个数 (经典 $O(\log n)$ 算法)
def get_ones(n):
    if n <= 0: return 0
    res = 0
    # 统计每一位上 1 出现的频率
    for i in range(62): # x<10**18  二进制大概是60位 开62位
        cycle = 1 << (i + 1)  # 第i位的二进制的周期变化
        res += (n + 1) // cycle * (cycle // 2) # 整周期里面的1
        res += max(0, (n + 1) % cycle - (cycle // 2)) # 剩余周期里面的1
    return res

# 1. 二分查找：找到第 X 位所在的那个数字 N
low, high = 0, X
N = high  # N 要确定的 假设最大为X 很安全 要找的数 肯定是小于X的
while low <= high:
    mid = (low + high) // 2
    if get_len(mid) >= X: # get_len() 获取的是总的长度 也就是拼接的二进制
        N = mid #找到那个数了
        high = mid - 1 # 范围大了
    else:
        low = mid + 1 # 范围小了

ans = get_ones(N - 1) # 0到N-1之前的1
rem = X - get_len(N - 1) # 剩下N这个数的 二进制的数
# 将 N 转为二进制字符串（去掉 '0b'）
s_n = bin(N)[2:]
# 如果是数字 0，特殊处理
for i in range(rem):
    if s_n[i] == '1':
        ans += 1
print(ans)
```
## 暴力法：纸带填色实验 (以 $X=7$ 为例)
想象你有一条无限长的纸带，上面划好了格子。你的任务是按顺序把数字的二进制写进去，直到填满第 **7** 个格子。
### 1. 填色过程拆解
- **数字 0**：二进制 `"0"`，占 **1** 格。
    - 纸带：`[0]` (当前总长 1，含 1 量 0)
- **数字 1**：二进制 `"1"`，占 **1** 格。
    - 纸带：`[0 | 1]` (当前总长 2，含 1 量 1)
- **数字 2**：二进制 `"10"`，占 **2** 格。
    - 纸带：`[0 | 1 | 1 | 0]` (当前总长 4，含 1 量 2)
- **数字 3**：二进制 `"11"`，占 **2** 格。
    - 纸带：`[0 | 1 | 1 | 0 | 1 | 1]` (当前总长 6，含 1 量 4)
- **数字 4**：二进制 `"100"`，占 **3** 格。
    - **⚠️ 紧急刹车**：如果全填进去，总长就变成 9 了，超过了目标 7。
    - **动作**：我们只需要再填 **$7 - 6 = 1$** 格。
    - **切割**：只取 `"100"` 的第 1 位，即 `"1"`。
    - 纸带最终状态：`[0 | 1 | 1 | 0 | 1 | 1 | 1]`
### 2. 结算
数一数填好的纸带里有多少个 `1`：一共 **5** 个。这就是暴力法的全部逻辑。
### 代码
```python
import sys
# 1. 变量
it = iter(sys.stdin.read().split())
target = int(next(it))  
ans = 0                
now_len = 0            
i = 0                  # 当前数字
# 3. 操作
while True:
    bin_s = bin(i)[2:] 
    bit_l = len(bin_s) 
    # 判定：如果加上这个数，纸带是否会“溢出”？
    if now_len + bit_l >= target:
        # 溢出了！算出最后还缺几个格子才能到 target
        need = target - now_len
        # 只数这个数字“前 need 位”里面的 1
        ans += bin_s[:need].count('1')
        break # 填满了，收工
    # 没溢出：整块吞掉，继续往前走
    ans += bin_s.count('1')
    now_len += bit_l
    i += 1
# 4. 答案
print(ans)
```
