# 翻转-真题
**1. 核心规则（孤岛翻转）**：
- 如果一个棋子与它两边的棋子颜色都不一样（即 `101` 中的 `0` 或 `010` 中的 `1`），它就是一个 **“孤岛”**。
- 你可以将这个“孤岛”翻转成与之邻居相同的颜色（$101 \to 111$ 或 $010 \to 000$）。
- 注意：这种操作只能让孤岛消失，**无法凭空创造孤岛**。  
**2. 约束条件**：
- **边缘不动**：第一个和最后一个棋子由于没有两个邻居，永远无法触发翻转。
- **不可传递性**：翻转一个棋子会改变其邻居是否为“孤岛”的状态。如果两个相邻的棋子都需要翻转，一旦翻转了其中一个，另一个就可能不再是“孤岛”，从而导致无法翻转。  
**3. 目的**：

计算将 $S$ 变为 $T$ 的最少翻转次数。如果无法完成转换，输出 `-1`。
## 分析
### 1. 核心判定逻辑：孤岛准则
在二进制串中，一个位想要从 $S_i$ 变成 $T_i$，必须同时满足两个“环境条件”：
- **在 $S$ 中它是“异类”**：$S_i$ 与左右邻居都不同（即 $S_{i-1} \neq S_i$ 且 $S_{i+1} \neq S_i$）。
- **在 $T$ 中它是“同类”**：翻转后的结果必须与邻居打成一片（即 $T_i = T_{i-1}$ 且 $T_i = T_{i+1}$）。
> **直观理解**：规则只允许你通过“被同化”来改变颜色。如果你翻转后在目标态 $T$ 里依然是个孤岛，那这个操作在逻辑上是无法起步的。
### 2. 绝对红线：判定为 `-1` 的情况
只要遇到以下任何一种情况，直接判定为不可能完成转换：

| **失败类别** | **具体表现**                                | **逻辑原因**                  |
| -------- | --------------------------------------- | ------------------------- |
| **边缘锁死** | $S[0] \neq T[0]$ 或 $S[n-1] \neq T[n-1]$ | 首尾没有两个邻居，永远成不了“孤岛”。       |
| **结构稳固** | $S_i$ 想变，但它在 $S$ 里有同色邻居。                | 不是孤岛，不满足触发翻转的物理条件。        |
| **目标违和** | $S_i$ 变完后，在 $T$ 中成了新的孤岛。                | 翻转只能消灭孤岛，不能在目标态创造孤岛。      |
| **相邻冲突** | $S_i$ 和 $S_{i+1}$ 同时想变。                 | 只要翻了其中一个，另一个的“孤岛”环境立刻被破坏。 |
## 代码
```python
import sys

# 1.变量
it = iter(sys.stdin.read().split())
g = int(next(it)) # 组数 D

# 3.操作
for _ in range(g):
    a = next(it) # 目标串 T
    b = next(it) # 初始串 S
    n = len(a)
    ans = 0
    f = 0 # 标记位
    
    # 2.边界
    # 首尾不同则绝无可能翻转成功
    if a[0] != b[0] or a[n-1] != b[n-1]:
        print("-1")
        continue
    
    # 线性扫描中间位
    for m in range(1, n - 1):
        if a[m] != b[m]:
            # 孤岛判定：b中是孤岛 且 a中不是孤岛
            if b[m] != b[m-1] and b[m] != b[m+1] and a[m] == a[m-1] and a[m] == a[m+1]:
                ans += 1
            else:
                f = 1
                break
                
    # 4.答案
    if f == 1:
        print("-1")
    else:
        print(ans)
```
