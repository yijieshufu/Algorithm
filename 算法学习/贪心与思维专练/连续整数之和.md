# 数字诗意-真题

- 一个数 $S$ 如果能表示为 **$\ge 2$ 个连续正整数**之和，它就是“诗意”的。
- 例子：$6 = 1 + 2 + 3$（诗意）；$8$ 无法表示（不诗意）。
- 给定 $n$ 个数。
- **目标**：删除所有“不诗意”的数。
- **最终要求**：输出**需要删除的数字个数**。
## 分析
**隐藏的数学规律（破题关键）：**
- **结论**：一个正整数如果是 **2 的幂次**（即 $1, 2, 4, 8, 16, \dots$），它就**不**能表示为连续正整数之和。
- **原因**：连续整数之和的公式要求该数必须有一个**奇因子**（大于 1）。而 2 的幂次只有 2 这个质因子，没有奇因子。
```python
import os
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
res = 0
for _ in range(n):
  a = int(next(it))
  if a>0 and (a&(a-1))==0:
    res+=1
print(res)
```

# 可分解的正整数-真题  

**1. 核心条件 (Conditions)**
- **序列构成**：公差为 $1$ 的连续整数（如 $\dots, -1, 0, 1, 2, \dots$）。
- **长度约束**：序列项数 $k \ge 3$。
- **目标要求**：序列总和等于给定的正整数 $A_i$。  
**2. 目的 (Purpose)**
- 统计给定的 $N$ 个正整数中，有多少个数字可以被拆解为满足上述条件的序列。
## 分析
- **对称抵消法**：对于任何正整数 $A$，我们都可以构造序列 $[-(A-1), \dots, A-1, A]$。
    - 前 $2A-1$ 项（从 $-(A-1)$ 到 $A-1$）正好关于 $0$ 对称，**总和为 $0$**。
    - 最后一项是 $A$，所以全序列总和为 $A$。
- **判定结论**：上述构造序列的长度为 $2A$。
    - 若 $A=1$，长度为 $2$（不符）。
    - 若 $A \ge 2$，长度 $\ge 4$（符合长度 $\ge 3$ 的要求）。
- **结论**：**只要 $A_i > 1$，该数即为“可分解”的。**

# 🏆 知识点：连续整数之和 (Sum of Consecutive Integers)

### 1. 数学本质：因子分解

对于任何整数 $n$，若能表示为 $k$ 个连续整数之和（设首项为 $a$），其本质受等差数列求和公式约束：

$$2n = k(2a + k - 1)$$

**核心观察：** 因子 $k$ 与 $(2a + k - 1)$ 的**奇偶性永远相反**（一奇一偶）。这意味着 $2n$ 的分解式中必须包含一个**大于 1 的奇数因子**。

---

### 2. 核心判别准则 (Decision Matrix)

在竞赛中，根据**数域限制**的不同，结论分为以下两个变体：

|**考点变体**|**序列约束**|**判定准则**|**物理意义**|
|---|---|---|---|
|**变体 A：正整数域**|项数 $k \ge 2$<br><br>  <br><br>首项 $a \ge 1$|**$n$ 不是 $2$ 的幂**<br><br>  <br><br>($n \neq 2^x$)|**奇因子驱动**：必须存在大于 1 的奇因子作为序列的“中心”或“平衡点”。|
|**变体 B：全整数域**|项数 $k \ge 3$<br><br>  <br><br>首项 $a \in \mathbb{Z}$|**$n > 1$**|**对称抵消驱动**：利用负数与正数抵消，通过拉长序列强行凑出 $n$。|
### 3. 原理解析与构造逻辑

#### A. 为什么 $2^x$ 不能由“正整数”凑出？
- **逻辑**：$2^x$ 的所有因子（除 1 外）全是偶数。
- **结果**：在公式 $2n = k(2a + k - 1)$ 中，无法拆解出一奇一偶且奇数 $>1$ 的组合，因此正整数序列无法闭环。
#### B. 为什么“全整数”环境下 $2^x$ 可以凑出？
- **对称构造法**：对于任何 $n \ge 2$，构造序列 $[-(n-1), \dots, 0, \dots, n-1, n]$。
- **抵消原理**：前 $2n-1$ 项关于 0 对称抵消为 0，总和即为最后一项 $n$。
- **长度验证**：该序列长度为 $2n$。当 $n \ge 2$ 时，长度 $\ge 4$，完美符合 $k \ge 3$ 的要求。
