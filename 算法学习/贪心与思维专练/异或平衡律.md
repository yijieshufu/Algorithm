# 电池分组-真题
将 $N$ 个能量电池（能量值为 $A_i$）分成**两组**，要求每组**至少一个**电池，且两组的**能量异或和相等**。
## 分析
设第一组电池的异或和为 $X$，第二组电池的异或和为 $Y$。  
题目要求：$X = Y$。  
根据异或的性质，如果 $X = Y$，那么 $X \oplus Y = 0$。  
因为这两组电池是由原本的 $N$ 个电池**全部**分出来的（分成两组意味着没有剩余），所以：
$$
A_1 \oplus A_2 \oplus \dots \oplus A_N = X \oplus Y
$$
因此，只要**所有电池的异或总和等于 0**，就一定可以**分成相等的两组**。
```python
import os
import sys
it = iter(sys.stdin.read().split())
t = int(next(it))
for _ in range(t):
  n = int(next(it))
  res = 0
  for _ in range(n):
    res ^= int(next(it))
  if res == 0:
    print("YES")
  else:print("NO")
```
## 具体的场景
### 寻找“单身狗” (The Odd One Out)
**【场景描述】**  
在一个集合中，除了**某一个**数字只出现了一次，其余所有的数字都成对出现（出现了两次）。请找出那个落单的数字。  
**【解题思维】**
- **本质**：利用 $A \oplus A = 0$。
- **逻辑**：成对出现的数字在异或运算中会全部互相抵消（归零）。最后剩下的 `res` 必然就是那个没被抵消的单数。  
**【极简代码】**
```python
import sys
# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it))
res = 0
# 3.操作
for _ in range(n):
    res ^= int(next(it)) # 成对的全部变0，落单的被保留
# 4.答案
print(res)
```
这里为什么 res = 0 ?  
	在数学和编程中，每种运算都有一个 **“单位元”**（Neutral Element），它的特点是：**任何数与它运算，结果都保持不变。**  
	- **加法**的单位元是 **0**：$x + 0 = x$  
	- **乘法**的单位元是 **1**：$x \times 1 = x$  
	- **异或 (XOR)** 的单位元是 **0**：$x \oplus 0 = x$
