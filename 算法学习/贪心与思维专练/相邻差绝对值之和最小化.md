# 画展布置-真题
从 $N$ 个数中选 $M$ 个，按某种顺序排列，使得相邻项平方差的绝对值之和最小  
题目要求最小化：$L = \sum_{i=1}^{M-1} |A_{i+1}^2 - A_i^2|$。
## 分析
### 1. 数学坍缩：化繁为简
题目要求最小化：$L = \sum_{i=1}^{M-1} |A_{i+1}^2 - A_i^2|$。
- **第一步：有序化**。如果你随机选 $M$ 个数，这个和会很大。但如果你将选出的这 $M$ 个数从小到大排好序，绝对值号就可以直接去掉。
- **第二步：裂项相消**。  
    $$L = (A_2^2 - A_1^2) + (A_3^2 - A_2^2) + \dots + (A_M^2 - A_{M-1}^2)$$  
    中间的项全部抵消，最后只剩下：  
    $$L = A_M^2 - A_1^2$$  
    **结论**：不管你中间怎么排，只要有序，代价只取决于这 $M$ 个数中**最大值的平方**与**最小值的平方**之差。

### 2. 排序贪心：为什么选连续的？
现在问题变成了：从 $N$ 个数里选 $M$ 个，让它们“最大平方 - 最小平方”最小。
- **直觉**：为了让差值最小，这 $M$ 个数在数值上必须尽可能“挤在一起”。
- **操作**：先对原数组 $A$ 进行排序。排序后，任何**连续**的 $M$ 个数，都是潜在的最优解。
### 3. 滑动窗口：高效扫描
既然最优解一定是排序后连续的 $M$ 个数，我们不需要暴力枚举所有组合，只需要用一个长度为 $M$ 的窗口在排好序的数组上划过去：
- 窗口左端点 $i$，右端点 $i + M - 1$。
- 每次计算 $A[i+M-1]^2 - A[i]^2$，取最小值。
## 代码

```python
import sys
it = iter(sys.stdin.read().split())
n, m = int(next(it)), int(next(it))
# 1. 排序：为了让相邻差绝对值之和最小，必须有序，且连续取值
a = sorted([int(x) for x in it])
ans = float('inf')
# 2. 滑动窗口：只需检查所有连续的 M 个元素
for i in range(n - m + 1):
    # 根据裂项相消公式，和 = 末项平方 - 首项平方
    diff = a[i+m-1]**2 - a[i]**2
    if diff < ans:
        ans = diff
print(ans)
```
# 🏆 相邻差绝对值之和最小化

### 1. 核心数学模型：裂项相消 (Telescoping)
当我们需要在一组选定的数 $\{x_1, x_2, \dots, x_M\}$ 中，通过某种排列顺序使 $L = \sum |x_{i+1} - x_i|$ 最小化时：
- **贪心策略**：将选出的数按**从小到大（或从大到小）** 排序。
- **数学坍缩**：排序后，相邻项的差值恒为正（或恒为负），绝对值符号消失：  
    $$L = (x_2 - x_1) + (x_3 - x_2) + \dots + (x_M - x_{M-1})$$  
    中间项成对抵消，最终结果：  
    $$L = x_{max} - x_{min}$$
    
**结论**：在有序状态下，无论中间项如何分布，代价只由**两端边界**决定。
### 2. 算法通用骨架 (3-Step Template)

1. **排序 (Sort)**：对原始 $N$ 个数据升序排列。
2. **连续性假设 (Contiguity)**：在有序序列中，使得 $max - min$ 最小的 $M$ 个数一定是**连续**的一段。
3. **窗口扫描 (Sliding Window)**：使用长度为 $M$ 的窗口遍历数组，代价即为 `a[i + M - 1] - a[i]`（或其变体，如平方差）。
## 🚀 场景一：最短服务路径 (1D Path Planning)

### 题目描述
数轴上有 $N$ 个待选服务点，坐标分别为 $x_1, x_2, \dots, x_N$。你需要从中挑选 $M$ 个点，并将它们按某种顺序排列。要求相邻两个服务点之间的距离之和（总路程）最小。请输出最小总路程。
### 简洁分析
- **本质**：求 $\sum |x_{i+1} - x_i|$ 的最小值。
- **数学破题**：排序后，最短路径必然是单向行进（不折返）。根据裂项相消，总路程为 $x_{max} - x_{min}$。
- **贪心逻辑**：在排好序的数组中，选**连续**的 $M$ 个点，其跨度（末项减首项）即为所求。
### 极简代码
```python
import sys
it = iter(sys.stdin.read().split())
n, m = int(next(it)), int(next(it))
a = sorted([int(x) for x in it])
ans = 10**18
for i in range(n - m + 1):
    # 坍缩公式：末项 - 首项
    ans = min(ans, a[i + m - 1] - a[i])
print(ans)
```
## 🚀 场景二：系统不稳定性 (Resource Allocation)

### 题目描述
有 $N$ 个零件，每个零件的功率为 $a_i$。现在要选出 $M$ 个零件组成一个动力组。动力组的“不稳定性”定义为：将选出的零件按功率升序排列后，相邻零件**功率平方差**的绝对值之和。求最小的不稳定性。
### 简洁分析
- **本质**：求 $\sum |a_{i+1}^2 - a_i^2|$。
- **数学破题**：由于要求升序排列，绝对值号直接去掉。裂项相消后得到：$a_{max}^2 - a_{min}^2$。
- **贪心逻辑**：排序后，利用滑动窗口寻找平方跨度最小的连续区间。
### 极简代码
```python
import sys
it = iter(sys.stdin.read().split())
n, m = int(next(it)), int(next(it))
a = sorted([int(x) for x in it])
ans = 10**18
for i in range(n - m + 1):
    # 坍缩公式：末项平方 - 首项平方
    ans = min(ans, a[i + m - 1]**2 - a[i]**2)
print(ans)
```
## 🚀 场景三：预算约束下的序列数 (Sequence Counting)

### 题目描述
给定一个集合 $A$（含 $N$ 个正整数）和一个预算 $K$。请问有多少种方式从 $A$ 中选出 $M$ 个数组成一个序列，使得该序列在升序排列后，相邻项的差值之和不超过 $K$？（选出的数在原集合中的位置不同即视为不同方案）。
### 简洁分析
- **本质**：求满足 $x_{max} - x_{min} \le K$ 的 $M$ 元子集个数。
- **数学破题**：相邻差之和坍缩为“最大值与最小值的跨度”。
- **解法**：排序后，对于每一个起始位置 $i$，如果 `a[i + M - 1] - a[i] <= K`，则说明这一段连续的 $M$ 个数满足条件。
- **注意**：如果是求“子集数量”而非“连续区间”，则涉及组合数 $C_{count}^M$；本题简化为统计满足条件的**连续窗口**数量。
### 极简代码
```python
import sys
it = iter(sys.stdin.read().split())
n, m, k = int(next(it)), int(next(it)), int(next(it))
a = sorted([int(x) for x in it])

ans = 0
for i in range(n - m + 1):
    # 坍缩约束：末项 - 首项 <= K
    if a[i + m - 1] - a[i] <= k:
        ans += 1
print(ans)
```
## 📊 终极总结：什么时候用“裂项相消”？
当你在题目中看到 $\sum |f(x_{i+1}) - f(x_i)|$ 且允许你**自由排列**顺序时，请务必在草稿纸上写下：  
$$f(x_{max}) - f(x_{min})$$

### 💡 考场直觉
如果题目要求“相邻两两之差”且结果要**最小**：
1. **排序**是第一步（有序能让路径最短，不绕路）。
2. **看公式能不能消掉中间项**（只要是 $f(i+1) - f(i)$ 的形式都能消）。
3. **滑动窗口**是最终杀招。
# 中位数贪心 (Median Greedy)

### 1. 核心思想： tug-of-war（拔河效应）
给定数轴上 $n$ 个点 $x_1, x_2, \dots, x_n$，我们要找一个点 $x$，使得目标函数最小：

$$f(x) = \sum_{i=1}^{n} |x_i - x|$$

**为什么不是平均数？**
- **平均数 (Mean)**：受极端值（离群点）影响极大。它最小化的是**距离的平方和** $\sum (x_i - x)^2$。
- **中位数 (Median)**：它只关心“左边有多少人”和“右边有多少人”。  
**直观证明：**  
假设你在数轴上选了一个点 $x$：
- 如果 $x$ 的**左边有 10 个点，右边有 12 个点**，当你向右移动 $1\text{ cm}$ 时：左边的 10 个点每人离你远了 $1\text{ cm}$（总距离 $+10$），右边的 12 个点每人离你近了 $1\text{ cm}$（总距离 $-12$）。
- **净结果**：总距离减少了 $2\text{ cm}$。
- **结论**：只要左右人数不相等，你往人数多的一侧移动，总距离一定会减小。只有移动到**中位数**位置，左右人数平衡（或达到平衡区间），总距离才最小。
### 2. 算法通用骨架
1. **排序 (Sort)**：将所有坐标点升序排列。
2. **取中 (Find Median)**：
    - 如果 $n$ 是奇数，中位数是 `a[n // 2]`。
    - 如果 $n$ 是偶数，中位数是 `a[n // 2 - 1]` 到 `a[n // 2]` 之间的任意值（通常取其中一个）。
3. **求和 (Calculate)**：遍历所有点，累加到中位数的距离。
## 🚀 场景一：经典仓库选址 (1D 中位数)

### 题目描述

在一条笔直的公路旁有 $n$ 家店铺，坐标分别为 $x_1, x_2, \dots, x_n$。现在要在这条公路上建一个物流中心，使得物流中心到所有店铺的**距离之和**最小。
### 简洁分析
- **目标函数**：最小化 $f(X) = \sum |x_i - X|$。
- **核心逻辑**：只要 $X$ 左边的店铺多于右边，向左移动就能减少总距离。只有移动到**中位数**，左右人数平衡，达到最优。
- **注意**：如果是偶数个点，中位数之间的任何位置（含端点）都是等价的最优解。
### 极简代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = sorted([int(next(it)) for _ in range(n)])

# 1. 锁定中位数
mid = a[n // 2]
# 2. 计算最小距离和
ans = sum(abs(x - mid) for x in a)
print(ans)
```
## 🚀 场景二：曼哈顿距离最优解 (2D 中位数)

### 题目描述
在二维平面上有 $n$ 个居民点 $(x_i, y_i)$，你需要建一个服务站 $(X, Y)$，使得所有人到服务站的**曼哈顿距离**之和最小。
### 简洁分析

- **目标函数**：最小化 $\sum (|x_i - X| + |y_i - Y|)$。
- **破题关键**：在曼哈顿距离中，$x$ 轴和 $y$ 轴的计算是**完全独立**的。
- **操作**：将 $x$ 坐标和 $y$ 坐标拆开，分别求各自维度的中位数，组合出的 $(X_{mid}, Y_{mid})$ 即为最优坐标。
### 极简代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
xs, ys = [], []
for _ in range(n):
    xs.append(int(next(it)))
    ys.append(int(next(it)))

# 分别排序求中位数
xs.sort(); ys.sort()
mx, my = xs[n // 2], ys[n // 2]
ans = sum(abs(x - mx) for x in xs) + sum(abs(y - my) for y in ys)
print(ans)
```
## 🚀 场景三：带权中位数 (Weighted Median)

### 题目描述
有 $n$ 家工厂分布在数轴上，坐标为 $x_i$。每家工厂每天的运货量（权重）为 $w_i$。建一个中转站 $X$，最小化**加权距离之和** $\sum w_i |x_i - X|$。
### 简洁分析
- **核心逻辑**：不再是人数平分，而是**权重平分**。我们要找一个点，使得其左侧的总权重和右侧的总权重达到平衡。
- **操作**：按坐标排序，计算总权重 $W$。累加前缀权重，第一个让前缀和 $\ge W/2$ 的点就是带权中位数。
### 极简代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
# 存储 (坐标, 权重)
pts = sorted([(int(next(it)), int(next(it))) for _ in range(n)])

total_w = sum(p[1] for p in pts)
curr_w = 0
ans_pos = 0
# 寻找第一个超过总权重一半的位置
for x, w in pts:
    curr_w += w
    if curr_w >= total_w / 2:
        ans_pos = x
        break
ans = sum(w * abs(x - ans_pos) for x, w in pts)
print(ans)
```
