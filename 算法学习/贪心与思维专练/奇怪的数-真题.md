# 奇怪的数-真题
1. **奇偶位对齐**（1-indexed）：
    - **第 1, 3, 5... 位**（奇数位）：只能填奇数 $\{1, 3, 5, 7, 9\}$。
    - **第 2, 4, 6... 位**（偶数位）：只能填偶数 $\{0, 2, 4, 6, 8\}$。
    - _注意：第一位填奇数，自动避开了“首位不能为0”的规则。_
2. **滑动窗口限制**：
    - 任意**连续 5 位**数字的和不能超过 $m$。
    - 只要有任意一组连续 5 位的和 $> m$，这个数就不是“奇怪的数”。  
求出长度为 $n$ 且满足上述所有条件的数的个数，结果对 **998244353** 取模。
## 分析
#### 1. 挖掘局部依赖
题目要求“任意连续 5 位之和 $\le m$”。这意味着：
- 当你决定第 $i$ 位填什么时，只需要参考第 $i-1, i-2, i-3, i-4$ 这 **4 位**的数值。
- 只要这 5 位的和达标，且符合奇偶性，这个数就是合法的。
- **结论**：我们不需要记录整个数字，只需要维护一个长度为 4 的“记忆窗口”。
#### 2. 状态定义：滑块记分牌
- **状态**：`f[a, b, c, d]` 表示最后四位分别是 $a, b, c, d$ 的合法方案总数。
- **规模**：由于奇偶限制，每一位只有 5 种选法（奇数位填 1,3,5,7,9；偶数位填 0,2,4,6,8）。
- **总状态数**：$5 \times 5 \times 5 \times 5 = 625$。这是一个非常小的数字。
#### 3. 转移逻辑：吞吐更新
每往后填一位数字 $e$：
1. **校验**：判断 $a + b + c + d + e \le m$。
2. **位移**：旧窗口 `(a, b, c, d)` 扔掉最左边的 $a$，变成新窗口 `(b, c, d, e)`。
3. **累加**：将旧窗口的方案数累加到新窗口中。
## 代码
```python
import sys 
it = iter(sys.stdin.read().split())
n,m = int(next(it)),int(next(it))
mod = 998244353
f = {}
# 初始化状态种类数量
for a in [1,3,5,7,9]:
	for b in [0,2,4,6,8]:
		for c in [1,3,5,7,9]:
			for d in [0,2,4,6,8]:
				f[(a,b,c,d)]=1
# 区间滑动
for i in range(5,n+1):
	g = {}
	nums = [1,3,5,7,9] if i%2 == 1 else [0,2,4,6,8]
	for (a,b,c,d),count in f.items():
		for e in nums:
			if a+b+c+d+e<=m:
				state = (b,c,d,e)
				g[state] = (g.get(state,0)+ count)%mod
	f = g # 保证了每次都是符合任意的5个数都是<=m 剔除了不符合的 剩下来的全是符合要求的
print(sum(f.values())%mod)
```
