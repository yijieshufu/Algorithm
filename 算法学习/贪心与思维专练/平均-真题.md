# 平均-真题
**1. 题目描述**：  
有一个长度为 $n$ 的数组（$n$ 是 10 的倍数），每个元素都是 $0$ 到 $9$ 之间的整数。修改第 $i$ 个元素的代价为 $b_i$。  
**2. 约束条件**：
- 最终数组中 $0$ 到 $9$ 这 10 种数字出现的次数必须相等，即每种数字都必须恰好出现 $n/10$ 次。
- $n$ 最高可达 $10^5$。  
**3. 目的**：  
计算将数组调整至“均衡状态”所需的**最小总代价**。
## 分析
虽然题目看起来需要复杂的匹配，但通过**贪心策略**可以非常直观地解决：
1. **确定目标**：每个数字的目标次数是 $m = n/10$。
2. **分类讨论**：
    - 如果某个数字出现的次数**小于等于** $m$，我们完全不需要动它（动它只会增加代价，且让缺口更大）。
    - 如果某个数字出现的次数**大于** $m$，我们必须从中选出 $count - m$ 个实例修改成其他数字。
3. **最小化代价**：
    - 为了让代价最小，对于那些“超标”的数字，我们理所当然应该挑选修改代价 $b_i$ **最小**的那几个进行修改。
    - 由于我们可以把这些多余的数字修改成**任何**我们缺少的数字，所以我们不需要关心它们具体变成了谁，只需要把所有超标数字中代价最小的部分加起来即可。
## 代码
```python
import sys

# 读入规范
it = iter(sys.stdin.read().split())

# 1.变量
n = int(next(it))
m = n // 10
# f 用来存储 0-9 每个数字对应的所有修改代价列表
f = [[] for _ in range(10)]
ans = 0

# 2.边界
# 每种数字目标频次为 m，超过 m 的部分必须被替换

# 3.操作
for _ in range(n):
    g = int(next(it)) # 数字 a_i
    b = int(next(it)) # 代价 b_i
    f[g].append(b)

# 遍历 0-9 这 10 个桶
for g in range(10):
    a = f[g] # 当前数字的所有代价
    if len(a) > m:
        # 如果当前数字超标，对代价进行排序
        a.sort()
        # 挑选出最小的 (总数 - m) 个代价累加
        for b in range(len(a) - m):
            ans += a[b]

# 4.答案
print(ans)
```
