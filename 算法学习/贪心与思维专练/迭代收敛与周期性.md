# 产值调整-真题
- **初始值**：给出的 $A, B, C$ 是非负整数。
- **核心逻辑**：
    - 新金矿 $A' = \lfloor \frac{B+C}{2} \rfloor$
    - 新银矿 $B' = \lfloor \frac{A+C}{2} \rfloor$
    - 新铜矿 $C' = \lfloor \frac{A+B}{2} \rfloor$
- **执行次数**：这种调整要连续执行 $K$ 次
## 代码

  if k>100:
    limit=100 + k%2
  for i in range(limit):
    na = (b+c)//2

    nc = (a+b)//2
    if na==a and nb ==b and nc ==c:
      break
    a,b,c=na,nb,nc
  print(a,end=" ");print(b,end=" ");print(c)

# 数值迭代收敛 
### 1. 核心本质：指数级差距缩减
当一个系统不断执行“取平均值”的操作时，系统内部的极差（最大值与最小值的差 $D$）会迅速缩小。
- **数学原理**：在 $A' = \frac{B+C}{2}$ 这种结构中，每执行一轮，原来的极端值（最大或最小）都会被拉向中间。极差 $D$ 每一轮大约缩减为原来的 $\frac{1}{2}$。
- **收敛速度**：
    - 经过 $10$ 次迭代：$D$ 变为 $1/2^{10} \approx 1/1000$。
    - 经过 $60$ 次迭代：$D$ 变为 $1/2^{60} \approx 1/10^{18}$。
- **临界点**：因为题目初始值通常在 $10^{18}$ 以内，所以 **$60 \sim 100$ 次迭代**足以让三个数在数学上几乎相等。
### 2.周期态下的奇偶性判定
在执行 $K$ 次迭代时，如果数值由于“向下取整”无法完全合一，它们会陷入一个**长度为 2 的循环**。这就意味着：**只要次数足够多，最终的结果只取决于 $K$ 是奇数还是偶数。**
#### 1. 为什么会产生“奇偶跳变”？
在数学上，平均值可能是 $5.5$。但计算机执行 `(6+5)//2` 时：
- **第 100 次**：结果可能是 $5$。
- **第 101 次**：由于数值位置互换，重新计算的结果可能是 $6$。
- **第 102 次**：又跳回了 $5$。

这种 **“5 $\leftrightarrow$ 6”** 的跳动周期固定为 **2**。所以：
- 所有与 $K$ **同奇偶**的步数（如 $100, 102, 104 \dots$），结果都一样。
- 所有与 $K$ **异奇偶**的步数（如 $101, 103, 105 \dots$），结果也都一样。
#### 2. 核心秘诀：$K \pmod 2$ 的降维打击
当 $K$ 是一个天文数字（如 $10^{18}$）时，我们无法模拟 $K$ 次，但我们可以模拟到一个**“性质相同”**的小数字：
- **公式**：`limit = 100 + (K % 2)`
- **逻辑拆解**：
    1. **100**：这是一个缓冲垫，确保数值已经完成了从 $10^{18}$ 到个位数的**指数级收敛**，进入了最后的跳动阶段。
    2. **K % 2**：这是**灵魂补丁**。它保证了我们模拟停止的那一刻，其**“步数的奇偶性”与真实的 $K$ 完全一致**。
> **结论**：如果 $K$ 是偶数，我们就模拟到第 $100$ 步；如果 $K$ 是奇数，我们就模拟到第 $101$ 步。这两步的结果，就是 $10^{18}$ 步之后的结果。

## 具体的场景
### 场景1：一维扩散/平滑 (1D Smoothing)
**【题目描述】**  
一排 $n$ 个位置，每个位置有一个热量值。每一秒，每个位置的热量变为它与左右邻居（如果存在）的平均值（向下取整）。求 $K$ 秒后的热量分布。  
**【识别信号】**
- **动作**：与邻居同化。
- **本质**：数值整体向中位数/平均数坍缩。
- **难点**：虽然数值收敛，但由于位置多，收敛速度比三元模型稍慢，但 $K$ 很大时依然适用 100-200 步原则。

**【极简规范代码】**
```python
import sys
# 1.变量
it = iter(sys.stdin.read().split())
n, k = int(next(it)), int(next(it))
a = [int(next(it)) for _ in range(n)]

# 2.边界
limit = k if k <= 200 else (200 + k % 2)

# 3.操作
for _ in range(limit):
    ans = [0] * n
    for i in range(n):
        l = a[i-1] if i > 0 else a[i]
        r = a[i+1] if i < n-1 else a[i]
        ans[i] = (l + a[i] + r) // 3
    if ans == a: break
    a = ans

# 4.答案
print(*(a))
```
