# 合并水果
- **场景还原**：你手头有 $n$ 个数字，每次选两个数 $a$ 和 $b$ 删掉，然后换成一个新数 $c = a + b$。
- **计费规则**：每合成一次，你就要支付 $a+b$ 元。
- **最终目标**：支付的总金额最少。
# 分析
这道题 就是 哈夫曼树
## 代码
```python
import os
import sys
import heapq 
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(x) for x in it]
heapq.heapify(a) # 堆化
res = 0 
while len(a)>1:
  s = heapq.heappop(a) + heapq.heappop(a)
  res +=s
  heapq.heappush(a,s)
print(res)
```
# 最小堆与哈夫曼贪心：本质
**【数学本质】**  
**权重最小化：** 让数值最小的元素参与最多次数的累加，数值最大的元素参与最少次数的累加。  
**【算法本质】**  
**动态最值维护：** 在不断产生新数据的过程中，始终能以 $O(\log N)$ 的极低代价，精准抓取当前集合中的“最小两元”。

## 变体一：K 叉哈夫曼（多路合并）
**【题目描述】**  
有 $n$ 堆果子，每次可以合并 **$k$ 堆**，合并的代价为这 $k$ 堆果子的重量之和。求将所有果子合并成一堆的最小代价。  
**【数学本质】**  
**补零对齐**：为了保证贪心最优，必须确保每次合并都是 $k$ 个。如果 $(n-1) \pmod{k-1} \neq 0$，说明最后一次合并可能凑不满 $k$ 个。此时需补入若干重量为 **$0$** 的“虚拟果子”，使得节点数满足 $(n-1) \pmod{k-1} == 0$。  

**【公式】**
1. **单次消耗**  
每次合并，你拿出 **$k$** 堆，放回 **$1$** 堆。  
**净消耗**：$k - 1$ 堆。
 2. **总目标**  
你起始有 **$n$** 堆，目标是合到只剩 **$1$** 堆。  
**总共需要消耗**：$n - 1$ 堆。
 3. **整除判定**  
既然每次只能消耗固定的 **$k-1$** 堆，那么总消耗量 **$n-1$** 必须是 **$k-1$** 的整数倍，合并才能刚好凑齐，不留余数。  
**公式**：$(n - 1) \pmod{k - 1} == 0$。

**【极简代码】**
```python
import sys
import heapq

# 1.变量
it = iter(sys.stdin.read().split())
n, k = int(next(it)), int(next(it))
a = [int(x) for x in it]
ans = 0

# 2.边界 (核心：补0让(n-1)能被(k-1)整除)
while (len(a) - 1) % (k - 1) != 0:
    a.append(0)
heapq.heapify(a)

# 3.操作
while len(a) > 1:
    s = 0
    # 每次弹出 k 个最小的
    for _ in range(k):
        if a: s += heapq.heappop(a)
    ans += s
    heapq.heappush(a, s)
# 4.答案
print(ans)
```

## 变体二：最大堆贪心（最大化代价/最大值维护）

**【题目描述】**  
给定 $n$ 个选手的战斗力，每轮比赛选出战斗力**最大**的两个选手进行对决，胜者的战斗力变为**两者之差**，负者淘汰。求最后剩下的选手的战斗力。  
**【算法本质】**  
**负数镜像**：Python 的 `heapq` 默认是最小堆。处理“最大”问题时，将所有数值取**负数**存入。此时，原数值最大的（如 100）变为最小的（-100），从而实现大顶堆的效果。  
**【极简代码】**  
```python
import sys
import heapq

# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it))
# 核心：存入负数模拟大顶堆
a = [-int(x) for x in it]
heapq.heapify(a)

# 3.操作
while len(a) > 1:
    f = -heapq.heappop(a) # 取出最大的
    g = -heapq.heappop(a) # 取出次大的
    if f != g: # 相同的被抵消掉了
        heapq.heappush(a, -(f - g))

# 4.答案
print(-a[0] if a else 0)
```

## 变体三：动态中位数（对顶堆）
**【应用场景】**  
数据流源源不断进来，你需要在 $O(1)$ 时间内随时回答：“当前所有数的**中位数**是多少？”  
**【数学本质】**  
**分区平衡映射**：用大顶堆（$L$）守住较小的一半，用小顶堆（$R$）守住较大的一半。中位数永远在两个堆顶之间产生。  
**【极简代码】**
```python
import sys
import heapq

# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it))
l, r = [], [] # l:大顶堆(负数), r:小顶堆

# 3.操作
for _ in range(n):
    v = int(next(it))
    # 核心：先入左堆，再平衡给右堆，确保左堆不比右堆少
    heapq.heappush(l, -v)
    heapq.heappush(r, -heapq.heappop(l))
    if len(r) > len(l):
        heapq.heappush(l, -heapq.heappop(r))
    
    # 4.答案：奇数个取左堆顶，偶数个取平均(视题目而定)
    print(-l[0]) 
```

## 变体四：海量数据 Top-K（固定容量堆）
**【应用场景】**  
给 $10^7$ 个数，内存极小，求**最大**的 $K$ 个数。  
**【算法本质】**  
**末位淘汰制**：维护一个容量仅为 $K$ 的**最小堆**。
- 堆顶是这 $K$ 个大数里“**最弱**”的。
- 新数如果比堆顶还小，滚；如果比堆顶大，踢掉堆顶，新数上位。
- **逆直觉点**：求最大的 $K$ 个数要用**最小堆**。  
**【极简代码】**
```python
import sys
import heapq

# 1.变量
it = iter(sys.stdin.read().split())
n, k = int(next(it)), int(next(it))
a = [] # 最小堆

# 3.操作
for _ in range(n):
    v = int(next(it))
    if len(a) < k:
        heapq.heappush(a, v)
    elif v > a[0]:
        heapq.heapreplace(a, v) # 弹出堆顶并压入新值，一步到位

# 4.答案
print(sorted(a, reverse=True))
```
