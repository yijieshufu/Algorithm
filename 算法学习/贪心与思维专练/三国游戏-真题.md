# 题目
- **国家与士兵**：魏($X$)、蜀($Y$)、吴($Z$) 三国，初始士兵数量均为 0。
- **独立事件**：共有 $n$ 个事件，每个事件 $i$ 发生时，三国士兵分别增加 $A_i, B_i, C_i$。
- **获胜规则**：如果某个国家的士兵数**严格大于**另外两个国家士兵数之和，则该国获胜。
    - 例如魏国获胜条件为：$X > Y + Z$。  
求在**确保至少有一个国家获胜**的情况下，最多能发生多少个事件。如果没有任何一种情况能让任何国家获胜，则输出 `-1`。
## 贪心分析过程（暴力直观逻辑）
要让某个国家获胜，最直观的想法就是：**每一个事件都尽可能让该国“多加分”，让对手“少加分”。**
### 1. 获胜条件的数学转化
以**魏国获胜**为例，条件是 $X - (Y + Z) > 0$。  
假设我们选择了 $k$ 个事件，其对应的士兵增加量为 $(A_i, B_i, C_i)$，那么条件变为：  
$$\sum_{i=1}^{k} A_i - \sum_{i=1}^{k} B_i - \sum_{i=1}^{k} C_i > 0 \implies \sum_{i=1}^{k} (A_i - B_i - C_i) > 0$$
### 2. 贪心策略
对于魏国，每个事件 $i$ 的“净贡献值”就是 $w_i = A_i - B_i - C_i$。
- 为了让选取的事件数量 $k$ 最大化，我们应该**优先选择贡献值最大的事件**。
- **步骤**：
    1. 计算所有事件对魏国的净贡献值。
    2. 将贡献值从大到小排序。
    3. 按顺序累加，只要当前的累加和 $S > 0$，计数就加 1。
    4. 一旦累加和 $S \le 0$，说明再往后加只会让情况变糟，停止计数。
### 3. 全局最优
分别计算魏、蜀、吴三国获胜时的最大事件数，取三者的**最大值**作为答案。
## 代码
```python
import sys

# 读入规范
it = iter(sys.stdin.read().split())

# 1.变量
n = int(next(it))
a = [int(next(it)) for _ in range(n)] # 魏增加量
b = [int(next(it)) for _ in range(n)] # 蜀增加量
m = [int(next(it)) for _ in range(n)] # 吴增加量 (使用变量m代表C)
ans = -1

# 3.操作
# 分别对三个国家进行贪心模拟
# 处理魏国 (f 为贡献列表, g 为当前计数和累加)
f = [a[g] - b[g] - m[g] for g in range(n)]
f.sort(reverse=True)
g, n_cnt = 0, 0
for val in f:
    g += val
    if g > 0: n_cnt += 1
    else: break
if n_cnt > 0: ans = max(ans, n_cnt)

# 处理蜀国
f = [b[g] - a[g] - m[g] for g in range(n)]
f.sort(reverse=True)
g, n_cnt = 0, 0
for val in f:
    g += val
    if g > 0: n_cnt += 1
    else: break
if n_cnt > 0: ans = max(ans, n_cnt)

# 处理吴国
f = [m[g] - a[g] - b[g] for g in range(n)]
f.sort(reverse=True)
g, n_cnt = 0, 0
for val in f:
    g += val
    if g > 0: n_cnt += 1
    else: break
if n_cnt > 0: ans = max(ans, n_cnt)

# 4.答案
print(ans)
```
