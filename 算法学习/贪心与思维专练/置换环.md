
# 题目描述
书架还原-真题  
给定 $N$ 本书的乱序排列，每次可以**交换任意两本书**，求恢复成 $1, 2, \dots, N$ 顺序的最少交换次数。
# 分析
### 置换环：极简逻辑定稿
**1. 微观（个体）：$k - 1$**
- **逻辑**：在一个长度为 $k$ 的环中，每交换一次归位一人。
- **关键**：前 $k-1$ 个人归位后，最后一人被迫自动归位（赠品）。
- **结论**：**一个环的代价 = 环长度 - 1**。

**2. 宏观（全局）：$n - m$**
- **状态**：起点是 $m$ 个环，终点是 $n$ 个单元素环（全归位）。
- **动力**：在环内每交换一次，环的总数就 **$+1$**（分裂出一个归位点）。
- **结论**：**总代价 = 终点(n) - 起点(m)**。

**3. 统一（本质）**
- **数学等价**：$\sum (k_i - 1) = \sum k_i - \sum 1 = n - m$。
- **物理本质**：排序就是不断**切断**错误关联。每动一刀，就解开一个死结，直到 $n$ 个元素全部独立。
---
**一句话核心：最少交换次数 = 总人数 - 初始环个数。**
## 代码

```python
import sys
it = iter(sys.stdin.read().split())

# 1.变量
n = int(next(it))
a = [0] + [int(next(it)) for _ in range(n)] # 书籍位置，1-indexed
b = [0] * (n + 1) # 访问标记数组 (vis)
m = 0 # 环的数量计数
ans = 0 

# 2.边界

# 3.操作
for i in range(1, n + 1):
    if not b[i]:
        m += 1 # 发现一个新环，环总数加1
        f = i # 从当前位置开始“顺藤摸瓜”
        while not b[f]:
            b[f] = 1 # 标记此位置已处理
            f = a[f] # 沿着指向跳到下一个位置

# 核心公式：最少交换次数 = 总人数 - 环的个数
ans = n - m

# 4.答案
print(ans)
```

## 场景
### 题型识别：🎭 置换环的“三副面具”

当你看到“最少交换次数”且支持“任意位置交换”时，请识别以下场景：

1. **基础排序型（直观）**：将 $1 \sim N$ 的乱序恢复为升序。
    
2. **座位/位置型（生活）**：每个人都有固定编号的椅子，通过交换座位让所有人归位。
    
3. **数组变换型（抽象）**：给定数组 $A$ 和 $B$，通过交换 $A$ 的元素使其变成 $B$。
    
    - **破题关键**：将 $B$ 的顺序定义为“正确坐标”，建立从 $A$ 到 $B$ 的索引映射。

---

### 核心技术：地址簿映射 (Address Book Mapping)

为了处理 $A \to B$ 的变换（尤其是存在重复元素时），我们使用“排队领号”逻辑：

1. **建表 (Map)**：遍历目标 $B$，记录每个“值”对应的“家（下标）”。若有重复值，用列表存入多个下标。
    
    - `g[值] = [下标1, 下标2, ...]`
        
2. **跳跃 (Jump)**：从当前位置 $i$ 出发，看手里的“书” $a[i]$，从它的地址池里弹出一个下标，作为下一个跳跃目标。
    
    - 路径：`位置 i -> 元素 a[i] -> 目标位置 g[a[i]].pop()`
        
3. **前提**：$A$ 和 $B$ 必须包含相同的元素集合。

---

### 🚀 竞赛极简代码模板 (兼容重复元素)

```Python

import sys
it = iter(sys.stdin.read().split())

# 1.变量
n = int(next(it))
a = [0] + [next(it) for _ in range(n)] # 初始态 A
b = [0] + [next(it) for _ in range(n)] # 目标态 B
f = [0] * (n + 1)                      # 访问标记数组 (vis)
g = {}                                 # 地址簿映射 (值 -> 下标列表)
m = 0                                  # 环的数量计数
ans = 0 

# 2.边界 (略)

# 3.操作
# 步骤一：建表 —— 给重复的元素“排队发号”
for i in range(1, n + 1):
    if b[i] not in g: g[b[i]] = []
    g[b[i]].append(i)

# 步骤二：跳跃 —— 扫描所有位置，顺着地址簿拆解环
for i in range(1, n + 1):
    if not f[i]:
        m += 1 # 发现一个新环，环总数加1
        curr = i
        while not f[curr]:
            f[curr] = 1
            # 查表跳跃：当前位置 -> 拿走该值对应的一个目标位置
            # 使用 pop() 确保每个目标坑位只被占用一次
            curr = g[a[curr]].pop()
# 步骤三：收网 —— 应用黄金公式
ans = n - m
# 4.答案
print(ans)
```

## 破题三部曲：如何确定用置换环？
当你看到题目时，按以下三个步骤自我提问：
1. **是不是“交换”？**（只能通过 Swap 改变状态，不能插入或删除）。
2. **是不是“任意位置”？**（如果只能交换**相邻**元素，那是逆序对问题，不是置换环）。
3. **是不是“一一对应”？**（每个位置都有且只有一个最终要去的目标位置）。
> **金律：** 只要满足“任意位置交换”且目标态明确，**置换环就是唯一的标准答案**。
