# 翻转-真题
给定初始串 $S$ 和目标串 $T$，规定一种翻转操作：
- **规则**：若一个位与左右邻居都不同（孤岛），可翻转为邻居颜色（如 `101` $\to$ `111`）。
- **目标**：求 $S$ 变 $T$ 的最小步数，若无解输出 -1。
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
g = int(next(it))
for _ in range(g):
    t = next(it) # 目标串 T
    s = list(next(it)) # 可以变化的 串S
    n = len(s) 
    ans = 0
    f = 1  # 标志位
    # 首尾不一致 
    if t[0]!=s[0] and t[n-1]!= s[n-1]:
      print("-1")
      continue
	# 判断每个位置上的数
    for m in range(1,n-1):
      if s[m]!=t[m]:
        if s[m-1]!=s[m] and s[m+1]!=s[m]:
          ans +=1
          s[m] = t[m]
        else:
          f = 0
          break
    print(ans if f else "-1")

```
