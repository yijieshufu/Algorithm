# 回文数组-真题
- **目标**：把数组变成**回文**（即 $a_i = a_{n-i+1}$，对称位置必须相等）。
- **操作工具**：
    1. **单点修改**：选 1 个数，$+1$ 或 $-1$。
    2. **相邻修改**：选 **相邻** 的 2 个数，**同时** $+1$ 或 **同时** $-1$。
- **代价**：以上两种操作，每次都只算 **1 次** 操作。  
用**最少**的操作次数，把所有对称位置的“不平等”抹平。
## 分析
### 1. 建模：对称差值序列
要让数组回文，即 $a_i = a_{n-i+1}$。我们定义 $m = \lfloor n/2 \rfloor$ 个**差值变量**：  
$$d_i = a_i - a_{n-i+1} \quad (i = 1, 2, \dots, m)$$  
我们的目标是让所有的 $d_i$ 变为 $0$。
### 2. 操作转换
- **单点修改**：改变 $a_i$ 或 $a_{n-i+1}$，会让 $d_i$ 变化 $\pm 1$。代价：**1**。
- **相邻修改**：改变 $(a_i, a_{i+1})$ 或 $(a_{n-i}, a_{n-i+1})$，会让 $(d_i, d_{i+1})$ 同时变化 $\pm 1$。代价：**1**。
    - **重点**：只有当 $d_i$ 和 $d_{i+1}$ **符号相同**时，一次相邻操作才能同时减小它们的绝对值，从而省下一次操作。
### 3. 贪心策略：最大化“节省”
这变成了一个简单的“节省”问题：
1. 计算所有差值绝对值的总和 `ans = sum(|d_i|)`。这是在完全没有相邻修改时的保底代价。
2. 遍历差值序列。如果 $d_i$ 和 $d_{i+1}$ **同号**，它们之间可以进行“节省”。
3. 节省的额度取决于 $d_i$ **剩余的可节省量**（即没被 $d_{i-1}$ 用掉的部分）和 $d_{i+1}$ 的需求量。
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]
m = n//2
d = [a[i] - a[n-i-1] for i in range(m)] # 对称位置的差值

ans = sum(abs(x) for x in d ) # 计算总代价
pre_s = 0 # 计算上一次的代价

for i in range(m-1):
  cur_v = abs(d[i]) - pre_s # 能作用与下一个 i+1 的免费代价
  if d[i]*d[i+1] > 0 :
    s = min(cur_v,abs(d[i+1]))
    ans -= s 
    pre_s = s 
  else:
    pre_s = 0
print(ans) 
```
