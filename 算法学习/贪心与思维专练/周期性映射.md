# 2025图形-真题
小蓝要画一个“2025图形”，该图形是一个高为 h、宽为 w 的矩形（即 h 行 w 列的字符矩阵）。  
**填充规则如下：**
- 第一行：从左到右重复填入 “2025” 字符串，直到填满 w 个字符。
- 从第二行开始：每一行相对于上一行**向左循环移动一位**（即首字符移到末尾），然后继续用 “2025” 重复填充至宽度 w。  
**示例：**  
当 h = 5, w = 10 时，输出图形为：
```python
2025202520
0252025202
2520252025 
5202520252 
2025202520
```
## 分析
```python
import os
import sys
it = iter(sys.stdin.read().split())
h = int(next(it))
w = int(next(it))
s="2025"
L=4
for i in range(h):# i相当于左移了
  row = []
  for j in range(w):
    row.append(s[(i+j)%L]) 
  print("".join(row))# 每行打印
```
# 周期性映射
### 1. 是什么：本质结构 (What)
该知识点的本质是建立一个从**二维矩阵坐标 $(i, j)$** 到 **一维种子序列下标 $k$** 的线性映射函数。它将复杂的动态物理移动（旋转字符串）简化为静态的算术定位。
### 2. 为什么：核心逻辑推导 (Why)
该逻辑由两个维度的位移叠加而成：
- **行偏移逻辑 (垂直维度)**：  
    题目要求“每行向左移 1 位”。在索引世界中，**左移 1 位 $\equiv$ 起点下标 $+1$**。  
    因此，第 $i$ 行的起始字符下标为：$i \pmod L$。
- **列增长逻辑 (水平维度)**：  
    在确定的行内，字符随列号 $j$ 连续向后填充。  
    相对于该行起点的偏移量即为：$j$。
- **数学叠加结论**：  
    $$\text{最终下标 } k = (\text{行起点} + \text{列偏移}) \pmod L = (i + j) \pmod L$$

### 变体一：加速左移 (Multi-step Left Shift)
**【题目描述】**  
构造一个 $h \times w$ 的矩阵。种子字符串为 `"ABCDE"`（长度 $L=5$）。  
规则：第一行正常填充；从第二行开始，每一行相对于上一行**向左循环移动 2 位**。  
**【数学本质】**
- **行起点偏移**：每行移 2 位，意味着第 $i$ 行的起点是 $2i$。
- **映射公式**：$k = (2i + j) \pmod 5$  
**【极简代码实现】**
```python
import sys

# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it)) # h
m = int(next(it)) # w
s = "ABCDE"
f = 5 # L

# 3.操作
for i in range(n):
    ans = []
    for j in range(m):
        # 4.答案：k = (i * step + j) % L
        # 这里 step = 2
        g = (i * 2 + j) % f
        ans.append(s[g])
    print("".join(ans))
```
### 变体二：标准右移 (Standard Right Shift)
**【题目描述】**  
构造一个 $h \times w$ 的矩阵。种子字符串为 `"HELLO"`（长度 $L=5$）。  
规则：第一行正常填充；从第二行开始，每一行相对于上一行**向右循环移动 1 位**。  
**【数学本质】**
- **行起点偏移**：向右移位意味着起点在种子字符串中**向前**滑动。
- **映射公式**：$k = (j - i) \pmod 5$
- **数学细节**：在 Python 中，负数取模（如 $-1 \pmod 5 = 4$）会自动处理好循环逻辑，无需手动加 $L$。  
**【极简代码实现】**
```python
import sys

# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it)) # h
m = int(next(it)) # w
s = "HELLO"
f = 5 # L

# 3.操作
for i in range(n):
    ans = []
    for j in range(m):
        # 4.答案：右移使用减法定位起点
        g = (j - i) % f
        ans.append(s[g])
    print("".join(ans))
```
