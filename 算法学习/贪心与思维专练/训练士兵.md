# 训练士兵-真题

想象你正在经营一家**士兵健身房**，你的目标是让 $n$ 名士兵全部“出师”。
### 1. 任务目标
每位士兵 $i$ 都有一个“出师标准”，即必须完成至少 $c_i$ 次训练。
### 2. 两种付费方式
你可以随时在这两种方式间切换，且次数不限：
- **零售模式（单人训）**：给第 $i$ 名士兵单独买 1 次训练，花费 $p_i$ 枚金币。
- **团购模式（全体训）**：一口气付 $S$ 枚金币，**所有**士兵（不管他需不需要，只要他还没出师）全部自动训练 1 次。
## 分析
### 1. 是什么：本质结构 (What)
**核心元：性价比的动态博弈。**  
这道题不是让你在“团购”和“零售”中二选一，而是让你决定 **“什么时候停止团购”**。
- **团购 ($S$)**：就像买包场票，不管里面坐几个人，价格都是固定的。
- **零售 ($\sum p_i$)**：就像按人头买票，人越多，总价越贵。
### 2. 为什么：逻辑支撑 (Why)
#### ① 排序的意义：按“毕业时间”排队
我们将士兵按需求次数 $c_i$ **从小到大**排序。
- **逻辑**：需求最少的士兵会最早“出师”。每当有一名士兵出师，剩下的、需要继续训练的人就少了一个，零售的总成本 $\sum p_i$ 就会下降。
#### ② 决策的题眼：$S$ 与 $\sum p_i$ 的博弈
- **阶段一（大部队时期）**：如果当前所有还没出师的士兵，单练一次的总价 $\sum p_i > S$，那么买一次团购绝对划算，因为买团购不仅更便宜，还能顺便把所有人都带上一程。
- **阶段二（零星收尾时期）**：随着士兵陆续出师，当剩下的这几个人单练一次的总价 $\sum p_i \le S$ 时，团购就失去了意义。此时，哪怕他们还需要训 100 次，我们也应该给他们买零售票。
#### ③ 批量处理的艺术
在代码中，我们不是一次一次买团购，而是计算出当前最快出师的那个士兵还需要 `(c - cur_k)` 次，直接**打包购买**这么多次团购。因为在这段时间里，零售总价肯定是一直大于 $S$ 的。
## 代码
```python
import sys

# 1. 变量
it = iter(sys.stdin.read().split())
n = int(next(it))
s = int(next(it)) # 团购价
a = []
for _ in range(n):
    p = int(next(it)) # 零售单价
    c = int(next(it)) # 需求次数
    a.append([c, p])
# 核心：按出师时间排序
a.sort()
ans = 0
cur_k = 0 # 当前已训练次数
total_p = sum(x[1] for x in a) # 当前所有活跃士兵的 零售总价
idx = 0
# 3. 操作
while idx < n:
    c, p_val = a[idx]
    if total_p > s:
        # 团购划算：直接团购到让当前这个最弱的士兵出师
        if c > cur_k:
            ans += (c - cur_k) * s
            cur_k = c
        # 更新活跃士兵总价（这名及后续相同次数的士兵都出师了）
        while idx < n and a[idx][0] <= cur_k:
            total_p -= a[idx][1]
            idx += 1
    else:
        # 零售划算：后面的人全部买零售票
        # 剩余士兵每个人需要补齐的次数是 (需求次数 - 当前已训练次数)
        if c > cur_k:
            ans += (c - cur_k) * p_val
        idx += 1
# 4. 答案
print(ans)
```
