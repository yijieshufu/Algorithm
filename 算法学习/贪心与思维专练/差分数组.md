# 回文数组-真题
- **目标**：把数组变成**回文**（即 $a_i = a_{n-i+1}$，对称位置必须相等）。
- **操作工具**：
    1. **单点修改**：选 1 个数，$+1$ 或 $-1$。
    2. **相邻修改**：选 **相邻** 的 2 个数，**同时** $+1$ 或 **同时** $-1$。
- **代价**：以上两种操作，每次都只算 **1 次** 操作。  
用**最少**的操作次数，把所有对称位置的“不平等”抹平。
## 代码
```python
import sys

# 认知块 1 & 2: 输入与对称差值预处理
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]
# 仅计算前一半的差值即可
d = [a[i] - a[n-1-i] for i in range(n // 2)]
ans = 0
prev = 0
# 认知块 3: 贪心计算增量贡献
for x in d:
    if x * prev > 0: # 块 3: 方向相同，计算绝对值的正增量
        if abs(x) > abs(prev):
            ans += abs(x) - abs(prev)
    else:            # 块 3: 方向不同，必须重新起步
        ans += abs(x)
    prev = x
print(ans)
```
## 分析

### 1. 降维：从“对称”到“归零”
- **转化**：我们要做的不是让数组变美，而是让对称位置的差值消失。
- **定义**：$d_i = a_i - a_{n-1-i}$（仅计算前一半）。
- **目标**：用最少的操作次数，让所有的 $d_i = 0$。
### 2. 核心：贪心“顺风车”逻辑
- **规则**：单点改 $d_i$ 花 1 块钱；同时改相邻的 $d_i, d_{i+1}$ 也**只花 1 块钱**。
- **策略**：当相邻两个坑**方向相同**时，填大坑可以“顺便”带走小坑。
- **计算准则**：我们只为 **“净增量”** 付钱。
### 3. 灵魂：`prev = x` 的额度接力
这是你之前的疑惑点，用一句话概括：**`prev` 代表你从前一个坑带过来的“免费施工额度”。**
- **坑变深时 ($|x| > |prev|$)**：  
    额度不够用了，你必须**自掏腰包补差价**（`abs(x) - abs(prev)`）。补完后，你现在手握更强的力量（新额度 `x`），传给下一个人。
- **坑变浅时 ($|x| < |prev|$)**：  
    前人的力量太强，你“顺便”就被填平了，**花费为 0**。但为了不挖过头，你切断了多余力量，传给下一个人的额度**收缩**为你的深度 `x`。
- **方向变时 ($x \cdot prev \le 0$)**：  
    前人的力量帮倒忙。**额度清零**，你必须全额支付 $|x|$，并开启新的施工方向。
### 4. 极简执行骨架
```python
# 1. 提取对称矛盾
d = [a[i] - a[n-1-i] for i in range(n // 2)]

# 2. 增量贡献扫描
ans, prev = 0, 0
for x in d:
    if x * prev > 0:            # 方向相同：蹭车
        ans += max(0, abs(x) - abs(prev)) # 只补差价
    else:                       # 方向不同：另起炉灶
        ans += abs(x)           # 全额付钱
    prev = x                    # 更新当前可传下去的“额度”
```
### 💡 考场判别金律

> **“操作涉及相邻/区间” + “求最少步数” + “目标是相等/归零”**
> 
> **$\implies$ 直接提取差值，只算坡度上升的“净增量”。**
