# 三国游戏-真题
- **初始状态**：魏 $(X)$、蜀 $(Y)$、吴 $(Z)$ 初始士兵均为 0。
- **事件发生**：共有 $n$ 个事件，每个事件 $i$ 让三国士兵分别增加 $A_i, B_i, C_i$。
- **获胜规则**：某国士兵数 > 另外两国之和（如魏胜：$X > Y + Z$）。
- **目标**：求在保证某国获胜的前提下，**最多**能发生多少个事件。无解输出 -1。
## 贪心分析过程
要让某个国家获胜，我们需要将复杂的比较转化为单一数值的累加。
1. **获胜等价式**：  
    以魏国为例，获胜条件为 $X > Y + Z$。  
    移项得：$X - Y - Z > 0$。
2. **净贡献值**：  
    对于每个事件 $i$，它对魏国获胜的“净贡献”为：  
    $$w_i = A_i - B_i - C_i$$  
    只要选出的事件集合满足 $\sum w_i > 0$，魏国就获胜。
3. **贪心策略**：  
    为了让事件数量 $k$ 最大化：
    - 计算所有事件的净贡献 $w_i$。
    - 将 $w_i$ **从大到小排序**。
    - 优先选取贡献最大的事件（即便是负数，只要当前总和大于 0 就可以选），直到累加和不再大于 0 为止。
## 代码
```python
import sys

it = iter(sys.stdin.read().split())

n = int(next(it))
a = [int(next(it)) for _ in range(n)] 
b = [int(next(it)) for _ in range(n)] 
c = [int(next(it)) for _ in range(n)] 
ans = -1
def solve(mine, other1,other2):
  f = [mine[i]-other1[i] - other2[i] for i in range(n)] # 记录贡献值
  f.sort(reverse = True)#大到小
  total_sum = 0 # 胜利的判断条件
  count = 0  # 记录发生事件的个数
  for val in f:
    total_sum +=val
    if total_sum >0 :
      count+=1
    else:break
  return count if count >0 else -1
ans = max(ans, solve(a, b, c)) # 魏胜
ans = max(ans, solve(b, a, c)) # 蜀胜
ans = max(ans, solve(c, a, b)) # 吴胜
print(ans)
```
