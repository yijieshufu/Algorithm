# 最多次数-真题
给出一个字符串 $s$，从中寻找由 `l`, `q`, `b` 三个字母组成的任意排列的子串（共 6 种：`lqb`, `lbq`, `qlb`, `qbl`, `blq`, `bql`）。要求切割出的单词互不重叠，求最多能切出多少个。
## 代码
```python
import os
import sys
it = iter(sys.stdin.read().split())
s = next(it)
l = len(s)
ans = 0
i = 0
target={'l','q','b'}
while i <=l-3:
  sub = s[i:i+3]
  if set(sub) == target:
    ans+=1
    i+=3
  else:i+=1
print(ans)
```
### 📌 策略一：无重复字符场景 (Set 判别法)
**适用场景：** 目标集合中的字符互不相同（如 `l, q, b`）。  
**核心逻辑：** 只要窗口长度相等，且 `set` 后的元素集合一致，即可判定为合法排列。
#### ⌨️ 极简代码实现（以寻找 `lqb` 及其排列为例）
```python
import sys
# 1.变量
it = iter(sys.stdin.read().split())
a = next(it)     # 原始长字符串
n = len(a)
g = {'l','q','b'} # 目标集合（无序、唯一）
m = 0            # 指针
ans = 0

# 2.边界
while m <= n - 3:
    # 3.操作
    f = a[m:m+3] # 截取定长子串
    if set(f) == g:
        ans += 1
        m += 3   # 若不重叠则跳3，若允许重叠则改1
    else:
        m += 1

# 4.答案
print(ans)
```

---

### 📌 策略二：有重复字符场景 (Sorted 判别法)
**适用场景：** 目标集合中包含重复字符（如判断子串是否为 `aab` 的排列：`aab`, `aba`, `baa`）。  
**核心逻辑：** `set` 会丢失频率信息，所以改用 `sorted()`。如果两个子串排序后的列表完全一致，则它们互为排列（异位词）。
#### ⌨️ 极简代码实现（以寻找 `aab` 及其排列为例）
```python
import sys
# 1.变量
it = iter(sys.stdin.read().split())
a = next(it)
n = len(a)
g = sorted("aab") # 预排好序的目标列表: ['a', 'a', 'b']
m = 0
ans = 0

# 2.边界
while m <= n - 3:
    # 3.操作
    f = sorted(a[m:m+3]) # 将当前子串排序
    if f == g:
        ans += 1
        m += 3
    else:
        m += 1

# 4.答案
print(ans)
```

### 💡 深度总结与举一反三
为了让你在考场上瞬间反应，请记住下表：

| **题目特征**                 | **判定方式**         | **核心优势**                   | **复杂度**       |
| ------------------------ | ---------------- | -------------------------- | ------------- |
| **字符唯一** (`lqb`, `xyz`)  | `set(f) == g`    | **秒杀**。逻辑极简，速度最快。          | $O(K)$        |
| **字符重复** (`aab`, `tree`) | `sorted(f) == g` | **稳健**。自动处理字符出现的频率。        | $O(K \log K)$ |
| **极致大数据** ($N > 10^6$)   | **频率数组**         | **巅峰性能**。用 `count` 数组动态维护。 | $O(1)$ 窗口移动   |
