# 食堂-真题
学校有三种宿舍：2人寝（$a_2$）、3人寝（$a_3$）、4人寝（$a_4$）。  
食堂有两种桌子：4人桌（$b_4$）、6人桌（$b_6$）。  
**规则**：同一个宿舍的人必须坐同一张桌子，不能拆分。  
**目标**：求食堂最多能同时**容纳多少学生用餐**。
## 分析
题目要求“最多满足多少同学用餐”，其实可以反过来想：**“如何让桌子空出来的废座最少？”**  
我们的资源是 **4人桌** 和 **6人桌**。我们要把 4人寝、3人寝、2人寝 像填缝一样塞进去，优先级严格按照“浪费的座位数”从少到多进行降级。
#### 🥇第一梯队：完美匹配（0 浪费）
_这是最高优先级，必须最先抢占桌子。_
- **3配3 $\rightarrow$ 6桌**：3人寝最难搞（不能去4人桌否则浪费），优先让他们内部消化。
- **4 $\rightarrow$ 4桌**：天作之合。
- **4配2 $\rightarrow$ 6桌**：4人寝如果没4人桌了，去6人桌必须强行拉一个2人寝垫背，完美填满。
- **2配2 $\rightarrow$ 4桌**
- **2配2配2 $\rightarrow$ 6桌**
#### 🥈 第二梯队：轻微浪费（空 1 座）
- **3配2 $\rightarrow$ 6桌**：坐5人，空1座（这是3人寝最后的倔强）。
- **3 $\rightarrow$ 4桌**：坐3人，空1座。
#### 🥉 第三梯队：残局扫尾（有座就行）
_这个时候好组合已经用光了，剩下的只要桌子能塞下，管它空几个座，直接往里扔。_
- **4 $\rightarrow$ 6桌**（空2座）
- **2配2 $\rightarrow$ 6桌**（空2座）
- **2 $\rightarrow$ 4桌**（空2座）
- **3 $\rightarrow$ 6桌**（空3座）
- **2 $\rightarrow$ 6桌**（空4座）
# 代码
```python
import sys
it = iter(sys.stdin.read().split())

n = int(next(it))
for _ in range(n):
    a = [0]*5
    b = [0]*7 
    ans = 0
	# 读入各自的数量
    a[2] = int(next(it))
    a[3] = int(next(it))
    a[4] = int(next(it))
    b[4] = int(next(it))
    b[6] = int(next(it))
	# 操作 0 浪费
	m = min(a[3]//2,b[6]);ans+=6*m;a[3]-=m*2;b[6]-=m # 3 3 去6
	m = min(a[4],b[4]);ans+=4*m;a[4]-=m;b[4]-=m # 4 去 4 
	m = min(a[2],a[4],b[6]);ans+=6*m;a[2]-=m;a[4]-=m;b[6]-=m # 4 2 去 6
	m = min(a[2]//2,b[4]);ans+=4*m;a[2]-=m*2;b[4]-=m # 2 2 去4
	m = min(a[2]//3,b[6]);ans+=6*m;a[2]-=m*3;b[6]-=m # 2 2 2 去 6
	# 1浪费
	# 3 去 4 
	m = min(a[3],b[4]);ans+=3*m;a[3]-=m;b[4]-=m
	# 2 3 去 6
	m = min(a[2],a[3],b[6]);ans+=5*m;a[2]-=m;a[3]-=m;b[6]-=m
	# 2浪费
	# 4 去 6
	m = min(a[4],b[6]);ans+=4*m;a[4]-=m;b[6]-=m
	# 2 去 4 
	m = min(a[2],b[4]);ans+=2*m;a[2]-=m;b[4]-=m
	# 2 2 去 6
	m = min(a[2]//2,b[6]);ans+=4*m;a[2]-=m*2;b[6]-=m
	# 3 浪费
	# 3 去 6 
	m = min(a[3],b[6]);ans+=3*m;a[3]-=m;b[6]-=m
	# 4 浪费
	# 2 去 6
	m = min(a[2],b[6]);ans+=2*m;a[2]-=m;b[6]-=m
	print(ans)
```

# 拼好数-真题
我们将含有不少于 **6个6** 的数视为一个“好数”。
- **例子**：`666666`、`162636465666` 是好数；`12366666`（只有5个6）不是好数。
- **任务**：给定 $n$ 个正整数 $a_i$，你可以将这些数分成若干组拼接起来。
- **规则**：
    1. 每组内的数可以按任意顺序拼接。
    2. **重点**：每一组最多只能有 **3 个数**。
- **求解**：最多可以得到多少个好数？
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
f = [0]*7 # 每个数据的中6的个数
ans = 0 

# 记录6的个数
for _ in range(n):
	g = next(it).count("6")
	if g >=6:ans+=1
	else:f[g]+=1
	
# 5 1配对 # 5 只会在这里用到
m = min(f[5],f[1])
ans+=m
f[5]-=m 
f[1]-=m
f[4]+=f[5]

#  4 1 1 
m = min(f[4],f[1]//2) 
ans+=m
f[4]-=m
f[1]-=m*2
# 4 2  # 后面不用4了
m = min(f[4],f[2])
ans+=m
f[4]-=m
f[2]-=m
f[3]+=f[4]
# 3+2+1
m = min(f[3], f[2], f[1]) 
ans += m 
f[3] -= m 
f[2] -= m 
f[1] -= m
# 3+3
m =f[3]//2
ans+=m
f[3]-=2*m  
f[2]+=f[3] # 3还可以当作2用
# 2 2 2 
ans+=f[2]//3
print(ans)

```
## 分析

**【核心思想】优先消灭废料 1 ＋ 资源逐层降级**  
**【前提规则】** 最多 3 数组合，带 $\ge 6$ 个的直接 `ans+1`。  
**第一层：5 的专属任务**
- **动作**：`5 + 1` 配对。（用最强资源救最废的 1）
- **降级**：用不完的 5，直接当 4 用（加到 4 的个数里）。

**第二层：4 的清障任务**
- **动作**：优先 `4 + 1 + 1`（消耗废料的最后大好时机），次选 `4 + 2`。
- **降级**：用不完的 4，直接当 3 用。

**第三层：3 的大杂烩**
- **动作**：优先 `3 + 2 + 1`（榨干最后的 1），次选 `3 + 3`（自给自足）。
- **降级**：用不完的 3，直接当 2 用。

**第四层：2 的扫尾任务**
- **动作**：全体 `2 + 2 + 2` 抱团取暖，榨干最后价值。

# 🏆 分类贪心匹配 (Categorized Greedy)

### 1. 核心思想 (Core Philosophy)

在有限的容器（桌子、拼接名额）和多样的资源（宿舍人数、数字中的“6”）之间，建立一套**严格的优先级序列**。其本质是：**“优先满足零浪费（或高价值）组合，资源用尽后逐层降级，直到压榨干最后一点价值。”**

### 2. 三大核心特征 (Three Key Features)

- **频率统计 (Bucketing)**：不关心具体某个数据，只关心“属于哪一类”。通常用 `f[i]` 统计类型为 $i$ 的资源数量。
- **贪心序 (Greedy Order)**：手动推导并排列所有可能的组合，按“性价比”（浪费最少、收益最高）从高到低排序。
- **余料降级 (Downgrading)**：如果高价值资源在当前优先级中没用完，将其视为低价值资源继续参与下一轮匹配（例如：没配成对的“5”降级当做“4”来用）。

## 🛠️ 解题通用逻辑模板

当你发现题目涉及 **“固定容器”** 容纳 **“不同规格资源”**，且 **“目标是最大化/最小化”** 时，请按以下步骤操作：
### 第一步：建立频率数组
将资源按属性分类。
```python
# 例如统计 6 的个数，或者统计宿舍人数
f = [0] * MAX_CATEGORY 
```
### 第二步：确定优先级列表 (The Priority List)
这是最关键的一步，需要手动分析。
- **0 浪费组**：如 $3+3 \to 6$ 桌，或 $5+1 \to 6$ 个“6”。
- **1 浪费组**：如 $4+1+1$（在最多凑 3 个数的规则下）。
- **保底组**：实在凑不齐，单走或者随意拼凑。
### 第三步：贪心消去 (The "min" Pattern)
利用 `min` 函数快速消耗资源对，这是分类贪心的标准写法：
```python
# 典型动作：匹配 a 和 b
m = min(f[a], f[b])
ans += m
f[a] -= m
f[b] -= m
```
### 第四步：资源降级 (Resource Degradation)
将剩余的高端资源转入低端池：
```python
f[3] += f[4]  # 4没用完，降级成3去参与下一轮
```

## 📊 题目对比总结

|**特性**|**好数拼接 (拼数字)**|**食堂用餐 (填桌子)**|
|---|---|---|
|**容器限制**|每组最多 3 个数|4 人桌或 6 人桌|
|**匹配目标**|6 的总数 $\ge 6$|填满座位或空位最少|
|**关键资源**|废料 "1" (最难处理)|3 人寝 (最难处理)|
|**降级策略**|5 $\to$ 4 $\to$ 3 $\to$ 2|按照浪费人数从 0 $\to$ 1 $\to$ 2 $\dots$|
|**数学本质**|分类枚举 + 局部最优|分类枚举 + 状态压榨|
