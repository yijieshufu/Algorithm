# 平均-真题
给定一个长度为 $n$（$n$ 是 10 的倍数）的数组，数组中的每个数 $a_i$ 都在 $[0, 9]$ 之间。
- **操作**：修改第 $i$ 个数需要花费 $b_i$ 的代价。
- **目标**：让 0 到 9 这 10 个数字出现的次数完全相等，即每个数字都必须恰好出现 $n/10$ 次。
- **求解**：达到该状态所需的**最小总代价**。
## 分析
虽然题目看起来需要复杂的匹配，但通过**贪心策略**可以非常直观地解决：
1. **确定目标**：每个数字的目标次数是 $m = n/10$。
2. **分类讨论**：
    - 如果某个数字出现的次数**小于等于** $m$，我们完全不需要动它（动它只会增加代价，且让缺口更大）。
    - 如果某个数字出现的次数**大于** $m$，我们必须从中选出 $count - m$ 个实例修改成其他数字。
3. **最小化代价**：
    - 为了让代价最小，对于那些“超标”的数字，我们理所当然应该挑选修改代价 $b_i$ **最小**的那几个进行修改。
    - 由于我们可以把这些多余的数字修改成**任何**我们缺少的数字，所以我们不需要关心它们具体变成了谁，只需要把所有超标数字**中代价最小的部分加起来**即可。
## 代码
```python
import sys

it = iter(sys.stdin.read().split())
n = int(next(it))
m = n // 10
f = [[] for _ in range(10)]
ans = 0
for _ in range(n):# 记录数a的不同代价
  a = int(next(it))
  b = int(next(it))
  f[a].append(b)
for g in range(10):
  list_a = f[g] # 数值为g的代价列表
  if len(list_a) > m:
    list_a.sort() # 拿小的来改
    for i in range(len(list_a)-m): # 超过的修改
      ans+=list_a[i]
print(ans)
```
