# 水质检测-真题
在一个 $2 \times n$ 的格子里，已经有一些点（检测器 `#`）了。两个点只要上下或左右相邻就是连通的。你的任务是：**最少**往空格子 `.` 里填多少个新的 `#`，能让现有的所有 `#` 都连在一起。

- **关键约束**：$n$ 高达 $1,000,000$，意味着我们只能用 $O(n)$ 的时间复杂度，也就是只能扫一遍。
- **题型**：线性动态规划 / 贪心
- **难度**：⭐⭐⭐（中等，省赛高频题）
- **是否必会**：**是**。这种 $2 \times N$ 的窄条状网格问题，是**动态规划**的绝佳切入点，必须掌握。
# 代码
```python
import sys
it = iter(sys.stdin.read().split())
s1 = next(it)
s2 = next(it)
n = len(s1)
L,R=-1,-1 # 定位L，R L第一个，R最后一个
for i in range(n):
  if s1[i]=='#' or s2[i]=='#':
    if L ==-1:L=i
    R = i 

if L == -1:print(0);sys.exit()# 特殊 情况 无
f0 = 0 if s1[L] == '#' else 1 # 初始 新增数 f0，f1  如果f1的L列没有 要花费一个补充
f1 = 0 if s2[L] == '#' else 1
for i in range(L+1,R+1): # 开始走L+1 到R列：
  c0 = 1 if s1[i]=='.' else 0 # 两个 都是遇到 . 直接 安装
  c1 = 1 if s2[i]=='.' else 0
  p0,p1=f0,f1 # 预存上个状态
  f0 = min(p0+c0,p1+c1+c0) # # 状态方程：要么直走，要么拐弯
  f1 = min(p1+c1,p0+c0+c1)
  if s1[i] == '#' and s2[i]=='#': # 同步：双#合流
    f0=f1=min(f0,f1)
print(min(f0,f1)) # 输出两个的最小
```

## 分析
### 1. 是什么：本质结构 (What)
**核心元：状态压缩的线性 DP。**  
在一个 $2 \times N$ 的网格里，要保证“全连通”，你每一列的选择极其有限。当你扫描到第 $i$ 列时，你只需要知道：
- **$f_0$**：要使第 $i$ 列的第一行连通，最少需要多少代价。
- **$f_1$**：要使第 $i$ 列的第二行连通，最少需要多少代价。  
这就像是在一条只有上下两层的平行隧道里铺电缆，你关心的只是电缆现在是在上层露头，还是在下层露头。
### 2. 为什么：逻辑支撑 (Why)
#### ① 扫描范围的“锚定” (L & R)
为什么只管 $L$ 到 $R$？因为 $L$ 之前的空格和 $R$ 之后的空格对“现有检测器连通”毫无贡献。
- **本质**：缩小定义域，排除无关噪声。
#### ② 状态转移的“代价权衡”
从 $i-1$ 列推到 $i$ 列，只有两种走法：
1. **横跳（Horizontal）**：
    - 上层到上层：$p_0 + \text{当前格子是否为空}$
    - 下层到下层：$p_1 + \text{当前格子是否为空}$
2. **拐弯（Vertical + Horizontal）**：
    - 要想从下层 $p_1$ 到达上层 $f_0$，必须经过 $(1, i)$ 再转到 $(0, i)$。
    - 代价：$p_1 + \text{下层当前格代价} + \text{上层当前格代价}$。
#### ③ 同步机制（The Sync Step）
**这是最核心的本质**：`if s1[i]=='#' and s2[i]=='#': f0=f1=min(f0,f1)`
- **逻辑**：如果当前列两行都是 `#`，说明上下两层在这里已经**天然合流**了。
- **意义**：既然合流了，那么从上面过来的最优解和从下面过来的最优解，在这一刻可以共享。这避免了路径的重复计算。
