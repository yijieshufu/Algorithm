# 合并水果
- **场景还原**：你手头有 $n$ 个数字，每次选两个数 $a$ 和 $b$ 删掉，然后换成一个新数 $c = a + b$。
- **计费规则**：每合成一次，你就要支付 $a+b$ 元。
- **最终目标**：支付的总金额最少。
# 分析
这道题 就是 哈夫曼树
## 代码
```python
import os
import sys
import heapq 
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(x) for x in it]
heapq.heapify(a) # 堆化
res = 0 
while len(a)>1:
  s = heapq.heappop(a) + heapq.heappop(a)
  res +=s
  heapq.heappush(a,s)
print(res)
```
# 最小堆与哈夫曼贪心：本质
**【数学本质】**  
**权重最小化：** 让数值最小的元素参与最多次数的累加，数值最大的元素参与最少次数的累加。  
**【算法本质】**  
**动态最值维护：** 在不断产生新数据的过程中，始终能以 $O(\log N)$ 的极低代价，精准抓取当前集合中的“最小两元”。

## 变体一：K 叉哈夫曼（多路合并）
**【题目描述】**  
有 $n$ 堆果子，每次可以合并 **$k$ 堆**，合并的代价为这 $k$ 堆果子的重量之和。求将所有果子合并成一堆的最小代价。  
**【数学本质】**  
**补零对齐**：为了保证贪心最优，必须确保每次合并都是 $k$ 个。如果 $(n-1) \pmod{k-1} \neq 0$，说明最后一次合并可能凑不满 $k$ 个。此时需补入若干重量为 **$0$** 的“虚拟果子”，使得节点数满足 $(n-1) \pmod{k-1} == 0$。  
**【极简代码】**
```python
import sys
import heapq

# 1.变量
it = iter(sys.stdin.read().split())
n, k = int(next(it)), int(next(it))
a = [int(x) for x in it]
ans = 0

# 2.边界 (核心：补0让(n-1)能被(k-1)整除)
while (len(a) - 1) % (k - 1) != 0:
    a.append(0)
heapq.heapify(a)

# 3.操作
while len(a) > 1:
    s = 0
    # 每次弹出 k 个最小的
    for _ in range(k):
        if a: s += heapq.heappop(a)
    ans += s
    heapq.heappush(a, s)
# 4.答案
print(ans)
```

## 变体二：最大堆贪心（最大化代价/最大值维护）

**【题目描述】**  
给定 $n$ 个选手的战斗力，每轮比赛选出战斗力**最大**的两个选手进行对决，胜者的战斗力变为两者之差，负者淘汰。求最后剩下的选手的战斗力。  
**【算法本质】**  
**负数镜像**：Python 的 `heapq` 默认是最小堆。处理“最大”问题时，将所有数值取**负数**存入。此时，原数值最大的（如 100）变为最小的（-100），从而实现大顶堆的效果。  
**【极简代码】**  
```python
import sys
import heapq

# 1.变量
it = iter(sys.stdin.read().split())
n = int(next(it))
# 核心：存入负数模拟大顶堆
a = [-int(x) for x in it]
heapq.heapify(a)

# 3.操作
while len(a) > 1:
    f = -heapq.heappop(a) # 取出最大的
    g = -heapq.heappop(a) # 取出次大的
    if f != g:
        heapq.heappush(a, -(f - g))

# 4.答案
print(-a[0] if a else 0)
```
