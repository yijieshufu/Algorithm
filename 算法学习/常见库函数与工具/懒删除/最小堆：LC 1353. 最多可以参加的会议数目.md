# 题目
给定 $n$ 个会议，每个会议 $a[i] = [start_i, end_i]$。  
你每天只能参加一个会议，且必须在该会议的持续时间内参加。  
求最多能参加多少个会议。
# 分析

先讲今天能参加的都 加入到 最小堆中（以截止时间）  
	根据快到期的 然后选择去参加会议

发现过了截止日期的那就不去了

参加完了 但是后面还有会议 那就到有会议那天去参加
# 代码

```python
import heapq 
class Solution:
    def maxEvents(self, events: List[List[int]]) -> int:
        a = events
        a.sort()
        h,n,i,ans = [],len(a),0,0 
        d = a[0][0] # 今天
        while i < n or h:
            while i < n and a[i][0] == d: # 今天所有的会议的结束时间入堆
                heapq.heappush(h,a[i][1])
                i+=1 # i 指针一直往下走 代表处理了一个了
            while h and h[0] < d:
                heapq.heappop(h)
            if h :
                heapq.heappop(h)
                ans+=1 # 参加一个
            d+=1 # 日期一直走
            if not h and i < n: # 参加完了 但是后面还有会议 那就到有会议那天去参加
                d = a[i][0]
        return ans 
```
