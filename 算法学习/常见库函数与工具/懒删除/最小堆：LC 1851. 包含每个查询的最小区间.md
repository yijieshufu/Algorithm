# 题目
给你一个二维整数数组 `intervals`，其中 `intervals[i] = [left_i, right_i]` 表示第 $i$ 个区间。

同时给你一个整数数组 `queries`。  
第 $j$ 个查询的答案是满足 $left_i \le queries[j] \le right_i$ 的 **长度最小** 区间的长度。  
如果不存在这样的区间，那么答案是 $-1$。
# 分析

先将符合左边界要求的 加入进来  
保存 好对应的长度（找最小的长度 --->> 用最小堆）  
然后右边界不满足的剔除  
	再输出 符合条件的最小记录

# 代码
```python
import heapq
class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        a = intervals
        a.sort() # 按照左端点排序
        q = sorted((v,i) for i,v in enumerate(queries)) # 方便后续 按照顺序输出答案
        h = []
        ans = [-1] * len(queries)
        i = 0
        for v,idx in q:
            while i < len(a) and a[i][0] <=v: # 左边界比v小的全进来
                l,r = a[i]
                heapq.heappush(h,(r-l+1,r)) # (长度，右端点)
                i +=1 # 指针
            while h and h[0][1]<v: # 右边界下的 不满足 直接剔除
                heapq.heappop(h)
            if h: ans[idx] = h[0][0] # 记录最小长度
        return ans
```
