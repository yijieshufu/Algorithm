# 整数删除-真题
**【描述】 (Description)**  
给定一个长度为 $N$ 的整数序列。你需要重复执行 $K$ 次以下操作：
1. **寻找**：找到序列中当前的最小值（若有多个，取最靠前的一个）。
2. **删除**：将该最小值从序列中移除。
3. **合并**：将被删除的这个数值，加到它**左右相邻**的两个数上（如果只有一边有邻居，就只加到那一边的数上）。  
 
**【目的】 (Objective)**  
输出经过 $K$ 次操作后，序列中剩下的 $N-K$ 个元素。
# 分析
每次删除最小值  
	等于 要求使用最小堆  
		`h = [(v[i],i) for i in range(n)] ` `heapq.heapify(h)` 读入到列表中 然后堆化  
针对 讲值分给两边  
	记录两边的下标 （使用链表）  
		然后更新

最后输出未访问
## 代码

```python
import os
import sys
import heapq
it = iter(sys.stdin.read().split())
n = int(next(it))
k = int(next(it))
v =[int(next(it)) for _ in range(n)]

l =[i-1 for i in range(n)]
r =[i+1 for i in range(n)]
r[n-1] = -1

h = [(v[i],i) for i in range(n)]
heapq.heapify(h)
del_cnt = 0 # 懒删除的标志位
vis = [0] * n # 记录被删除的节点

while del_cnt < k:
  val,idx = heapq.heappop(h)
  if val !=v[idx] or vis[idx]:
    continue
  vis[idx] = 1
  del_cnt+=1
  # 处理左边
  li = l[idx]
  if li !=-1:
    v[li] +=val
    r[li] =r[idx]
    heapq.heappush(h,(v[li],li))
  # 处理右边
  ri = r[idx]
  if ri != -1:
    v[ri] +=val
    l[ri] = l[idx]
    heapq.heappush(h,(v[ri],ri))

ans = [str(v[i]) for i in range(n) if not vis[i]]
print(" ".join(ans))
```
