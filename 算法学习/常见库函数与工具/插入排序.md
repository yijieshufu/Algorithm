# 排序模版练习
- **核心动作**：在 $N \le 100$ 的极小规模下，实现**插入排序**算法对序列进行升序排列。
- **数据边界**：$N \in [2, 100]$，由于 $N$ 极小，$O(N^2)$ 的暴力实现完全可行。
## 代码

```python
import sys
# 极简 I/O 起手式
it = iter(sys.stdin.read().split())
n = int(next(it))
a = [int(next(it)) for _ in range(n)]
for i in range(1, n):
    v = a[i]
    j = i - 1 # 前一个
    while j >= 0 and a[j] > v: # 找到比当前v大的
        a[j + 1] = a[j]  # 向后移
        j -= 1
    a[j + 1] = v 
	print(*a)
```
