# 原料采购-真题
**输入**：采购点数量 $n$，目标需求 $m$，每单位距离运费 $o$。  
接下来 $n$ 行，给出每个点的单价 $a$、库存 $b$、距离工厂的距离 $c$。  
**要求**：寻找一条采购路线，凑齐 $m$ 单位原料，使得“总材料费 + 最远距离 $\times o$”最小。不可达则输出 `-1`。

# 分析
遇到一个站点  
	不管了 直接全入  
	然后判断是否超了  
		超了 扔高单价的  
			扔了 高单价 还不行 再扔  
			超过的 扔了一部分 发现不超了 那就在存回去
# 代码
```python
import sys
import heapq
it = iter(sys.stdin.read().split())
n, m, o = int(next(it)), int(next(it)), int(next(it))

h =[]
cost = 0
cur_m = 0
ans = float('inf')

for _ in range(n):
  a, b, c = int(next(it)), int(next(it)), int(next(it))
  heapq.heappush(h,(-a,b)) # 存入 大根堆
  # 一股脑 全入
  cur_m += b
  cost += a*b
  while cur_m > m:
    p,q = heapq.heappop(h)
    p = -p
    ex = cur_m - m # 多的部分
    
    if q<=ex: # 直接全退
      cur_m -= q
      cost -= p * q
    else: # 退一部分 ，剩下还是压回来
      cur_m -= ex
      cost -= p * ex
      heapq.heappush(h,(-p,q-ex))
  if cur_m == m:
    ans = min(ans,cost+ c * o )
print(ans if ans != float('inf') else -1)
```
