# 题目
有 $n$ 门课，每门课有持续时间 $t$ 和最晚完成时间 $d$。

你从第 1 天开始，同一时间只能上一门课。  
求最多能修几门课。
# 分析

预处理：  
	按照截止时间 从小到大 排序

剔除的思想  
	一股脑 都加进去  
	发现 当前的时间 大于了 截止时间了  
		就可以 剔除 耗时最长的

# 代码
```python
import heapq
class Solution:
    def scheduleCourse(self, courses: List[List[int]]) -> int:
        courses.sort(key = lambda x:x[1]) # 按截止时间排序
        h = []
        cur = 0
        for t,d in courses:
            cur +=t
            heapq.heappush(h,-t) 
            if cur > d:
                cur += heapq.heappop(h)
        return len(h)
```
