# 题目
车初始有 `startFuel` 升油，目的地距离为 `target`。  
沿途有加油站，提供一定量汽油。  
求最少加几次油能到终点。无法到达返回 -1。
# 分析

`stations.append([target,0])` 目的地 和 油量

一公里 一升油

到了一个地方  
	基于能不能跑到  
		跑不到才加油  
	油都是给你按照最大的备好了
# 代码
```python
import heapq
class Solution:
    def minRefuelStops(self, target: int, startFuel: int, stations: List[List[int]]) -> int:
        h = []
        ans = 0
        cur = 0
        stations.append([target,0])

        for pos,fuel in stations:
            startFuel -= (pos - cur)

            while startFuel < 0 and h:
                startFuel -= heapq.heappop(h) # - 负油 等于加油
                ans +=1
            if startFuel < 0 : return -1

            heapq.heappush(h,-fuel) # 存入大根堆
            cur = pos 
        return ans 
```
