# 179. 最大数
给定一组非负整数 `nums`，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数，以字符串形式返回。
# 分析 

-1 是在前面  
`cmp_to_key`

# 代码

```python
from functools import cmp_to_key
class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        a = [str(x) for x in nums]
        f = lambda x,y: 1 if x + y < y + x else -1
        a.sort(key = cmp_to_key(f))
        ans = "".join(a)
        return "0" if ans[0] =='0' else ans
```
