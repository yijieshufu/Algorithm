# LC 56. 合并区间
给定一个包含若干区间的二维数组，**合并所有重叠**的区间，返回一个恰好覆盖所有原区间且**互不重叠**的新区间集合。
# 代码
```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort()
        ans = []
        for v in intervals:
			# 不重叠
            if not ans or ans[-1][1] < v[0]: # 当前进来的 左边界 是否 大于次新的右边界
                ans.append(v)
            else:# 重叠了 右边的 取最大边界
                ans[-1][1] = max(ans[-1][1],v[1])
        return ans
```
