# 整数删除-真题
**【描述】 (Description)**  
给定一个长度为 $N$ 的整数序列。你需要重复执行 $K$ 次以下操作：
1. **寻找**：找到序列中当前的最小值（若有多个，取最靠前的一个）。
2. **删除**：将该最小值从序列中移除。
3. **合并**：将被删除的这个数值，加到它**左右相邻**的两个数上（如果只有一边有邻居，就只加到那一边的数上）。  
**【条件】 (Constraints)**
- **规模**：$1 \le K < N \le 5 \times 10^5$。
    - _Sigma 级警示_：因为 $N$ 达到了 $5 \times 10^5$，如果每一轮都用 `list.index(min)` 这种 $O(N)$ 的方法找最小值，总复杂度会达到 $O(N \cdot K) \approx 2.5 \times 10^{11}$，**绝对会超时（TLE）**。
- **数值**：$0 \le A_i \le 10^8$。加和后数值可能超过 $2^{31}-1$，在部分语言中需注意使用 64 位整数（Python 默认支持大数，无需担心）。  
**【目的】 (Objective)**  
输出经过 $K$ 次操作后，序列中剩下的 $N-K$ 个元素。
 ## 🧠 核心逻辑分析
这道题的难点在于：**当你删除一个数并修改它的邻居时，序列的结构和数值都在动态变化。**
1. **如何快速找到最小值？** $\rightarrow$ 想到 **优先队列（最小堆，Priority Queue）**。
    - 我们需要把 `(数值, 原始下标)` 存入堆中。
    - _注意_：因为邻居的值会变，堆里的旧值会失效。我们需要一种“懒删除”或“有效性检查”机制。
2. **如何快速找到相邻的元素？** $\rightarrow$ 想到 **双向链表 (Doubly Linked List)**。
    - 数组删除元素是 $O(N)$，但双向链表删除节点是 $O(1)$。
    - 我们可以用两个数组 `L[i]` 和 `R[i]` 分别记录下标为 `i` 的元素左边和右边的邻居下标。
## 代码

```python
import os
import sys
import heapq
it = iter(sys.stdin.read().split())
n = int(next(it))
k = int(next(it))
V =[int(next(it)) for _ in range(n)] # 最原始的值
L = [i - 1 for i in range(n)] # L[i] 存 i 的左邻居，0 的左邻居是 -1
R = [i + 1 for i in range(n)] # R[i] 存 i 的右邻居
R[n - 1] = -1  
hq = [] #最小堆用的是list
for i in range(n):
  heapq.heappush(hq, (V[i], i)) # 存入小根堆
deleted = [False] * n 
ops = 0
while ops<k and hq:
  val, idx = heapq.heappop(hq) # 当前最小的值
  if deleted[idx] or val!=V[idx]: # 假删除 不是原来值 不看
    continue
  deleted[idx]=True
  ops+=1
  # 正式开始操作
  left_idx = L[idx] # 左邻居
  right_idx = R[idx] # 右邻居
  # 先分左
  if left_idx != -1:
    V[left_idx] += val #值分给左边
    R[left_idx] = right_idx # 更新右邻居
    heapq.heappush(hq,(V[left_idx],left_idx)) 
  #再分右
  if right_idx != -1: 
    V[right_idx] += val
    L[right_idx] = left_idx
    heapq.heappush(hq,(V[right_idx],right_idx))

ans = (str(V[i]) for i in range(n) if not deleted[i])
sys.stdout.write(" ".join(ans)+"\n")
```
