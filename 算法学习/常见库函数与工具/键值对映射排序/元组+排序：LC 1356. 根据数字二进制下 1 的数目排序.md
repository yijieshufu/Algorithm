# 题目
给你一个整数数组 `arr`。请你将数组按二进制中 `1` 的个数升序排序；  
如果个数相同，则按数值大小升序排序。 
# 分析
`lambda x:` 定义一个匿名函数（一次性抛弃型函数），接收待排序数组里的每一个元素 `x` 作为入参
# 代码
```python
class Solution:
    def sortByBits(self, arr: List[int]) -> List[int]:
        f = lambda x:(bin(x).count('1'),x)
        arr.sort(key = f)
        return arr
```
