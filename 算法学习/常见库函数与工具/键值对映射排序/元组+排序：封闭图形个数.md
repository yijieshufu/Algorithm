# 封闭图形个数
题目重新定义了数字的“大小”逻辑，我们需要严格遵循以下优先级：
- **第一优先级（封闭图形数）**：统计每个数字包含的“圈”的总数，总数越少，数字越小。
- **第二优先级（数值大小）**：如果两个数字的“圈”一样多，则比较它们本身的数值，数值越小，数字越小。
- **单个数字的“权值”对照表**：

| **封闭图形数量** | **对应的数字成员**   |
| ---------- | ------------- |
| **0 个**    | 1, 2, 3, 5, 7 |
| **1 个**    | 0, 4, 6, 9    |
| **2 个**    | 8             |
> **注意：** 圈的个数是**累加**的。例如数字 $68$：$6$ 有 1 个，$8$ 有 2 个，总计 3 个。
## 代码
```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
a=[next(it) for _ in range(n)]
M = [1, 0, 0, 0, 1, 0, 1, 0, 2, 1]
f = lambda x: (sum(M[int(c)] for c in x),int(x))
a.sort(key = f)
print(*a)
```
