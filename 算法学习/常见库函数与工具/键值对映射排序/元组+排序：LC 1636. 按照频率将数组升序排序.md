# 题目
给你一个整数数组 `nums`，请你将数组按照每个值的频率升序排序。  
如果有多个值的频率相同，请你按照数值本身将它们**降序排序**。
# 分析

# 代码
```python
class Solution:
    def frequencySort(self, nums: List[int]) -> List[int]:
        d = {}
        for a in nums:
            d[a] = d.get(a,0)+1
        nums.sort(key = lambda x:(d[x],-x))
        return nums
```
