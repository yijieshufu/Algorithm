# 题目
给定一个大小为 `n` 的数组 `a`，返回其中的多数元素。  
多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。
# 分析
使用字典 统计 次数  
	判断
# 代码
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        n = len(nums)
        d = {}
        for x in nums:
            d[x] = d.get(x,0) + 1
            if d[x] > n//2: return x
```
