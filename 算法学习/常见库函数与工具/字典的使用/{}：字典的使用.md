# 小蓝的图书馆
小蓝需要管理图书馆的图书信息。初始书库为空，需要支持两种操作：
1. `add bookname author`：向书库添加一本书及其作者。
2. `find author`：查询书库中**该作者**共有多少本书。  
注意：需要统计的是书的总量（Total count），而不是不同书的种类数。同一个作者可能有多本同名的书，每 `add` 一次，计数就要加 1。

## 分析
直接用字典  
	{}
## 代码

```python
import sys
it = iter(sys.stdin.read().split())
n = int(next(it))
d = {}
for _ in range(n):
    op = next(it)
    if op == 'add':
        _  = next(it)
        au = next(it)
        d[au] = d.get(au, 0) + 1
    else:
        # 块 2：核心查询
        au = next(it)
        print(d.get(au, 0))
```
