# LC 383. 赎金信

给你两个字符串 `a` (ransomNote) 和 `b` (magazine)，判断 `a` 能不能由 `b` 里的字符构成。

`b` 中的每个字符只能在 `a` 中使用一次。

# 分析
记录b中的频次  
	通过a中的元素来消减  
	发现消不动 就 False
# 代码
```python
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        d = {}
        for c in b:
            d[c] =d.get(c,0)+1
        for c in a:
            if d.get(c,0) <=0:return False
            d[c] -=1
        return True
```
