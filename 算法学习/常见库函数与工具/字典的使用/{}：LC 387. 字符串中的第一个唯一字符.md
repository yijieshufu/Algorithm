# 题目
给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 -1。
# 分析
字典记录频次  
`enumerate` 返回下标
# 代码
```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        d = {}
        for c in s:
            d[c] = d.get(c,0)+1
        for i ,c in enumerate(s):
            if d[c] == 1:return i 
        return -1
```
