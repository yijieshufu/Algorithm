#  受限交换
给定两个长度为 $N$ 的排列 $A$ 和 $B$（由 $1 \sim N$ 组成）。

每次操作只能交换 $A$ 中相邻的两个元素（即满足 $|i-j| \le 1$ 的 $A_i$ 与 $A_j$）。

求将序列 $A$ 恰好变为序列 $B$ 所需的最少交换次数。

数据范围：$1 \le N \le 10^5$。

# 分析 
**底层矛盾**：相邻交换排序的最小步数，在数学上严格等价于序列的**逆序对数量**。

**解决方案**：
1. **坐标映射（降维）**：序列 $B$ 不是标准的 $1 \sim N$ 升序排列，因此需要建立一个哈希映射，记录 $B$ 中每个元素的目标物理索引。
2. **重构序列**：将序列 $A$ 中的每个真实数值，替换为它在序列 $B$ 中对应的目标索引。
3. **树状数组（求逆序对）**：在新序列上从右向左扫描，利用**树状数组**（Fenwick Tree）在 $O(N \log N)$ 的时间复杂度内统计比当前元素小的已出现元素个数（即逆序对数量）。
