# 关东煮
- **初始状态**：甲拿了 **11** 串。
- **触发规则 A（后悔）**：累计吃掉 **2** 串，产生 **1** 次后悔。
- **触发规则 B（奖励）**：累计后悔 **3** 次，奖励 **1** 串并立即吃掉。
- **循环终止**：直到不再产生新的奖励串为止。
- **目标**：计算甲总共吃掉多少串。

# 代码
```python
import sys

a = 11
cnt = 0
h = 0

while a >0:
  a-=1
  cnt +=1
  if cnt %2 ==0:
    h+=1
    if h %3 ==0:
      cnt +=1
print(cnt)
```
